# Exercise 4.23: Fourth-norm approximation as a convex QCQP

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.23](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=211). The source exercise and all of its subparts were checked directly.

Write $`r_i=a_i^Tx-b_i`$ and introduce squared-residual bounds $`u_i`$. Solve

```math
\begin{aligned}
\mathrm{minimize}\quad &\sum_i u_i^2\\
\mathrm{subject\ to}\quad &(a_i^Tx-b_i)^2\le u_i,\quad i=1,\ldots,m.
\end{aligned}
```

The objective is convex quadratic. Each left side minus $`u_i`$ is a convex quadratic, so this is a convex QCQP. The inequalities force $`u_i\ge0`$.

For fixed $`x`$, minimizing the increasing function $`u_i^2`$ on $`u_i\ge r_i^2\ge0`$ gives $`u_i=r_i^2`$. Thus partial minimization gives $`\sum_i r_i^4=\|Ax-b\|_4^4`$. The fourth power is strictly increasing on nonnegative numbers, so the QCQP and norm problem have exactly the same optimal $`x`$ values. Lift an original optimizer by $`u_i=r_i^2`$; recover an original optimizer by discarding $`u`$. The original optimum is the fourth root of the QCQP optimum.

A minimizer exists because the residual affine set is closed and norm sublevel sets are compact in residual space. Nonuniqueness of $`x`$ along $`\ker A`$ is harmless.

## Validation

Both the objective and each constraint are degree at most two in the lifted variables; directly minimizing a quartic was not mislabeled as a QCQP.
