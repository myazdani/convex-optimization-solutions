# Exercise 3.19: Ordered weighted sums and an integrated log barrier

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.19, p. 116](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=130).

Original solution.

## (a) Decreasing nonnegative weights

Set $`\alpha_{r+1}=0`$ and let $`s_k(x)=\sum_{i=1}^k x_{[i]}`$, known to be convex. Telescoping yields
```math
\sum_{i=1}^r\alpha_i x_{[i]}
=\sum_{k=1}^r(\alpha_k-\alpha_{k+1})s_k(x).
```
Every coefficient is nonnegative, so this is a nonnegative sum of convex functions and is convex. The identity permits ties among weights and among sorted coordinates, and zero final weights.

## (b) Integral of a trigonometric log barrier

For each fixed $`\omega`$, $`T(x,\omega)`$ is affine in $`x`$. The strict-positivity domain is an intersection of open affine halfspaces, hence convex. Composition with the convex function $`-\log`$ makes $`x\mapsto-\log T(x,\omega)`$ convex on that domain. Integrating its convexity inequality over $`[0,2\pi]`$ proves convexity of $`f`$.

The integral is finite for every domain point: the continuous positive function $`\omega\mapsto T(x,\omega)`$ has a strictly positive minimum and a finite maximum on the compact integration interval. Thus the argument uses ordinary finite integrals, without an unmentioned integrability assumption.
