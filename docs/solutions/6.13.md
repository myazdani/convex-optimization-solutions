# Exercise 6.13: Quasiconvex interpolation by nested convex hulls

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 6.13, printed page 348. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=362).

For each data point define the finite set of lower-valued sample locations $`S_i=\{u_j:y_j<y_i\}`$.

Suppose a quasiconvex interpolant exists. Its strict sublevel set $`\{u:f(u)<y_i\}`$ is convex: a finite convex combination has value at most the maximum of its finitely many values, which is still below $`y_i`$. It contains $`S_i`$ but excludes $`u_i`$. Therefore $`u_i\notin\mathrm{conv}(S_i)`$. If $`S_i`$ is nonempty, its convex hull is compact. Let $`v_i`$ be its nearest point to $`u_i`$ and put $`h_i=u_i-v_i\ne0`$. The projection inequality gives
```math
h_i^T(u_j-u_i)\le-\|h_i\|_2^2\quad(u_j\in S_i).
```
Consequently $`g_i=h_i/\|h_i\|_2^2`$ satisfies all the requested inequalities. If $`S_i`$ is empty choose $`g_i=0`$.

Conversely, the inequalities imply $`u_i\notin\mathrm{conv}(S_i)`$: taking a convex combination would give $`g_i^T(u_i-u_i)\le-1`$, a contradiction. Let the distinct data values be $`\alpha_1<\cdots<\alpha_L`$. For $`\ell<L`$ put
```math
C_\ell=\mathrm{conv}\{u_i:y_i\le\alpha_\ell\},
\qquad C_L=\mathbb R^k,
```
and define $`f(u)=\alpha_{\min\{\ell:u\in C_\ell\}}`$. The sets are nested and convex, so every sublevel set of this finite-valued function is either empty, one of the $`C_\ell`$, or all of $`\mathbb R^k`$. It is quasiconvex. A point with value $`\alpha_\ell`$ belongs to $`C_\ell`$ (or $`C_L`$), and cannot belong to $`C_{\ell-1}`$ by the exclusion just proved. Thus $`f(u_i)=y_i`$ for all samples. The construction includes a single value level and repeated sample locations; for empty data take a constant function.
