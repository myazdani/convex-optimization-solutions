# Exercise 4.19: Fractional one-norm approximation on a box

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.19](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=210). The source exercise and all of its subparts were checked directly.

## (a) Quasiconvexity

On $`\|x\|_\infty\le1`$, Hölder's inequality gives

```math
c^Tx+d\ge d-\|c\|_1>0.
```

For any real $`\alpha`$, the objective sublevel condition is $`\|Ax-b\|_1-\alpha(c^Tx+d)\le0`$, a convex inequality. Its intersection with the box is convex, proving quasiconvexity.

## (b) Exact convex reformulation

From an original feasible $`x`$, define $`t=1/(c^Tx+d)`$ and $`y=tx`$. Then $`\|y\|_\infty\le t`$ and $`c^Ty+dt=1`$, while

```math
\|Ay-bt\|_1=t\|Ax-b\|_1=\frac{\|Ax-b\|_1}{c^Tx+d}.
```

Conversely, the proposed constraints first imply $`t\ge0`$. If $`t=0`$, the norm bound forces $`y=0`$, violating the equality. Thus $`t>0`$, and $`x=y/t`$ satisfies the original box and $`c^Tx+d=1/t`$, with exactly the same objective. This proves a bijective, objective-preserving feasible-set map and correspondence of all optimizers.

The new objective is a norm of an affine expression, the norm inequality is convex, and the remaining equation is affine. If desired, it is an LP after introducing $`u\succeq\pm(Ay-bt)`$ and minimizing $`\mathbf1^Tu`$.

The original box is compact and its denominator is bounded away from zero, so an optimizer exists. Moreover,

```math
\frac1{d+\|c\|_1}\le t\le\frac1{d-\|c\|_1},
```

so the transformed feasible set is compact too. These bounds follow either from the inverse map or directly from the normalization and $`|c^Ty|\le\|c\|_1t`$.

## Validation

The displayed convex problem needs no separately written strict inequality on $`t`$: its given constraints already force positivity. Denominator positivity and attainment are checked.
