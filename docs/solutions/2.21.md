# Exercise 2.21: The cone of separating affine functions

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.21, p. 63](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=77).

Original solution.

Let $`T`$ denote the coefficient pairs in question. Each condition is a homogeneous linear inequality in $`(a,b)`$:
```math
a^Tx-b\le0\quad(x\in C),\qquad b-a^Ty\le0\quad(y\in D).
```
Thus $`T`$ is an intersection of closed halfspaces through the origin, hence a closed convex cone. Explicitly, adding two admissible inequalities with nonnegative multipliers preserves every condition, and $`(0,0)\in T`$.

When $`C,D`$ are both nonempty, any member with $`a=0`$ must satisfy both $`0\le b`$ and $`b\le0`$, so $`b=0`$. Consequently every nonzero coefficient pair defines a genuine separating hyperplane, and if no such hyperplane exists then $`T=\{(0,0)\}`$.

The book's parenthetical singleton assertion needs this nonemptiness qualification. If empty sets are allowed, the cone conclusion remains true but that assertion can fail: for $`C=\varnothing`$, $`D=\mathbb R^n`$, there is no genuine separating hyperplane and $`T=\{(0,b):b\le0\}`$. This does not affect the convex-cone statement.
