# Exercise 5.21: A convex problem with a positive duality gap

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.21](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=294). The source exercise and all of its subparts were checked directly.

## (a) Convexity and primal solution

The objective $`e^{-x}`$ is convex, and $`x^2/y`$ is the convex quadratic-over-linear perspective on the convex domain $`y>0`$. Its inequality forces $`x=0`$. Thus every $`(0,y)`$, $`y>0`$, is optimal, with $`p^\star=1`$.

## (b) Dual problem and gap

For $`\lambda\ge0`$,

```math
g(\lambda)=\inf_{x\in\mathbb R,y>0}\{e^{-x}+\lambda x^2/y\}=0.
```

Nonnegativity proves the lower bound zero, and the sequence $`x=k,y=k^4`$ has value $`e^{-k}+\lambda/k^2\to0`$, proving equality. The infimum is not attained because the exponential is strictly positive. Hence the dual maximizes zero over $`\lambda\ge0`$, every such multiplier is optimal, $`d^\star=0`$, and the duality gap is one. For negative multipliers the unrestricted dual function is $`-\infty`$, obtained by fixing nonzero $`x`$ and letting $`y\downarrow0`$.

## (c) Slater

Strict feasibility would require $`x^2/y<0`$, which is impossible. Slater's condition therefore fails, as is consistent with the positive gap.

## (d) Perturbed values and failure of the claimed bound

For $`u<0`$ the constraint is infeasible. For $`u=0`$ its value is one as above. For $`u>0`$, choose $`x=k>0,y=k^2/u`$; the constraint is tight and the objective tends to zero. Therefore

```math
p^\star(u)=\begin{cases}+\infty,&u<0,\\1,&u=0,\\0,&u>0.\end{cases}
```

For positive $`u`$ this infimum is unattained. Fix any finite optimal multiplier $`\lambda^\star\ge0`$. If it is zero, every positive $`u`$ violates $`0\ge1-\lambda^\star u`$. If it is positive, choose $`0<u<1/\lambda^\star`$ for the same contradiction. The valid weak-duality bound uses $`d^\star-\lambda^\star u= -\lambda^\star u`$, not $`p^\star(0)-\lambda^\star u`$ when strong duality fails.

## Validation

Both limiting infima retain the strictly positive $`y`$ domain. The sensitivity failure holds for every optimal dual multiplier, not just a convenient selected one.
