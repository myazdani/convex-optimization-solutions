# Exercise 4.54: Optimal points and every positive scalarization

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.54](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=220). The source exercise and all of its subparts were checked directly.

If $`x^\star`$ is an optimal point, then for every feasible $`y`$, $`f_0(y)-f_0(x^\star)\in K`$. For every $`\lambda\in\mathrm{int}K^*`$, dual-cone membership gives

```math
\lambda^Tf_0(x^\star)\le\lambda^Tf_0(y).
```

Hence $`x^\star`$ solves every such scalarized problem. Convexity of the original problem is unnecessary.

Conversely suppose the same feasible point $`x`$ solves the scalarized problem for every interior dual weight. Fix another feasible $`y`$ and put $`d=f_0(y)-f_0(x)`$. Then $`\lambda^Td\ge0`$ for all $`\lambda\in\mathrm{int}K^*`$. Choose a fixed interior dual vector $`\lambda_0`$. For any $`\mu\in K^*`$ and $`\epsilon>0`$, the vector $`\mu+\epsilon\lambda_0`$ is interior, so its pairing with $`d`$ is nonnegative. Letting $`\epsilon\downarrow0`$ gives $`\mu^Td\ge0`$ for every dual-cone vector. The bipolar characterization of the closed convex cone now gives $`d\in K`$. Since this holds for every feasible $`y`$, $`x`$ is an optimal point.

## Validation

The converse requires one point to minimize every strictly positive scalarization, not merely one selected scalarization. Closedness and the proper-cone interior properties justify the dual-limit argument.
