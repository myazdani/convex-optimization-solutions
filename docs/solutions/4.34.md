# Exercise 4.34: Log-convexity of the Perron eigenvalue

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.34](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=214). The source exercise and all of its subparts were checked directly.

Let $`A,B`$ be entrywise positive and $`0<\theta<1`$. Define the entrywise geometric interpolation $`C_{ij}=A_{ij}^{\theta}B_{ij}^{1-\theta}`$. By Perron–Frobenius, choose positive eigenvectors $`v,w`$ for the positive spectral radii $`\rho(A),\rho(B)`$. Set $`z_i=v_i^\theta w_i^{1-\theta}>0`$. Hölder's inequality gives, row by row,

```math
\begin{aligned}
(Cz)_i
&=\sum_j(A_{ij}v_j)^\theta(B_{ij}w_j)^{1-\theta}\\
&\le\left(\sum_jA_{ij}v_j\right)^\theta
\left(\sum_jB_{ij}w_j\right)^{1-\theta}\\
&=\rho(A)^\theta\rho(B)^{1-\theta}z_i.
\end{aligned}
```

The stated Perron eigenvalue characterization $`\rho(C)=\inf_{u\succ0}\max_i(Cu)_i/u_i`$ then yields

```math
\rho(C)\le\rho(A)^\theta\rho(B)^{1-\theta}.
```

Taking logarithms is legitimate since the radii are positive. Writing $`U_{ij}=\log A_{ij}`$ and $`V_{ij}=\log B_{ij}`$, the interpolated matrix has log entries $`\theta U+(1-\theta)V`$. The inequality is exactly the convexity inequality for the function mapping log entries to log spectral radius. At $`\theta=0,1`$ it holds with equality; at $`\theta=1/2`$ it gives the requested geometric-mean bound.

## Validation

The argument concerns entrywise logarithms, not the matrix logarithm. Positivity supplies the positive eigenvectors and avoids undefined logarithms.
