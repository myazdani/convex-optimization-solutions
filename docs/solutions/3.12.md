# Exercise 3.12: An affine function between convex and concave functions

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.12, p. 115](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=129).

Original solution.

Consider the open convex subsets of $`\mathbb R^{n+1}`$
```math
U=\{(x,t):t>f(x)\},\qquad V=\{(x,t):t<g(x)\}.
```
They are open because finite convex and concave functions on all of space are continuous, and disjoint because $`g\le f`$. Separation gives $`(a,b)\ne0`$ and $`c`$ such that
```math
a^Tx+bt\ge c\quad((x,t)\in U),\qquad
a^Tx+bt\le c\quad((x,t)\in V).
```
Sending $`t\to+\infty`$ in $`U`$ forces $`b\ge0`$. If $`b=0`$, the fact that both sets project onto every $`x\in\mathbb R^n`$ forces $`a^Tx=c`$ for all $`x`$, hence $`a=0`$, a contradiction. Thus $`b>0`$.

Let $`t\downarrow f(x)`$ and $`t\uparrow g(x)`$ in the respective inequalities. They become
```math
g(x)\le h(x)=\frac{c-a^Tx}{b}\le f(x),\qquad x\in\mathbb R^n.
```
The constructed $`h`$ is affine, as required. Full domains are used to rule out a vertical separating hyperplane.
