# Exercise 8.28: Inscribed and covering homothetic symmetric polyhedra

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.28, printed page 452. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=466).

Assume $`P_1`$ is nonempty, checking this first by LP. The set $`P_2=\{z:|Cz|\le\mathbf1\}`$ always contains zero. We state the usual bounded-template formulations, then handle the scale-zero issue when the template is unbounded.

## (a) Largest inscribed copy
For each row $`a_i^T`$ of $`A`$, compute the support value by an LP:
```math
h_i=\sup\{a_i^Tz:-\mathbf1\le Cz\le\mathbf1\}.
```
For finite $`h_i`$, exact containment is $`a_i^Tx_c+t h_i\le b_i`$. Thus solve
```math
\text{maximize }t\quad\text{subject to }Ax_c+t h\le b,\quad t\ge0.
```
These conditions follow by maximizing each defining affine functional on $`tP_2+x_c`$, and suffice because they enforce every halfspace of $`P_1`$. They are exact also at $`t=0`$ when all support values are finite. If any $`h_i=+\infty`$, no positive-scale copy fits; the optimal scale is zero, with any center in $`P_1`$.

## (b) Smallest covering copy
For each row $`c_j^T`$ of $`C`$, compute $`U_j=\sup_{x\in P_1}c_j^Tx`$ and $`L_j=\inf_{x\in P_1}c_j^Tx`$ by two LPs. If any bound is infinite, no finite positive-scale cover exists. Otherwise, for $`t>0`$, containment is exactly
```math
U_j-c_j^Tx_c\le t,\qquad c_j^Tx_c-L_j\le t.
```
Minimize $`t`$ subject to these linear inequalities and $`t\ge0`$. When $`C`$ has full column rank, $`P_2`$ is bounded and this is exact even at zero: the zero inequalities then force every point of $`P_1`$ to equal $`x_c`$.

If $`C`$ is rank deficient, do not silently identify $`0P_2+x_c=\{x_c\}`$ with $`\{x:C(x-x_c)=0\}`$, which is an affine subspace. A positive LP optimum is still an exact solution. A zero LP optimum is attained in the original set-scaling problem only when $`P_1`$ is a singleton; otherwise it is the infimum, with arbitrarily small positive scales feasible and no minimum. This distinction is necessary for the unbounded-template cases allowed by the literal statement. Singleton status can be checked by coordinatewise LP bounds on $`P_1`$. If $`P_1`$ is empty, part (a) is infeasible and part (b) is vacuous with optimum zero.
