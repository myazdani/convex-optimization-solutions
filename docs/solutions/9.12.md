# Exercise 9.12: A trust region produces a regularized Newton model

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.12, printed page 515. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=529).

The convexity assumption gives $`H\succeq0`$. The ball is compact, so the quadratic model has a minimizer $`v_*`$. Use the equivalent constraint $`\|v\|^2\le\gamma^2`$; since $`\gamma>0`$, zero is strictly feasible. Convex KKT conditions therefore yield a multiplier $`\widehat\beta\ge0`$ with
```math
(H+2\widehat\beta I)v_*=-g,\qquad
\widehat\beta(\|v_*\|^2-\gamma^2)=0.
```
The regularized quadratic has gradient zero at $`v_*`$ and PSD Hessian $`H+2\widehat\beta I`$, so $`v_*`$ globally minimizes
```math
\tfrac12v^THv+g^Tv+\widehat\beta\|v\|^2.
```
This proves the assertion. If an unconstrained model minimizer lies in the ball, one may take $`\widehat\beta=0`$. Otherwise the ball is active and $`\widehat\beta>0`$, making the regularized Hessian positive definite. Diagonalizing $`H`$ then reduces finding the multiplier to the monotone scalar equation $`\|(H+2\beta I)^{-1}g\|=\gamma`$. If $`g=0`$, zero is already optimal and no positive regularization is necessary.
