# Exercise 4.21: Linear and quadratic optimization on ellipsoids

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.21](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=210). The source exercise and all of its subparts were checked directly.

## (a) Linear objective, centered ellipsoid

For $`A\succ0`$ set $`z=A^{1/2}x`$ and $`d=A^{-1/2}c\ne0`$. The problem is $`\min_{\|z\|_2\le1}d^Tz`$. Cauchy–Schwarz gives its unique minimizer $`z^\star=-d/\|d\|_2`$. Thus

```math
x^\star=-\frac{A^{-1}c}{\sqrt{c^TA^{-1}c}},\qquad
p^\star=-\sqrt{c^TA^{-1}c}.
```

If symmetric $`A`$ is not positive semidefinite, choose $`v`$ with $`v^TAv<0`$. If $`c^Tv\ne0`$, choose its sign so $`c^Tv<0`$; the ray $`tv`$ is feasible and has objective tending to $`-\infty`$. If $`c^Tv=0`$, put $`w=-c+kv`$. For sufficiently large $`|k|`$, $`w^TAw<0`$, while $`c^Tw=-\|c\|_2^2<0`$. The ray $`tw`$ again proves value $`-\infty`$. Thus every such nonconvex case with $`c\ne0`$ is unbounded below.

For completeness, the excluded singular positive semidefinite case is finite exactly when $`c\in\mathrm{range}(A)`$. If so replace the inverse by the pseudoinverse and add arbitrary kernel vectors to the displayed minimizer; otherwise a kernel direction proves unboundedness.

## (b) Shifted ellipsoid

Put $`z=x-x_c`$ and apply part (a). The unique solution and value are

```math
x^\star=x_c-\frac{A^{-1}c}{\sqrt{c^TA^{-1}c}},\qquad
p^\star=c^Tx_c-\sqrt{c^TA^{-1}c}.
```

## (c) Quadratic objective

Set $`C=A^{-1/2}BA^{-1/2}`$ and $`z=A^{1/2}x`$. The problem becomes $`\min_{\|z\|_2\le1}z^TCz`$. Let $`\beta=\lambda_{\min}(C)`$. Spectral decomposition yields

```math
p^\star=\min(0,\beta).
```

If $`B\succeq0`$, the value is zero, and the complete optimal set is $`\ker B\cap\{x:x^TAx\le1\}`$, including the origin. If $`B`$ is not positive semidefinite, congruence gives $`\beta<0`$. The inequality $`z^TCz\ge\beta\|z\|_2^2\ge\beta`$ is tight precisely for unit vectors in the minimum-eigenvalue eigenspace. Hence all optimizers are

```math
x=A^{-1/2}z,\qquad \|z\|_2=1,\qquad Cz=\beta z.
```

Equivalently they satisfy $`Bx=\beta Ax`$ and $`x^TAx=1`$. Negative eigenvalues therefore give an explicit global solution even though the objective is nonconvex; compactness of the ellipsoid ensures attainment.

## Validation

The nonconvex constraint case and nonconvex objective case have different outcomes and are proved separately. All minimizer nonuniqueness in the quadratic case is included.
