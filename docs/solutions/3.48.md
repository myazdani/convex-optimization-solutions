# Exercise 3.48: Subtracting a nonnegative constant preserves log-concavity

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.48, p. 122](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=136).

Original solution.

If $`a=0`$, the assertion is immediate. Suppose $`a>0`$, and write $`h=\log f`$, a concave function. The new positive domain is $`\{x:h(x)>\log a\}`$, a convex strict superlevel set. On $`s>\log a`$, define
```math
\phi(s)=\log(e^s-a),\qquad
\phi'(s)=\frac{e^s}{e^s-a}>0,\qquad
\phi''(s)=-\frac{ae^s}{(e^s-a)^2}<0.
```
Thus $`\phi`$ is concave and increasing, so $`\log(f-a)=\phi\circ h`$ is concave on the new domain. Therefore $`g=f-a`$ is log-concave wherever it is positive, including the possible empty-domain case.
