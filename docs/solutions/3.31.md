# Exercise 3.31: The largest positively homogeneous minorant

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.31, p. 119](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=133).

Original solution.

Use extended values outside the domain. The defining expression can also be written as the partial infimum of a perspective:
```math
g(x)=\inf_{t>0}t f(x/t).
```
This interpretation allows $`+\infty`$ when no scaling is in the domain, and possibly $`-\infty`$.

## (a) Homogeneity and the zero-scale qualification

For every $`s>0`$, the substitution $`\beta=\alpha s`$ gives
```math
g(sx)=\inf_{\alpha>0}\frac{f(\alpha sx)}\alpha
=s\inf_{\beta>0}\frac{f(\beta x)}\beta=sg(x).
```
The source's claim for $`s=0`$ needs an additional normalization/properness assumption. If $`0\in\mathrm{dom}\,f`$ and $`f(0)\ge0`$, then $`g(0)=\inf_{\alpha>0}f(0)/\alpha=0`$, giving the usual zero-scale identity at finite-valued points. But if $`f\equiv-1`$, then $`g\equiv-\infty`$ and ordinary homogeneity at zero is not meaningful. If $`0\notin\mathrm{dom}\,f`$, then $`g(0)=+\infty`$. Thus positive-scale homogeneity is unconditional; a finite homogeneous function on a cone containing zero requires the stated zero-value qualification.

## (b) Greatest homogeneous underestimator

Taking $`\alpha=1`$ gives $`g\le f`$. If $`h`$ is positively homogeneous and $`h\le f`$, then for every $`\alpha>0`$,
```math
h(x)=\frac{h(\alpha x)}\alpha\le\frac{f(\alpha x)}\alpha.
```
Taking the infimum proves $`h(x)\le g(x)`$. This establishes maximality wherever proper minorants exist; if the expression is $`-\infty`$, the inequality correctly rules out finite-valued homogeneous minorants there.

## (c) Convexity

The perspective $`P(x,t)=t f(x/t)`$ is jointly convex for $`t>0`$. Its partial infimum is convex. Explicitly, choose approximately minimizing positive scales $`t_1,t_2`$ for $`x_1,x_2`$ and set $`t=\theta t_1+(1-\theta)t_2>0`$. Perspective convexity gives
```math
g(\theta x_1+(1-\theta)x_2)
\le P(\theta x_1+(1-\theta)x_2,t)
\le\theta P(x_1,t_1)+(1-\theta)P(x_2,t_2).
```
Let the approximation errors tend to zero. This proves convexity when $`g`$ is proper; limits of arbitrarily negative values give the corresponding improper extended-valued conclusion. The result does not justify silently asserting finiteness, which the counterexample in (a) disproves.
