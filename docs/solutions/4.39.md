# Exercise 4.39: Congruence reductions of semidefinite programs

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.39](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=215). The source exercise and all of its subparts were checked directly.

Write $`M(x)=\sum_i x_iF_i+G`$.

## (a) Invertible congruence

For every real $`v`$,

```math
v^TR^TM(x)Rv=(Rv)^TM(x)(Rv).
```

Because $`R`$ is invertible, $`Rv`$ ranges over all vectors. Thus $`M(x)\preceq0`$ if and only if $`R^TM(x)R\preceq0`$. Expanding the latter gives exactly the stated transformed coefficient matrices. The same $`x`$ is feasible in both problems and the objective is unchanged; all values and optimizers therefore coincide.

## (b) Diagonal case

If all transformed matrices are diagonal, negative semidefiniteness is simply nonpositivity of each diagonal entry. The equivalent LP minimizes $`c^Tx`$ subject to

```math
\sum_i x_i(\widetilde F_i)_{jj}+\widetilde G_{jj}\le0,
\qquad j=1,\ldots,k.
```

## (c) Arrow-matrix case

Let $`h=\sum_i\alpha_i x_i+\beta`$ and $`v=\sum_i x_i a_i+b`$. The transformed LMI is

```math
\begin{bmatrix}hI&v\\v^T&h\end{bmatrix}\preceq0.
```

For $`v\ne0`$, its two eigenvalues on the subspace spanned by $`(v,0)`$ and the final coordinate are $`h\pm\|v\|_2`$, and the remaining ones are $`h`$. The same conclusion follows directly for $`v=0`$. Hence it is equivalent to the single SOC constraint

```math
\left\|\sum_i x_i a_i+b\right\|_2\le-\sum_i\alpha_i x_i-\beta.
```

The scalar case with an empty vector part reduces to the single linear inequality $`h\le0`$. The conic constraint already enforces nonnegativity of its right side.

## Validation

Invertibility is essential to part (a), and the sign of the SOC right side reflects a negative, rather than positive, semidefinite LMI.
