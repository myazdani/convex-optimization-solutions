# Exercise 9.26: Sparse lifted Newton equations for affine compositions

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.26, printed page 518. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=532).

Stack the $`A_i`$ into $`A`$, the $`g_i`$ into $`q`$, and let $`B=\mathrm{diag}(H_1,\ldots,H_N)`$. The Newton model is
```math
\min_v\ \tfrac12(Av)^TB(Av)+q^TAv.
```
Although $`A^TBA`$ is dense, it need not be explicitly formed. Introduce $`z=Av`$ and a multiplier $`\eta`$. The exact Newton direction is obtained from the sparse symmetric system
```math
\begin{bmatrix}
0&0&A^T\\
0&B&-I\\
A&-I&0
\end{bmatrix}
\begin{bmatrix}v\\z\\\eta\end{bmatrix}
=
\begin{bmatrix}0\\-q\\0\end{bmatrix}.
```
Its equations say $`\eta=Bz+q`$, $`z=Av`$, and $`A^T\eta=0`$, hence $`A^TBA v=-A^Tq`$, exactly the Newton equation. Small dense $`H_i`$ blocks and sparse $`A_i`$ are retained without computing any $`H_i^{-1}`$, so semidefinite local Hessians are allowed. If the full Newton Hessian is positive definite, the lifted system is nonsingular; a sparse symmetric-indefinite factorization with an ordering exploiting the incidence graph is an appropriate direct method.

Setup storage is $`O(\sum_i\mathrm{nnz}(A_i)+\sum_i m_i^2)`$. Factorization cost depends on fill-in and the actual sparsity graph; small $`m_i`$ alone does not justify a universal linear-time claim. If direct fill is excessive, apply the Hessian matrix-free as
```math
Hv=\sum_i A_i^T(H_i(A_iv)),
```
at cost $`O(\sum_i\mathrm{nnz}(A_i)+\sum_i m_i^2)`$ per product and use preconditioned conjugate gradients when $`H\succ0`$. Terminating that solve at a specified residual gives an inexact Newton method, which must be distinguished from an exact direct solve. In either implementation evaluate the local derivatives at $`A_ix+b_i`$, solve for the direction, and perform a feasibility-preserving descent line search. If $`H`$ is singular, use a justified reduced-space or regularized variant rather than silently inverting it.
