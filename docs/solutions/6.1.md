# Exercise 6.1: Quadratic bounds for the logarithmic penalty

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 6.1, printed page 344. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=358).

Put $`s=(u/a)^2`$. For $`0\le s<1`$, integration of the geometric series gives
```math
-\log(1-s)=\sum_{j=1}^{\infty}\frac{s^j}{j}.
```
Consequently $`\phi(u)\ge u^2`$, and, when $`u\ne0`$,
```math
\frac{\phi(u)}{u^2}=\sum_{j=1}^{\infty}\frac{(u/a)^{2j-2}}j
```
is nondecreasing in $`|u|`$. Its continuous value at zero is one. Set $`M=\|u\|_\infty<a`$. Each component therefore satisfies
```math
u_i^2\le\phi(u_i)\le\frac{\phi(M)}{M^2}u_i^2.
```
Summation proves both bounds. If $`M=0`$, the vector is zero and both bounds hold with the continuous ratio one. At $`M/a=1/4`$, the ratio is $`-16\log(15/16)=1.032616338\ldots<1.033`$, giving the stated numerical factor.
