# Exercise 9.13: Self-concordance of an inverse-slack penalty

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.13, printed page 516. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=530).

## (a) Scalar inverse
For $`f(x)=1/x`$,
```math
f''(x)=2x^{-3},\qquad |f'''(x)|=6x^{-4},
\qquad \frac{|f'''(x)|}{2f''(x)^{3/2}}
=\frac{3\sqrt x}{2\sqrt2}.
```
The last ratio is at most one exactly when $`x\le8/9`$. Hence the function is self-concordant on the requested interval $`(0,8/9)`$.

## (b) Sum of inverse slacks
Let $`s_i(x)=b_i-a_i^Tx`$ and choose $`\alpha>(9/8)\max_i\sup_{x\in\mathrm{dom}f}s_i(x)`$. Every slack in the domain satisfies $`0<s_i(x)/\alpha<8/9`$. Thus
```math
\frac\alpha{s_i(x)}=\frac1{s_i(x)/\alpha}
```
is the scalar self-concordant function from (a) composed with an affine map. Along any line, the affine chain rule preserves the self-concordance inequality, including constant slacks. A sum preserves it because for nonnegative second derivatives $`q_i`$,
```math
\left|\sum_i f_i'''\right|\le2\sum_i q_i^{3/2}
\le2\left(\sum_iq_i\right)^{3/2}.
```
Therefore the full penalty is self-concordant. Boundedness of the domain ensures each affine slack has a finite supremum, so such an $`\alpha`$ can be chosen; the same proof works on any domain with finite maximum slack.
