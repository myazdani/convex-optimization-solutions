# Exercise 3.24: Function classifications on the probability simplex

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.24, p. 117](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=131).

Original solution.

The nontrivial classifications below are for $`n\ge2`$ with the strictly ordered support in the question. For $`n=1`$ every function is constant, so all four properties hold.

## (a)–(c) Expectations and event probabilities

Each is affine in $`p`$: respectively $`\sum_i a_ip_i`$, $`\sum_{i:a_i\ge\alpha}p_i`$, and $`\sum_{i:\alpha\le a_i\le\beta}p_i`$. Therefore each is convex, concave, quasiconvex, and quasiconcave, including empty or certain events.

## (d) Negative entropy

With $`0\log0=0`$, the function is convex by convexity of $`s\log s`$ and continuous extension at zero, hence quasiconvex. It is neither concave nor quasiconcave: two distinct point masses have value zero, while their equal mixture has value $`-\log2<0`$.

## (e) Variance

It is concave and quasiconcave, since
```math
v(\theta p+(1-\theta)q)
=\theta v(p)+(1-\theta)v(q)
 +\theta(1-\theta)(\mu_p-\mu_q)^2.
```
It is neither convex nor quasiconvex: distinct point masses have variance zero and their mixture has positive variance.

## (f) First quartile

It is both quasiconvex and quasiconcave, since
```math
\{p:q(p)\le t\}=\left\{p:\sum_{a_i\le t}p_i\ge\tfrac14\right\},
\qquad
\{p:q(p)\ge t\}=\left\{p:\sum_{a_i<t}p_i<\tfrac14\right\}.
```
Both sets are convex. It is neither convex nor concave. Restrict to the first two support values and write $`s=p_1`$. The quartile is $`a_1`$ for $`s\ge1/4`$ and $`a_2`$ otherwise. The midpoint of $`s=0.3`$ and $`s=0`$ is $`0.15`$, violating convexity; the midpoint of $`s=0.5`$ and $`s=0`$ is $`0.25`$, violating concavity.

## (g) Smallest 90-percent support cardinality

Let $`c(p)`$ be this integer-valued quantity. For $`1\le k\le n`$,
```math
c(p)\ge k\quad\Longleftrightarrow\quad
\sum_{i=1}^{k-1}p_{[i]}<0.9.
```
The empty sum for $`k=1`$ is zero. A largest-coordinate sum is convex, so its strict sublevel set is convex. Every real superlevel of the integer-valued function reduces to one of these sets, proving quasiconcavity.

It is not quasiconvex or convex: distinct point masses have cardinality one, while their equal mixture has cardinality two. It is not concave: for two coordinates take $`p=(0.89,0.11)`$ with cardinality two and $`q=(1,0)`$ with cardinality one. Their midpoint has cardinality one, below the average $`3/2`$.

## (h) Minimum 90-percent interval width

The minimum is attained by an interval whose endpoints are support values; there are only finitely many such intervals. Write its width as $`w(p)`$. For every real $`r`$,
```math
w(p)\ge r\quad\Longleftrightarrow\quad
\sum_{i:a_i\in I}p_i<0.9
\quad\text{for every support-endpoint interval }I\text{ of width }<r.
```
This is an intersection of strict affine halfspaces, so $`w`$ is quasiconcave. It is neither quasiconvex nor convex: point masses at two different support points have width zero, whereas their equal mixture requires the positive distance between them. It is not concave: on those two points, the distribution $`(0.89,0.11)`$ requires their full distance, while $`(1,0)`$ and their midpoint both have width zero.
