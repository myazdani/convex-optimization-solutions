# Exercise 5.3: One inequality and the conjugate perspective

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.3](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=287). The source exercise and all of its subparts were checked directly.

For $`\lambda>0`$, the dual function is

```math
g(\lambda)=\inf_{x\in\mathrm{dom}f}\{c^Tx+\lambda f(x)\}
=-\lambda f^*(-c/\lambda).
```

Thus on the full domain $`\mathrm{dom}f=\mathbb R^n`$ and with $`c\ne0`$, the nontrivial dual is

```math
\mathrm{maximize}_{\lambda>0}\quad-\lambda f^*(-c/\lambda).
```

The omitted endpoint $`\lambda=0`$ has value $`\inf_x c^Tx=-\infty`$, so including it cannot improve the dual bound. Infinite conjugate values likewise give dual value $`-\infty`$.

Even if $`f`$ is nonconvex, its conjugate is convex, since it is the supremum of the affine functions $`y\mapsto y^Tx-f(x)`$. The perspective $`\lambda f^*(y/\lambda)`$ is convex for positive $`\lambda`$; restricting $`y=-c`$ and negating it proves concavity of the dual objective. Alternatively every $`c^Tx+\lambda f(x)`$ is affine in $`\lambda`$, and their infimum is concave. Therefore the dual is a convex optimization problem in the sense of concave maximization over a convex domain. No strong-duality conclusion follows without further assumptions.

If $`f`$ has a restricted domain, retain the endpoint separately as $`g(0)=\inf_{x\in\mathrm{dom}f}c^Tx`$, which need not be $`-\infty`$; the positive-multiplier formula is unchanged. This is the domain-correct version of the same dual.

## Validation

The multiplier sign, minus sign in the conjugate argument, and the zero-multiplier domain issue are all explicit; convexity of the original constraint was not assumed.
