# Exercise 3.46: Full-domain continuous quasilinear functions

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.46, p. 122](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=136).

Original solution.

If $`f`$ is constant, take $`a=0`$ and a constant $`g`$. Suppose it is nonconstant. For any level $`\alpha`$ strictly between two attained values, let
```math
C_\alpha=\{x:f(x)\le\alpha\},\qquad
D_\alpha=\{x:f(x)>\alpha\}.
```
Both are nonempty and convex: the first by quasiconvexity, the second because it is the union of the nested convex sets $`\{f\ge\beta\}`$ for $`\beta>\alpha`$. Continuity makes the first closed and the second open.

Separation gives a nonzero normal $`a_\alpha`$ and a scalar $`b_\alpha`$ with $`a_\alpha^Tx\le b_\alpha`$ on $`C_\alpha`$ and $`a_\alpha^Tx\ge b_\alpha`$ on $`D_\alpha`$. Openness of $`D_\alpha`$ makes its inequality strict. Since these two sets partition all of space, this forces
```math
C_\alpha=\{x:a_\alpha^Tx\le b_\alpha\}.
```
Indeed a point in the displayed halfspace cannot be in the open opposite set, and the reverse inclusion is already known.

All these nontrivial sublevel halfspaces are nested. Containment of nonempty proper halfspaces forces their normals to be positive multiples of each other (Exercise 2.6). Choose a fixed nonzero common orientation $`a`$. If $`a^Tx=a^Ty`$ but $`f(x)\ne f(y)`$, a level strictly between their values would place one point in its sublevel halfspace and the other outside, impossible for equal $`a`$ coordinates. Thus $`f`$ is constant on each hyperplane perpendicular to $`a`$.

Define $`g(s)=f(sa/\|a\|_2^2)`$. Then $`f(x)=g(a^Tx)`$ for every $`x`$. The same oriented halfspace description implies that $`g`$ is nondecreasing: if $`s<t`$ but $`g(s)>g(t)`$, a level between them would have a sublevel containing $`t`$ but not $`s`$, contradicting its lower-halfline form. Reversing $`a`$ gives a nonincreasing representation if desired.

Conversely, a monotone scalar function composed with a linear functional has sublevel and superlevel sets that are halfspaces, possibly open, empty, or all of space. Thus it is quasilinear. Continuity is not needed for this converse.
