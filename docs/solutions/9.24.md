# Exercise 9.24: Block-diagonal Newton systems and separability

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.24, printed page 518. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=532).

For a fixed partition into blocks of sizes $`n_1,\ldots,n_k`$, let $`H=\mathrm{diag}(H_1,\ldots,H_k)`$ and partition the gradient correspondingly. The Newton equations separate into
```math
H_i\Delta x_i=-g_i,\qquad i=1,\ldots,k.
```
Factor and solve each positive-definite block independently, optionally in parallel. Dense Cholesky costs about $`\sum_i n_i^3/3`$ instead of $`n^3/3`$, with triangular solves costing $`O(\sum_i n_i^2)`$ and storage of the same order. Singular blocks require an appropriate reduced-space or regularized method; block structure alone does not supply a unique Newton direction.

If this zero cross-block Hessian structure holds throughout an open convex domain, the objective is additively separable by blocks, up to an affine term and constant:
```math
f(x)=c+\sum_i f_i(x_i).
```
Indeed a component of the gradient has zero derivative with respect to every other block; along the segment between two points having the same $`i`$th block, it is constant. It therefore depends only on $`x_i`$. Integrating these block gradient fields on their convex projected domains gives the $`f_i`$, and their sum has the same gradient as $`f`$, leaving only a constant. Each $`f_i`$ is convex because its Hessian is PSD. A coupled domain may still impose coupled feasibility even when the formula separates. Block diagonality at only one iterate does not imply global separability.
