# Exercise 8.18: Moving an analytic center with redundant inequalities

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.18, printed page 449. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=463).

There is an important missing hypothesis in an unrestricted reading: the claim is false for general unbounded polyhedra. For $`P=[0,\infty)`$ described by $`-x\le0`$, every nonconstant valid added inequality has nonpositive normal. All nonconstant logarithmic barrier terms then decrease as $`x\to\infty`$, so no finite point can be an analytic center. We prove the intended statement for a bounded full-dimensional polyhedron, the setting in which a unique analytic center is available.

Let $`s_i=b_i-a_i^Tx_0>0`$ and
```math
g=\nabla\phi(x_0)=\sum_i\frac{a_i}{s_i}.
```
If $`g=0`$, the point is already an analytic center; take the redundant constant inequality $`0\le1`$ once. Otherwise set $`c=-g`$. Boundedness ensures that $`H=\sup_{x\in P}c^Tx`$ is finite. Choose a positive integer
```math
q>H-c^Tx_0,
\qquad\gamma=c^Tx_0+q.
```
Then $`c^Tx\le H<\gamma`$ holds everywhere on $`P`$, so adding $`q`$ copies leaves the set unchanged. The new barrier is $`\widetilde\phi(x)=\phi(x)-q\log(\gamma-c^Tx)`$, and at $`x_0`$,
```math
\nabla\widetilde\phi(x_0)
=g+\frac{q c}{\gamma-c^Tx_0}=g+c=0.
```
Its convexity makes $`x_0`$ a global minimizer. Since a bounded full-dimensional polyhedron has row normals spanning $`\mathbb R^n`$, its original barrier Hessian $`\sum_i a_ia_i^T/s_i(x)^2`$ is positive definite throughout the strict domain; the minimizer is therefore unique. More generally the construction works whenever the support value in direction $`-g`$ is finite, with uniqueness only modulo lineality if present.
