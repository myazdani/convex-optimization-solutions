# Exercise 7.12: Optimal randomized action is deterministic

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 7.12, printed page 396. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=410).

Let $`s_i`$ be column $`i`$ of $`S`$. The desired diagonal entry is $`(PS)_{ii}=P_{i,:}s_i`$, a convex combination of entries in row $`i`$ of $`P`$. Therefore every feasible strategy satisfies
```math
\min_i(PS)_{ii}\le\min_i\max_jP_{ij}.
```
For each outcome $`i`$, choose any $`j_i\in\arg\max_jP_{ij}`$ and set $`s_i=e_{j_i}`$. These choices are independent between columns, satisfy the probability constraints, and give $`(PS)_{ii}=\max_jP_{ij}`$ simultaneously. The optimal value is thus exactly $`\min_i\max_jP_{ij}`$, attained by this deterministic action strategy. Ties can be resolved arbitrarily; randomization over tied maximizing actions also works but is unnecessary.
