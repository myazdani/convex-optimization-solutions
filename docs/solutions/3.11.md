# Exercise 3.11: Monotone gradients and a non-gradient monotone map

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.11, p. 115](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=129).

Original solution.

The first-order convexity inequalities at $`x`$ and $`y`$ are
```math
f(y)\ge f(x)+\nabla f(x)^T(y-x),\qquad
f(x)\ge f(y)+\nabla f(y)^T(x-y).
```
Adding and rearranging yields $`(\nabla f(x)-\nabla f(y))^T(x-y)\ge0`$, so the gradient is monotone.

The converse for arbitrary mappings is false. On $`\mathbb R^2`$, let $`\psi(x_1,x_2)=(-x_2,x_1)`$. Its matrix is skew-symmetric, so
$`(\psi(x)-\psi(y))^T(x-y)=0`$ for all pairs: it is monotone. But it cannot be any scalar function's gradient. If it were, its continuously differentiable components would give mixed second derivatives $`\partial_2\partial_1f=-1`$ and $`\partial_1\partial_2f=1`$, contradicting equality of continuous mixed partials. Thus monotonicity alone does not enforce the integrability condition needed for a gradient.
