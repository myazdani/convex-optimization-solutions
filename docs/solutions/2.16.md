# Exercise 2.16: Partial sums of convex sets

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.16, p. 62](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=76).

Original solution.

Take two points $`(x,y)`$, $`(\widehat x,\widehat y)`$ in the partial sum, with witnesses $`y=y_1+y_2`$, $`\widehat y=\widehat y_1+\widehat y_2`$ and
$`(x,y_i),(\widehat x,\widehat y_i)\in S_i`$ for $`i=1,2`$. For $`t\in[0,1]`$, convexity of $`S_i`$ gives
```math
(tx+(1-t)\widehat x,\;ty_i+(1-t)\widehat y_i)\in S_i.
```
Adding the last coordinates of these two witnesses shows that
$`(tx+(1-t)\widehat x,ty+(1-t)\widehat y)`$ is in the partial sum. Thus the set is convex, including the vacuous empty case. Equivalently, it is the linear image of the convex set of triples $`(x,y_1,y_2)`$ satisfying both membership conditions.
