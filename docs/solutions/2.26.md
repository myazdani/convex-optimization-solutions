# Exercise 2.26: A closed convex set is determined by its support function

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.26, p. 63](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=77).

Original solution.

If $`C=D`$, the two defining suprema are equal. Conversely, assume their support functions agree, and suppose first that the sets are nonempty. If $`x\in C\setminus D`$, strict separation of the point $`x`$ from the closed convex set $`D`$ gives $`a\ne0`$ and a finite $`\beta`$ such that
```math
a^Tx>\beta\ge a^Td\qquad(d\in D).
```
Hence $`S_C(a)\ge a^Tx>\beta\ge S_D(a)`$, contradicting equality. Thus $`C\subseteq D`$; swapping them gives the reverse inclusion.

Equivalently every nonempty closed convex set has the representation
```math
C=\bigcap_{y\in\mathbb R^n}\{x:y^Tx\le S_C(y)\},
```
where a support value $`+\infty`$ imposes no restriction. If empty sets are admitted, use the usual extended-real convention $`\sup\varnothing=-\infty`$: their support function is identically $`-\infty`$, whereas a nonempty set has support value zero at $`y=0`$. This handles the empty cases as well.
