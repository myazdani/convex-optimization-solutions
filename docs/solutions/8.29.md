# Exercise 8.29: Outer polyhedral approximation using support functions

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.29, printed page 453. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=467).

Write $`s_i=S_C(a_i)=\sup_{z\in C}a_i^Tz`$ for each row of $`A`$. For $`t>0`$, the containment condition is equivalent to
```math
Az\le Ax+t b\quad(z\in C),
```
and hence to the finite affine inequalities $`s_i\le a_i^Tx+t b_i`$. The desired LP is therefore
```math
\text{minimize }t\quad\text{subject to }Ax+t b\ge s,\quad t\ge0.
```
Only the support values of the given set are needed; its convexity is irrelevant. A value $`s_i=+\infty`$ makes finite-scale containment impossible. For nonempty bounded $`P`$, this LP is exact at $`t=0`$ too: the constraints then say $`C-x\subseteq\{v:Av\le0\}=\mathrm{rec}(P)=\{0\}`$, precisely the singleton containment condition.

For an unbounded template the original definition of $`tP+x`$ needs a qualification at zero. The LP's zero-scale section instead tests containment in $`x+\mathrm{rec}(P)`$, which may be larger than $`\{x\}`$. Assume $`P`$ is nonempty. If a positive optimum results, it is exact. If the LP reaches zero and $`C`$ is a nonsingleton, the original problem has infimum zero but cannot attain it: for any $`u_0\in P`$, the LP pair $`(0,x)`$ can be changed to $`(\epsilon,x-\epsilon u_0)`$, since
```math
A(x-\epsilon u_0)+\epsilon b\ge Ax\ge s.
```
This gives feasible positive-scale covers converging in objective to zero. If $`C`$ is a singleton, a zero-scale copy at that point is valid. For example $`P=[0,\infty)`$, $`C=[1,2]`$ illustrates why zero scale cannot generally be treated as a recession cone. Empty $`C`$ is vacuous; an empty template cannot cover a nonempty set at any scale.
