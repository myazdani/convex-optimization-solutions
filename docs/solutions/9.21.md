# Exercise 9.21: Optimizing the stated Newton complexity bound

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.21, printed page 517. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=531).

Apart from the tolerance term, the coefficient in (9.56) is
```math
C(\alpha,\beta)=\frac{20-8\alpha}{\alpha\beta(1-2\alpha)^2},
\qquad0<\alpha<\tfrac12,\quad0<\beta<1.
```
For any fixed $`\alpha`$ it decreases strictly as $`\beta`$ increases. Thus the best possible coefficient is an infimum as $`\beta\uparrow1`$, not an attained minimum for the permitted backtracking parameter range.

At $`\beta=1`$ in this limiting calculation, the logarithmic derivative vanishes exactly when
```math
-\frac8{20-8\alpha}-\frac1\alpha+\frac4{1-2\alpha}=0
\quad\Longleftrightarrow\quad8\alpha^2-30\alpha+5=0.
```
Only $`\alpha_*=(15-\sqrt{185})/8\approx0.1748161864`$ lies in the allowed interval. The coefficient diverges at both interval endpoints, and there is only one interior stationary point, so this is the global minimizing $`\alpha`$. Substitution gives $`C_*=251.5636022058\ldots`$.

The infimum of the displayed bound is therefore
```math
C_*\bigl(f(x^{(0)})-p^\star\bigr)+\log_2\log_2(1/\epsilon),
```
with the same integer rounding convention as the original iteration bound. Choosing $`\beta`$ close to one approaches it. This optimizes the number-of-Newton-steps bound only; it ignores the additional line-search evaluations as $`\beta\uparrow1`$, so it is not a claim of best wall-clock parameters.
