# Exercise 2.6: Containment and equality of halfspaces

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.6, p. 60](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=74).

Original solution.

The inclusion holds exactly when there is a scalar $`\lambda>0`$ such that
```math
\widetilde a=\lambda a,\qquad \widetilde b\ge\lambda b.
```
Sufficiency follows by multiplying $`a^Tx\le b`$ by $`\lambda`$.

For necessity, choose a point $`x_0`$ with $`a^Tx_0=b`$. For any $`v\in\ker a^T`$, the entire line $`x_0+tv`$ is in the first halfspace; boundedness above of $`\widetilde a^T(x_0+tv)`$ for all real $`t`$ forces $`\widetilde a^Tv=0`$. Hence $`\widetilde a=\lambda a`$ for a nonzero scalar $`\lambda`$. The ray $`x_0-ta`$, $`t\ge0`$, forces $`\lambda>0`$, since a negative scalar would make $`\widetilde a^T(x_0-ta)`$ tend to $`+\infty`$. Evaluating at $`x_0`$ gives $`\widetilde b\ge\lambda b`$.

The halfspaces are equal exactly when $`\widetilde a=\lambda a`$ and $`\widetilde b=\lambda b`$ for some $`\lambda>0`$. If the latter inequality were strict, a point with $`a^Tx`$ strictly between $`b`$ and $`\widetilde b/\lambda`$ would belong only to the second halfspace.
