# Exercise 9.14: The logarithmic-composition rule

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.14, printed page 516. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=530).

On the specified domain put $`a=-g(x)>0`$. Direct differentiation gives
```math
f''=\frac{g''}{a}+\frac{(g')^2}{a^2}+\frac1{x^2}>0,
\qquad
f'''=\frac{g'''}a+\frac{3g'g''}{a^2}+\frac{2(g')^3}{a^3}-\frac2{x^3}.
```
Convexity of $`g`$ gives $`g''\ge0`$. Define the nonnegative normalized quantities
```math
p=\frac{\sqrt{g''/a}}{\sqrt{f''}},\qquad
q=\frac{|g'|/a}{\sqrt{f''}},\qquad
r=\frac{1/x}{\sqrt{f''}}.
```
They satisfy $`p^2+q^2+r^2=1`$. The assumed third-derivative bound implies
```math
\frac{|f'''|}{2(f'')^{3/2}}
\le\frac32rp^2+\frac32p^2q+q^3+r^3\le1,
```
where the last step is exactly the elementary inequality supplied in the exercise. Hence $`|f'''|\le2(f'')^{3/2}`$, proving self-concordance. The domain is an interval because it is the intersection of the positive halfline and a strict sublevel set of convex $`g`$; this checks the convex-domain requirement as well as the derivative inequality.
