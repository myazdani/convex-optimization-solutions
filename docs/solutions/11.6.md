# Exercise 11.6: General scalar barriers and their duality gaps

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 11.6, printed page 624. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=638).

As in the original convex problem, assume all $`f_i`$, including $`f_0`$, are convex and twice differentiable. Let $`x=x_*(t)`$ be an existing strictly feasible center.

## (a) Convexity
A convex nondecreasing function composed with a convex function is convex. More explicitly,
```math
\nabla^2 h(f_i(x))
=h''(f_i)\nabla f_i\nabla f_i^T+h'(f_i)\nabla^2f_i\succeq0,
```
since $`h'',h'\ge0`$. Summing and adding $`tf_0`$ proves the claim. The strict feasible domain is convex.

## (b) Dual point and gap
Set $`\lambda_i=h'(f_i(x))/t\ge0`$. Centering stationarity reads
```math
\nabla f_0(x)+\sum_i\lambda_i\nabla f_i(x)=0.
```
The convex Lagrangian is therefore minimized at $`x`$, giving a finite dual value $`g(\lambda)=f_0(x)+\sum_i\lambda_i f_i(x)`$. Its primal-dual gap is
```math
f_0(x)-g(\lambda)=-\frac1t\sum_i f_i(x)h'(f_i(x)).
```
For the inverse barrier $`h(u)=-1/u`$, this equals $`\tfrac1t\sum_i1/(-f_i(x))`$, so it depends on the actual slacks.

## (c) A problem-independent gap
To depend only on $`t,m`$ for every problem, the scalar function $`-u h'(u)`$ must be constant on $`u<0`$. Necessity can already be tested with one constant constraint $`f_1(x)=u<0`$ and a strictly convex unconstrained objective: any chosen negative slack can occur at its center. Write the constant as $`c`$. Integrating $`h'(u)=-c/u`$ gives
```math
h(u)=-c\log(-u)+d.
```
Convexity and monotonicity require $`c\ge0`$, and closedness with blow-up at zero excludes $`c=0`$, so $`c>0`$. Conversely every such logarithmic barrier gives the gap $`cm/t`$. The additive constant has no effect on centering or the dual variables.
