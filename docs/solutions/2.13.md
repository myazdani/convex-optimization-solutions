# Exercise 2.13: Conic hull of fixed-rank positive semidefinite matrices

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.13, p. 61](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=75).

Original solution.

For $`1\le k\le n`$, the answer is
```math
\{0\}\ \cup\ \{Y\in\mathbb S_+^n:\mathrm{rank}\,Y\ge k\}.
```
First, every generator $`XX^T`$ is positive semidefinite and has rank $`k`$. In a sum of positive semidefinite matrices, the nullspace is the intersection of their nullspaces: if $`v^T\sum_jY_jv=0`$, every nonnegative summand $`v^TY_jv`$ is zero, which for a positive semidefinite matrix implies $`Y_jv=0`$. Hence every nonzero conic combination has rank at least $`k`$.

Conversely, let $`Y=\sum_{i=1}^r\lambda_iq_iq_i^T`$ with $`r\ge k`$, $`\lambda_i>0`$, and orthonormal $`q_i`$. For each $`k`$-element subset $`J\subseteq\{1,\ldots,r\}`$, define $`Y_J=\sum_{i\in J}\lambda_iq_iq_i^T`$. It is a rank-$`k`$ outer product, using columns $`\sqrt{\lambda_i}q_i`$. Each eigencomponent occurs in exactly $`\binom{r-1}{k-1}`$ subsets, so
```math
Y=\binom{r-1}{k-1}^{-1}\sum_{|J|=k}Y_J.
```
This is a conic combination. Zero is obtained with all weights zero. Thus the description is exact, and for $`k>1`$ it need not be closed. For $`k=0`$ the sole outer product is zero; for $`k>n`$ no rank-$`k`$ generator exists (with the empty-combination convention its conic hull is $`\{0\}`$).
