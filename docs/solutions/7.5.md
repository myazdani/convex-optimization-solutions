# Exercise 7.5: Markov transition estimation

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 7.5, printed page 394. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=408).

Condition on the observed initial state. Let
```math
N_{ij}=\#\{t\in\{1,\ldots,N-1\}:k_t=j,\ k_{t+1}=i\},
\qquad N_j=\sum_iN_{ij}.
```
Only departure times through $`N-1`$ count in the denominator; the final state supplies no outgoing observation. The conditional log likelihood is $`\sum_{ij}N_{ij}\log P_{ij}`$, with $`0\log0=0`$ and a positive count at zero probability assigned value $`-\infty`$.

## (a) Empirical transitions
For a column with $`N_j>0`$ put $`r_i=N_{ij}/N_j`$. For any probability column $`p`$,
```math
\sum_iN_{ij}\log p_i=\sum_iN_{ij}\log r_i
-N_j\sum_{i:r_i>0}r_i\log\frac{r_i}{p_i}.
```
The last divergence is nonnegative: apply $`\log t\le t-1`$ to $`p_i/r_i`$ and sum, including the fact that any mass outside the positive support reduces its sum. Equality requires $`p=r`$. Therefore $`\hat P_{ij}=N_{ij}/N_j`$. When $`N_j=0`$, the likelihood is independent of column $`j`$, so any probability column is optimal.

## (b) Known equilibrium distribution
Maximize the same concave log likelihood subject to
```math
P\ge0,\quad\mathbf1^TP=\mathbf1^T,\quad Pq=q.
```
All constraints are affine. Equivalently minimize its negative, a convex optimization problem. Zero coordinates of $`q`$ and zero observed counts are handled by these constraints and the extended-value convention; if they force a positive-count transition to have zero probability, the model assigns the observed sequence probability zero. This uses a known stationary distribution, not an assumption that an unconditioned unknown initial-state law can be ignored.
