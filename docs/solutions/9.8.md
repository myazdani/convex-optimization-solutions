# Exercise 9.8: Steepest descent in the infinity norm

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.8, printed page 515. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=529).

With $`g=\nabla f(x)`$, the normalized subproblem is $`\min g^Tv`$ subject to $`|v_i|\le1`$. It separates by coordinate: choose
```math
v_i=-\mathrm{sign}(g_i)\quad(g_i\ne0),
```
and any $`v_i\in[-1,1]`$ for a zero gradient coordinate. Its directional derivative is $`-\sum_i|g_i|=-\|g\|_1`$, consistent with the one-norm as dual of the infinity norm. An unnormalized steepest direction is $`-\|g\|_1\mathrm{sign}(g)`$, using zero in zero coordinates if desired.

Thus all coordinates with nonzero gradient move with equal magnitude, opposite to their partial derivative signs. The direction uses signs rather than relative gradient magnitudes; line search chooses the common scale. When the whole gradient is zero, the unnormalized direction is zero and the algorithm should stop.
