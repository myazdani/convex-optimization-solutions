# Exercise 9.18: Quadratic contraction of the Newton decrement

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.18, printed page 517. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=531).

Let $`H=\nabla^2f(x)\succ0`$, $`g=\nabla f(x)`$, $`h=-H^{-1}g`$, and $`\lambda=\sqrt{h^THh}<1`$. Assume the full Newton segment lies in the domain, as guaranteed for a closed self-concordant function by the Dikin-ellipsoid property. We address the missing-domain qualification below.

Normalize coordinates so that $`H=I`$. Exercise 9.17 gives, for $`0\le t\le1`$,
```math
(1-t\lambda)^2 I\preceq H(x+th)\preceq(1-t\lambda)^{-2}I.
```
Since $`g+h=0`$, integration of the gradient along the segment yields
```math
\nabla f(x+h)=\int_0^1(H(x+th)-I)h\,dt.
```
The spectral norm of the integrand matrix is at most $`(1-t\lambda)^{-2}-1`$, as this exceeds $`1-(1-t\lambda)^2`$. Consequently
```math
\|\nabla f(x+h)\|_2
\le\lambda\int_0^1[(1-t\lambda)^{-2}-1]dt
=\frac{\lambda^2}{1-\lambda}.
```
Also $`H(x+h)^{-1}\preceq(1-\lambda)^{-2}I`$. Combining the two inequalities gives
```math
\lambda(x+h)\le\frac{\lambda^2}{(1-\lambda)^2}.
```
This is coordinate invariant, so it proves the desired result for the original $`H`$ as well. The case $`\lambda=0`$ is stationary and immediate.

Self-concordance as only a local derivative inequality does not force the full step to stay in an arbitrarily restricted domain. For example $`f(s)=s^2/2`$ restricted to $`(0.1,0.3)`$ is strictly convex and self-concordant, but at $`s=0.2`$ its decrement is below one and its Newton point zero is outside. Thus either closedness (as in the chapter's convergence setting) or explicit feasibility of $`x+h`$ is necessary. For a closed self-concordant function, the Hessian upper bound integrates to a finite function upper bound all the way to any putative domain boundary at local norm below one; closedness forbids such a finite-valued boundary exit, proving the needed segment inclusion.
