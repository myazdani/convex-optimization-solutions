# Exercise 9.29: Arrowhead elimination for two-stage optimization

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.29, printed page 519. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=533).

Exercise 4.64 has first-stage $`x\in\mathbb R^n`$, scenario variables $`z_i\in\mathbb R^q`$, and objective $`\sum_i\pi_i f(x,z_i,i)`$. Remove zero-probability scenarios, whose variables do not affect the objective. At a Newton iterate define
```math
A=\sum_i\pi_i f_{xx}^{(i)},\qquad
B_i=\pi_i f_{xz}^{(i)},\qquad C_i=\pi_i f_{zz}^{(i)},
```
and partition the gradient as $`g_x,g_i`$. The Hessian has arrowhead form: diagonal blocks $`A,C_1,\ldots,C_S`$, cross-blocks $`B_i`$ between $`x`$ and $`z_i`$, and zero coupling between different scenario variables.

Assume the full Newton Hessian is positive definite, which in particular makes every $`C_i`$ and its Schur complement positive definite. Factor the $`C_i`$ independently, form
```math
M=A-\sum_iB_iC_i^{-1}B_i^T,
\qquad r=-g_x+\sum_iB_iC_i^{-1}g_i,
```
solve $`M\Delta x=r`$, then recover
```math
\Delta z_i=-C_i^{-1}(g_i+B_i^T\Delta x).
```
These identities follow directly by eliminating each scenario row of the block Newton equations, so the result is the exact Newton step. All inverse symbols represent factored solves.

Dense arithmetic within the individual blocks costs
```math
O\bigl(Sq^3+Snq^2+Sn^2q+n^3\bigr),
```
including scenario factorizations, cross solves, Schur assembly, and the common factorization. For fixed $`n,q`$ this is linear in the number of scenarios; a dense unstructured factorization of dimension $`n+Sq`$ costs $`O((n+Sq)^3)`$, cubic in $`S`$. Scenario work is also parallelizable and can be streamed to reduce memory. If the objective is merely convex and its Hessian singular, the basic unique Newton step is not defined; regularization or a reduced formulation is needed, with the same arrowhead structure available afterward.
