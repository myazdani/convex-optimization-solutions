# Exercise 11.2: A centering problem with no minimizer

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 11.2, printed page 623. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=637).

The strict domain is $`x_2>0,x_1<x_2`$, and the logarithmic centering objective is
```math
F_t(x)=t x_2-\log(x_2-x_1)-\log x_2.
```
For any fixed $`x_2>0`$, sending $`x_1\to-\infty`$ makes $`F_t\to-\infty`$. Hence no centering minimizer exists for any $`t>0`$, and there is no central path of exact minimizers. Indeed $`\partial F_t/\partial x_1=1/(x_2-x_1)>0`$, so stationarity is impossible.

The original LP nevertheless has optimal value zero, attained at every $`(x_1,0)`$ with $`x_1\le0`$. It is the unbounded slack in a direction of constant objective that defeats the barrier method as stated: the barrier rewards sending that slack to infinity. A boundedness/existence assumption for the centering problems is therefore substantive. For example an added lower bound on $`x_1`$ that preserves an LP optimum would remove this particular escape direction, but it is an additional constraint, not something the original algorithm may silently assume.
