# Exercise 4.8: Explicit solutions of elementary linear programs

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.8](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=206). The source exercise and all of its subparts were checked directly.

## (a) Affine feasible set

If $`b\notin\mathrm{range}(A)`$, the problem is infeasible and its value is $`+\infty`$. Otherwise choose $`x^0`$ with $`Ax^0=b`$. Every feasible point is $`x^0+v`$ for $`v\in\ker A`$. If $`c\perp\ker A`$, equivalently $`c=A^Ty`$ for some $`y`$, the objective is the constant $`c^Tx^0=y^Tb`$, and every feasible point is optimal. Otherwise select a null vector with $`c^Tv<0`$ by changing its sign if needed; the ray $`x^0+tv`$ proves value $`-\infty`$ and no optimizer.

## (b) Halfspace

A finite optimum is possible exactly when $`c=-\lambda a`$, $`\lambda\ge0`$. In that case $`c^Tx\ge-\lambda b`$. If $`\lambda>0`$, every boundary point $`a^Tx=b`$ is optimal with value $`-\lambda b`$; if $`c=0`$, all feasible points are optimal with value zero. Otherwise, if $`c`$ has a component perpendicular to $`a`$, moving opposite that component is an improving feasible ray. If it has no such component, it is a positive multiple of $`a`$, and moving along $`-a`$ proves unboundedness.

## (c) Rectangle

Independence of coordinates gives

```math
x_i^\star=\begin{cases}l_i&c_i>0,\\u_i&c_i<0,\\\text{any point of }[l_i,u_i]&c_i=0,\end{cases}
\qquad
p^\star=\sum_i\min(c_il_i,c_iu_i).
```

These choices describe the entire optimal set, including degenerate intervals.

## (d) Simplex and optional investment

Let $`c_{\min}=\min_i c_i`$. On the simplex the objective is a convex combination of the coefficients, hence the value is $`c_{\min}`$. Exactly the distributions supported on the indices with $`c_i=c_{\min}`$ are optimal.

With total mass at most one, introduce the uninvested mass as an extra coordinate with cost zero. The value becomes $`\min(0,c_{\min})`$. If $`c_{\min}<0`$, invest all mass in minimum-cost indices. If $`c_{\min}>0`$, the unique optimum is zero. If $`c_{\min}=0`$, any mass from zero to one supported on zero-cost indices is optimal.

## (e) Unit capacities and total budget

Order the coefficients $`c_{(1)}\le\cdots\le c_{(n)}`$. For $`0\le\alpha<n`$, put $`k=\lfloor\alpha\rfloor`$ and $`\theta=\alpha-k`$. One optimizer fills the first $`k`$ coordinates to one, sets the next to $`\theta`$, and sets the others to zero, giving

```math
p^\star=\sum_{j=1}^k c_{(j)}+\theta c_{(k+1)}.
```

For $`\alpha=n`$ all coordinates equal one. Integer $`\alpha`$ has no fractional coordinate. To prove optimality, if a more expensive coordinate has positive mass while a cheaper one has unused capacity, move the smaller of these amounts to the cheaper coordinate. The objective decreases strictly unless the costs tie. Repeating this exchange gives the displayed allocation. All optimizers satisfy this no-improving-exchange condition, allowing arbitrary allocation among equal-cost boundary coordinates.

For budget at most $`\alpha`$, fill negative-cost coordinates in the same order until the budget is exhausted or all negative coordinates are full. Zero-cost coordinates may use any leftover budget, and positive-cost coordinates receive zero. This includes $`\alpha=0`$ and all ties.

## (f) Weighted budget

Put $`z_i=d_ix_i`$ and $`r_i=c_i/d_i`$. The problem becomes $`\min\sum_i r_i z_i`$ with $`0\le z_i\le d_i`$ and $`\sum_i z_i=\alpha`$. Order by increasing $`r_i`$. Fill the capacities $`d_i`$ in that order; if $`D_k=\sum_{j=1}^k d_{(j)}\le\alpha<D_{k+1}`$, take

```math
z_{(j)}=d_{(j)}\ (j\le k),\quad
z_{(k+1)}=\alpha-D_k,\quad z_{(j)}=0\ (j>k+1),
```

then recover $`x_i=z_i/d_i`$. The value is $`\sum_{j\le k}c_{(j)}+(\alpha-D_k)r_{(k+1)}`$. At the full budget all coordinates are one. The same exchange proof, now moving units of weighted budget, proves optimality. Tied ratios admit redistribution within their capacities and describe all remaining nonuniqueness.

## Validation

Infeasibility, unboundedness, zero costs, ties, noninteger budgets, and both endpoints of each budget interval are included. All finite box/simplex cases attain their values by compactness.
