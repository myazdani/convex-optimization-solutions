# Exercise 6.8: Finite, interval, and polyhedral robust fitting

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 6.8, printed page 346. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=360).

The vector $`b`$ is fixed. All formulations below are exact; independence of uncertain rows is essential in (b),(c).

## (a) Finite scenarios
Introduce $`r_j=A_jx-b`$. For the one-norm use nonnegative $`u_{ji}\ge\pm(r_j)_i`$ and minimize $`\sum_jp_j\sum_i u_{ji}`$, an LP. For the infinity norm use $`t_j\ge\pm(r_j)_i`$ and minimize $`\sum_jp_jt_j`$, also an LP. For the two-norm minimize the same weighted sum subject to $`\|r_j\|_2\le t_j`$, an SOCP. The epigraph variables attain the norm whenever their weight is positive; zero-weight scenarios can be omitted.

## (b) Independent coefficient intervals
Let $`C=(L+U)/2`$ and $`R=(U-L)/2`$, so $`R_{ij}>0`$. For fixed $`x`$, the possible residual in row $`i`$ is the interval centered at $`(Cx-b)_i`$ with radius $`(R|x|)_i`$. Its largest magnitude is
```math
s_i(x)=|(Cx-b)_i|+(R|x|)_i.
```
Each row can choose its own endpoint, simultaneously realizing all $`s_i(x)`$. Monotonicity of all three norms on nonnegative vectors proves $`\sup_A\|Ax-b\|_p=\|s(x)\|_p`$.

Represent this by $`u\ge x,u\ge-x`$ and
```math
s\ge Cx-b+Ru,\qquad s\ge-Cx+b+Ru.
```
Minimize $`\mathbf1^Ts`$ for $`p=1`$, minimize $`t`$ with $`s\le t\mathbf1`$ for $`p=\infty`$, or minimize $`t`$ with $`\|s\|_2\le t`$ for $`p=2`$. The first two are LPs and the third an SOCP. Because $`R\ge0`$, slack in $`u`$ cannot improve the objective, so the representation is exact.

## (c) Independent row polyhedra
Define
```math
s_i(x)=\max\left\{\sup_{C_i a\le d_i}(a^Tx-b_i),
\sup_{C_i a\le d_i}(-a^Tx+b_i)\right\}.
```
Nonempty bounded row sets make these maxima finite and attained. As in (b), independent row choices imply the worst-case norm is $`\|s(x)\|_p`$. Linear-programming duality represents $`s_i\ge s_i(x)`$ exactly through
```math
\begin{aligned}
&C_i^T\lambda_i^+=x,\quad\lambda_i^+\ge0,
&&d_i^T\lambda_i^+-b_i\le s_i,\\
&C_i^T\lambda_i^-=-x,\quad\lambda_i^-\ge0,
&&d_i^T\lambda_i^-+b_i\le s_i.
\end{aligned}
```
The bounded primal LPs have attained dual optima, so this is both necessary and sufficient, even if a row polyhedron is lower dimensional. Use the same three objectives/epigraphs as in (b), giving respectively LP, SOCP, and LP formulations.
