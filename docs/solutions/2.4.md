# Exercise 2.4: The hull as the smallest convex superset

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.4, p. 60](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=74).

Original solution.

Let $`H`$ be the set of finite convex combinations of points of $`S`$. It contains $`S`$ by taking one point with weight one. It is convex because a convex combination of two finite convex combinations is another finite convex combination: multiply their respective weights by $`t`$ and $`1-t`$ and concatenate the lists.

Every convex set containing $`S`$ contains each finite convex combination of its points, by Exercise 2.1, so it contains $`H`$. Therefore $`H`$ is contained in the intersection $`I`$ of all convex supersets of $`S`$. On the other hand, $`H`$ is itself one such superset, so $`I\subseteq H`$. Consequently $`I=H=\mathrm{conv}\,S`$. When $`S=\varnothing`$, both sides are empty, using the empty convex superset.

The same argument works with finite nonnegative combinations, affine combinations, or unrestricted linear combinations, respectively, because each corresponding class is closed under its defining combination operation.
