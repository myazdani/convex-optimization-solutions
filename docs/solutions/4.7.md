# Exercise 4.7: Convex fractional reformulations

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.7](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=205). The source exercise and all of its subparts were checked directly.

## (a) Positive affine denominator

On the convex domain $`c^Tx+d>0`$, the sublevel inequality at any real level $`\alpha`$ is

```math
f_0(x)-\alpha(c^Tx+d)\le0.
```

Its left side is convex, so every sublevel set is convex. Together with the convex inequalities and affine equations this is a quasiconvex problem. Nonnegativity of the numerator is not needed for an affine denominator.

## (b) Perspective transformation

Use

```math
t=\frac1{c^Tx+d}>0,\qquad y=tx,\qquad g_i(y,t)=t f_i(y/t).
```

The perspective domain includes $`t>0`$ and $`y/t\in\mathrm{dom}(f_i)`$. Multiplication by positive $`t`$ turns each original inequality into $`g_i(y,t)\le0`$, and the equations become $`Ay=bt`$ and $`c^Ty+dt=1`$. The objective becomes $`g_0(y,t)`$ exactly. Conversely these equations and $`t>0`$ imply $`c^T(y/t)+d=1/t>0`$, and $`x=y/t`$ is original-feasible with the same objective. These maps are inverse bijections on feasible sets. Perspective functions are convex; the remaining constraints are affine. Thus this is a convex problem with identical infimum and corresponding optimizers, including when the infimum is unattained. One must not silently allow $`t=0`$ through a closed-perspective extension.

## (c) Positive concave denominator

Let $`H(y,t)=t h(y/t)`$, the concave perspective. An equivalent convex problem is

```math
\begin{aligned}
\mathrm{minimize}\quad &t f_0(y/t)\\
\mathrm{subject\ to}\quad &t f_i(y/t)\le0,\quad i=1,\ldots,m,\\
&Ay=bt,\qquad H(y,t)\ge1,\qquad t>0.
\end{aligned}
```

All perspective domains must hold. The superlevel inequality for $`H`$ is convex. From an original feasible $`x`$, take $`t=1/h(x)`$, $`y=tx`$; the lifted objective equals the ratio. From a lifted feasible point put $`x=y/t`$. Then $`h(x)\ge1/t>0`$, so, using the assumed $`f_0(x)\ge0`$,

```math
\frac{f_0(x)}{h(x)}\le t f_0(x).
```

These two constructions prove equal infima and recover an original optimizer from any lifted optimizer. Any original optimizer has the normalized optimal lift. A lift with slack $`H>1`$ need not be normalized when the optimal numerator is zero, but recovery is still valid.

For the matrix example put $`G=tF_0+\sum_j y_jF_j=tF(y/t)`$. The formulation is

```math
\begin{aligned}
\mathrm{minimize}\quad &\mathrm{tr}(G)/m\\
\mathrm{subject\ to}\quad &(\det G)^{1/m}\ge1,\\
&G=tF_0+\sum_jy_jF_j,\qquad G\succ0,\qquad t>0.
\end{aligned}
```

The determinant root is concave on the positive semidefinite cone, so its superlevel constraint is convex. Positive definiteness is necessary for the original domain (and follows if the determinant-root constraint is interpreted on that cone). The arithmetic–geometric mean inequality gives objective at least one, but does not guarantee that a scalar multiple of the identity is available in this affine family or that the infimum is attained.

## Validation

Both directions of both transformations preserve feasibility; sign and strict-domain assumptions were retained. The nonnegative-numerator assumption is used only where an inequality, rather than an exact denominator normalization, is introduced.
