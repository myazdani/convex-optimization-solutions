# Exercise 4.13: Robust linear inequalities with interval coefficients

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.13](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=207). The source exercise and all of its subparts were checked directly.

For the stated uncertainty intervals to be nonempty, assume $`V_{ij}\ge0`$. For any fixed $`x`$, independently maximizing each coefficient in row $`i`$ gives

```math
\sup_{A\in\mathcal A}(Ax)_i
=\bar a_i^Tx+\sum_jV_{ij}|x_j|.
```

An attaining row chooses the upper endpoint when $`x_j\ge0`$ and the lower endpoint when $`x_j<0`$. Because all rows and entries vary independently, the robust inequalities are equivalent to $`\bar A x+V|x|\preceq b`$.

Introduce $`t\in\mathbb R^n`$ to obtain the LP

```math
\begin{aligned}
\mathrm{minimize}\quad &c^Tx\\
\mathrm{subject\ to}\quad &\bar A x+Vt\preceq b,\\
&-t\preceq x\preceq t.
\end{aligned}
```

A robust-feasible $`x`$ lifts with $`t=|x|`$. Conversely the last inequalities give $`t\succeq|x|`$, and entrywise nonnegativity of $`V`$ implies $`\bar A x+V|x|\preceq\bar A x+Vt\preceq b`$. The original and lifted feasible sets therefore project exactly onto one another, with the same objective and corresponding optimizers. The LP has $`2n`$ variables and $`m+2n`$ scalar inequalities, rather than enumerating exponentially many uncertainty corners.

If an alleged interval has negative width, the uncertainty set is empty and the universal constraint is vacuous; that degenerate input must be treated separately, not inserted into the nonnegative-width derivation.

## Validation

The entrywise sign of $`V`$ is essential to the reverse implication. No sign restriction on $`x`$ or on the nominal matrix was imposed.
