# Exercise 8.23: Margin maximization and the hard-margin quadratic program

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.23, printed page 451. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=465).

The margin problem (8.23) maximizes $`t`$ under
```math
a^Tx_i-b\ge t,\quad a^Ty_j-b\le-t,\quad\|a\|_2\le1.
```
Assume both finite classes are nonempty.

## (a) Separation and normalization
If $`t_*>0`$, the optimizing affine function strictly separates the classes. Conversely, if an affine function strictly separates them, the minimum of its finitely many signed gaps is positive. Its nonzero normal can be scaled to unit norm, giving a feasible positive margin; hence $`t_*>0`$. Thus “separated” here must mean strict linear separation, rather than allowing points of both classes on the same hyperplane.

For a positive optimum, $`a_*\ne0`$. If $`\|a_*\|<1`$, divide $`a_*,b_*,t_*`$ by $`\|a_*\|`$ to preserve all linear inequalities and increase the margin, a contradiction. Therefore $`\|a_*\|=1`$.

## (b) Reciprocal norm formulation
For any feasible positive margin define $`\widetilde a=a/t,\ \widetilde b=b/t`$. Then the signed gaps are at least one, and $`\|\widetilde a\|\le1/t`$. Conversely any feasible unit-gap pair has $`\widetilde a\ne0`$ and produces
```math
a=\frac{\widetilde a}{\|\widetilde a\|},\qquad
b=\frac{\widetilde b}{\|\widetilde a\|},\qquad
t=\frac1{\|\widetilde a\|}.
```
These two maps prove that minimizing $`\|\widetilde a\|`$ under the displayed unit-gap inequalities is equivalent, with optimal values $`t_*=1/\|\widetilde a_*\|`$. Replacing the objective by $`\tfrac12\|\widetilde a\|^2`$ makes it literally a QP with the same minimizers. If the classes are not strictly separable, this QP is infeasible and the original optimal margin is zero (the zero affine function is feasible).
