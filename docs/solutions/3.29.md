# Exercise 3.29: A convex piecewise-affine function is a maximum

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.29, p. 119](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=133).

Original solution.

Fix a piece $`X_i`$ and choose $`x_i\in\mathrm{int}\,X_i`$. In a neighborhood of $`x_i`$, $`f(x)=a_i^Tx+b_i`$, so $`f`$ is differentiable there with gradient $`a_i`$. The first-order inequality for a convex function with full domain yields, for every $`z`$,
```math
f(z)\ge f(x_i)+a_i^T(z-x_i)=a_i^Tz+b_i.
```
Thus each listed affine piece is a global minorant, and $`f(z)\ge\max_i(a_i^Tz+b_i)`$. Conversely the pieces cover all of space, so for each $`z`$ at least one index $`j`$ satisfies $`z\in X_j`$ and $`f(z)=a_j^Tz+b_j`$. Hence $`f(z)\le\max_i(a_i^Tz+b_i)`$. The two inequalities prove equality. Boundary overlaps, identical pieces, and redundant affine functions do not change the argument.
