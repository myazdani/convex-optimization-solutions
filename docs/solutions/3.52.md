# Exercise 3.52: Log-convexity of moments and the gamma function

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.52, p. 123](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=137).

Original solution.

Assume $`f`$ is measurable so that the displayed integrals are defined. Use the nonnegative measure $`d\mu(u)=f(u)\,du`$ on $`[0,\infty)`$. For $`x,y\ge0`$ and $`0<\theta<1`$, Hölder's inequality with exponents $`1/\theta`$ and $`1/(1-\theta)`$ gives
```math
\begin{aligned}
\phi(\theta x+(1-\theta)y)
&=\int (u^x)^\theta(u^y)^{1-\theta}\,d\mu(u)\\
&\le\left(\int u^x\,d\mu(u)\right)^\theta
\left(\int u^y\,d\mu(u)\right)^{1-\theta}\\
&=\phi(x)^\theta\phi(y)^{1-\theta}.
\end{aligned}
```
Endpoint weights are immediate. This is log-convexity. In particular the finite-integral domain is convex; on it the logarithm is convex whenever the integrals are positive. If the measure is zero the function is identically zero and satisfies the nonnegative log-convexity inequality; divergent moments are interpreted as extended values. The value assigned to $`0^0`$ does not affect this Lebesgue integral.

For $`f(u)=e^{-u}`$, the integral is finite and positive for every nonnegative exponent, and $`\phi(s)=\Gamma(s+1)`$. Therefore $`\Gamma(x)`$ is log-convex for $`x\ge1`$, since translation of the argument preserves log-convexity.
