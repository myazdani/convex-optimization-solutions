# Exercise 2.38: Barrier, recession, and normal cones

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.38, p. 66](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=80).

Original solution.

## (a) Barrier cone

If $`y_1^Tx\le M_1`$ and $`y_2^Tx\le M_2`$ on $`C`$, then for $`\alpha,\beta\ge0`$,
$`(\alpha y_1+\beta y_2)^Tx\le\alpha M_1+\beta M_2`$. Thus the barrier cone is closed under nonnegative combinations and contains zero. This argument requires no convexity or closure of $`C`$. For empty $`C`$, the bound is vacuous and the barrier cone is all of space.

## (b) Recession cone with the book's minus-sign convention

Let $`R(C)=\{y:x-ty\in C\text{ for every }x\in C,t\ge0\}`$. Zero belongs. Positive scaling is immediate. If $`y,z\in R(C)`$, first move from $`x`$ to $`x-ty\in C`$ and then to $`x-ty-tz\in C`$. Hence $`y+z\in R(C)`$. In fact this proves the cone property even without convexity; in particular it proves the requested result for convex $`C`$.

Now suppose $`C`$ is nonempty, closed, and convex, and write $`B(C)`$ for its barrier cone. If $`y\in R(C)`$ and $`a\in B(C)`$, then
```math
a^T(x-ty)=a^Tx-t a^Ty\le S_C(a)<+\infty\qquad(t\ge0).
```
This is impossible for $`a^Ty<0`$, so $`y\in B(C)^*`$.

Conversely, suppose $`y\in B(C)^*`$, $`x\in C`$, and $`t\ge0`$. For every $`a\in B(C)`$,
```math
a^T(x-ty)\le a^Tx\le S_C(a).
```
A nonempty closed convex set is the intersection of its supporting halfspaces with finite support values (strict separation excludes every outside point). Therefore $`x-ty\in C`$. This proves $`R(C)=B(C)^*`$. The sign is positive duality because the exercise defines recession directions using $`x-ty`$.

## (c) Normal cone and its polyhedral form

For arbitrary $`C`$,
```math
N_C(x_0)=\bigcap_{x\in C}\{y:y^T(x-x_0)\le0\}
```
is a closed convex cone. For $`P=\{x:Ax\le b\}`$ and $`x_0\in P`$, let $`I=\{i:a_i^Tx_0=b_i\}`$ be the active indices. Then
```math
N_P(x_0)=\left\{\sum_{i\in I}\lambda_i a_i:\lambda_i\ge0\right\}.
```
Every such combination is normal by summing the active inequalities. Conversely suppose $`y`$ is outside this finitely generated, hence closed, cone. Separation from it gives a direction $`d`$ with $`a_i^Td\le0`$ for all active indices and $`y^Td>0`$. All inactive constraints have strictly positive slack; because there are finitely many, $`x_0+\epsilon d\in P`$ for sufficiently small $`\epsilon>0`$. Then $`y^T(x_0+\epsilon d-x_0)>0`$, so $`y`$ is not normal. This proves equality, including redundant constraints and lower-dimensional polyhedra.
