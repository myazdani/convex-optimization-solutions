# Exercise 3.57: Matrix convexity of the inverse

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.57, p. 124](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=138).

Original solution.

A symmetric-matrix inequality is equivalent to its scalar quadratic-form inequalities for every vector $`v`$. Fix such a vector. On $`X\succ0`$,
```math
v^TX^{-1}v=\sup_z\{2v^Tz-z^TXz\}.
```
Completing the square, or differentiating in $`z`$, proves equality with maximizer $`z=X^{-1}v`$. For fixed $`z`$ the maximand is affine in $`X`$, so this is a convex scalar function of $`X`$.

Therefore for $`X,Y\succ0`$ and $`0\le\theta\le1`$,
```math
v^T(\theta X+(1-\theta)Y)^{-1}v
\le v^T\bigl(\theta X^{-1}+(1-\theta)Y^{-1}\bigr)v
```
for every $`v`$. The quadratic-form characterization of semidefinite order gives
```math
(\theta X+(1-\theta)Y)^{-1}
\preceq\theta X^{-1}+(1-\theta)Y^{-1}.
```
This is matrix convexity. No simultaneous diagonalization or commutativity assumption is used.
