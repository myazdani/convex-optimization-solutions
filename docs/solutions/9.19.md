# Exercise 9.19: Attainment and distance from the optimum

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.19, printed page 517. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=531).

Write $`\|v\|_x=\sqrt{v^T\nabla^2f(x)v}`$. Strict convexity and self-concordance make this a norm.

## (a) Decrement below one
Let $`x=\bar x`$ and $`\lambda=\lambda(x)<1`$. For any domain point $`y=x+h`$, set $`r=\|h\|_x`$. Along its segment, the reciprocal-curvature inequality gives
```math
\frac{d^2}{dt^2}f(x+th)\ge\frac{r^2}{(1+tr)^2},\qquad0\le t\le1.
```
Also $`\nabla f(x)^Th\ge-\lambda r`$. Integrating twice gives
```math
f(y)\ge f(x)-\lambda r+r-\log(1+r).
```
The right side tends to infinity as $`r\to\infty`$ because $`\lambda<1`$. Thus the given closed sublevel set is bounded, hence compact. Continuity on the domain and closedness of that sublevel set give an attained minimum $`x_*`$ in it. Since the differentiable domain is open, stationarity holds at $`x_*`$.

Apply the first integrated derivative bound along the segment from $`x`$ to $`x_*`$:
```math
0=\nabla f(x_*)^T(x_*-x)
\ge-\lambda r+\frac{r^2}{1+r}.
```
If $`r>0`$, division gives $`r/(1+r)\le\lambda`$, or $`r\le\lambda/(1-\lambda)`$. The same result holds trivially at $`r=0`$. This is the requested local-norm distance bound.

## (b) Bounded below and one closed sublevel set
Start at a point defining the nonempty closed sublevel set and use the damped Newton step $`h/(1+\lambda)`$. Integration of the self-concordant Hessian upper bound gives
```math
f\left(x+\frac h{1+\lambda}\right)
\le f(x)-\lambda+\log(1+\lambda).
```
All these damped steps are in the domain and the initial closed sublevel set: along the proposed step the same upper bound ensures nonincrease, and a hypothetical finite boundary exit would have a finite function bound, contradicting closedness of that sublevel set. This is the closed-sublevel version of the usual Dikin-step argument.

If every iterate had $`\lambda\ge1`$, each step would decrease the objective by at least $`1-\log2>0`$, contradicting boundedness below. Thus some iterate has decrement below one. Its own sublevel set is closed: a convergent sequence in it lies in the original closed sublevel set, whose limit is in the domain, where continuity preserves the smaller level bound. Part (a) now gives attainment. The argument proves existence; it does not assume convergence of an unverified iterative procedure as a premise.
