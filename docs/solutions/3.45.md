# Exercise 3.45: First- and second-order tests for the negative product

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.45, p. 122](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=136).

Original solution.

For $`x>0`$, $`\nabla f(x)=(-x_2,-x_1)`$. If $`f(y)\le f(x)`$, then $`y_1y_2\ge x_1x_2`$. Arithmetic–geometric mean gives
```math
x_2y_1+x_1y_2\ge2\sqrt{x_1x_2y_1y_2}\ge2x_1x_2.
```
Therefore
$`\nabla f(x)^T(y-x)=2x_1x_2-x_2y_1-x_1y_2\le0`$. The first-order characterization proves quasiconvexity on the convex positive orthant.

For the second-order check,
```math
\nabla^2f=\begin{bmatrix}0&-1\\-1&0\end{bmatrix}.
```
A tangent direction $`v`$ satisfying $`\nabla f(x)^Tv=0`$ has $`v_2=-(x_2/x_1)v_1`$. Hence
```math
v^T\nabla^2f\,v=-2v_1v_2=2(x_2/x_1)v_1^2>0
```
for every nonzero tangent direction. Thus the strict second-order sufficient condition is satisfied everywhere and also proves quasiconvexity. The full Hessian is indefinite; positivity is required only in level-set tangent directions.
