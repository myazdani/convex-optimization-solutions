# Exercise 3.39: Conjugate transformation rules

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.39, p. 120](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=134).

Original solution.

## (a) Adding an affine function

Directly from the supremum definition,
```math
g^*(y)=\sup_x\{(y-c)^Tx-f(x)-d\}=f^*(y-c)-d.
```

## (b) Perspective

Let $`g(x,t)=t f(x/t)`$, $`t>0`$, and use dual variables $`(y,s)`$. Substitution $`x=tz`$ gives
```math
g^*(y,s)=\sup_{t>0,z\in\mathrm{dom}\,f}
 t(y^Tz+s-f(z))
=\begin{cases}0,&f^*(y)+s\le0,\\+\infty,&\text{otherwise}.
\end{cases}
```
If every parenthesized coefficient is nonpositive, the supremum is zero by sending $`t\downarrow0`$ with fixed $`z`$. If their supremum is positive, at least one coefficient is positive and $`t\to\infty`$ proves divergence. This also covers infinite $`f^*(y)`$.

## (c) Partial minimization and affine images

Using $`-\inf=\sup(-\cdot)`$,
```math
g^*(y)=\sup_x\sup_z\{y^Tx-f(x,z)\}=f^*(y,0).
```
This is an algebraic identity and does not require interchange of a minimum and maximum or attainment of the infimum. For the stated affine-image construction, it becomes
```math
g^*(y)=\sup_z\{y^T(Az+b)-h(z)\}
=b^Ty+h^*(A^Ty).
```
Empty fibers are assigned $`+\infty`$ and do not contribute to the supremum.

## (d) Biconjugacy

An affine function $`y^Tx-\beta`$ is a global minorant of $`f`$ exactly when
```math
\beta\ge\sup_x(y^Tx-f(x))=f^*(y).
```
Thus the supremum of all global affine minorants is
```math
\sup_y\{y^Tx-f^*(y)\}=f^{**}(x).
```
Exercise 3.28 shows this supremum equals a proper closed convex $`f`$ everywhere, including outside its domain. Hence $`f=f^{**}`$. Properness is the standard assumption excluding functions identically infinite or taking the value minus infinity, for which additional extended-value conventions would be required.
