# Exercise 6.3: Conic formulations of five approximation criteria

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 6.3, printed page 344. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=358).

Throughout, introduce the affine residual $`r=Ax-b`$.

## (a) Deadzone penalty
An LP is
```math
\begin{array}{ll}
\text{minimize}&\sum_i t_i\\
\text{subject to}&t_i\ge0,\quad t_i\ge r_i-a,\quad t_i\ge-r_i-a.
\end{array}
```
For fixed residuals the smallest feasible $`t_i`$ is exactly $`\max(0,|r_i|-a)`$.

## (b) Logarithmic penalty
On its finite domain the objective is
```math
-a^2\log\left(\prod_{i=1}^m\frac{(a+r_i)(a-r_i)}{a^2}\right).
```
Because the negative logarithm is decreasing, minimize it by maximizing the geometric mean of the $`2m`$ nonnegative affine factors $`a+r_i,a-r_i`$. This is an SOCP: impose
```math
 t\ge0,\quad a+r_i\ge0,\quad a-r_i\ge0,\qquad
 t\le\left(\prod_i(a+r_i)(a-r_i)\right)^{1/(2m)}
```
and maximize $`t`$. Here is an explicit SOC implementation of the last constraint, including non-power-of-two sizes. Let $`N`$ be the smallest power of two at least $`2m`$. Make the $`N`$ leaves the $`2m`$ factors and $`N-2m`$ additional copies of $`t`$. At each pair of nonnegative children $`v,w`$, introduce a nonnegative parent $`s`$ and impose
```math
\|(2s,v-w)\|_2\le v+w.
```
Constrain the root to be at least $`t`$. The tree says $`t^N\le t^{N-2m}\prod_i(a^2-r_i^2)`$, which for $`t>0`$ is precisely the required inequality; at $`t=0`$ both formulations hold by continuity. It uses fewer than $`4m`$ leaves and linearly many cones.

A strictly feasible residual exists if and only if the optimal SOCP value is positive. If positive, the maximizer has every factor positive and gives the original optimizer; the original value is $`-2ma^2\log(t/a)`$. If the best value is zero (or the SOCP is infeasible), no residual lies in the barrier domain, so the original extended-value problem has no finite solution. Compactness of feasible residuals in $`[-a,a]^m`$ and closedness of the affine residual range ensure attainment of the SOCP value when its feasible set is nonempty.

## (c) Huber penalty
Use the identity
```math
\phi(r)=\min_{z+w=r}\{z^2+2M|w|\}.
```
Indeed, the minimizing $`z`$ is $`r`$ if $`|r|\le M`$ and $`M\,\mathrm{sign}(r)`$ otherwise, as follows from the scalar subgradient equation. A QP is therefore
```math
\begin{array}{ll}
\text{minimize}&\sum_i(z_i^2+2Mt_i)\\
\text{subject to}&Ax-b=z+w,\quad -t_i\le w_i\le t_i.
\end{array}
```
The inequalities imply $`t_i\ge0`$ automatically.

## (d) Log-Chebyshev criterion
Set $`s_i=a_i^Tx/b_i`$. The formulation in the question is equivalent to the SOCP
```math
\begin{array}{ll}
\text{minimize}&t\\
\text{subject to}&s_i\le t,\quad
\|(2,s_i-t)\|_2\le s_i+t,\quad i=1,\ldots,m.
\end{array}
```
The cone inequality is equivalent to $`s_i,t\ge0`$ and $`s_it\ge1`$, hence actually both are positive. Its objective is the exponential of the original log-Chebyshev value, so their minimizers coincide. It also implies $`t\ge1`$.

## (e) Sum of the largest residual magnitudes
For any nonnegative vector $`v`$ and integer $`1\le k\le m`$,
```math
\sum_{i=1}^k v_{[i]}=\min_{\tau\in\mathbb R}
\left(k\tau+\sum_i\max(v_i-\tau,0)\right).
```
To verify this, the expression dominates the sum over every set of $`k`$ indices; equality holds for any threshold between $`v_{[k+1]}`$ and $`v_{[k]}`$ (with the evident endpoint convention for $`k=m`$). Thus the required LP minimizes $`k\tau+\sum_i s_i`$ subject to
```math
s_i\ge0,\qquad s_i\ge r_i-\tau,\qquad s_i\ge-r_i-\tau,
\qquad r=Ax-b.
```
