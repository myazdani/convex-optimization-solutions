# Exercise 3.42: Quasiconcavity of approximation width

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.42, p. 121](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=135).

Original solution.

For a coefficient vector $`x`$, let $`e_x(t)=\sum_i x_if_i(t)-f_0(t)`$, continuous in $`t`$. For every $`T\ge0`$, define
```math
C_T=\bigcap_{0\le t\le T}\{x:-\epsilon\le e_x(t)\le\epsilon\}.
```
Each condition is an affine slab in $`x`$, so $`C_T`$ is convex.

The superlevel set $`\{x:W(x)\ge T\}`$ equals $`C_T`$. One direction follows immediately from feasibility up to $`T`$. For the converse, if the supremum width is at least $`T`$, every time strictly below $`T`$ is covered by feasible intervals approaching that supremum, because the set of feasible endpoints is downward closed. Continuity of $`e_x`$ then extends the bound to $`T`$ itself. Thus all nonnegative superlevels are convex, proving quasiconcavity.

There is a harmless convention issue when $`|e_x(0)|>\epsilon`$: there is no admissible nonnegative endpoint. With $`\sup\varnothing=-\infty`$, the effective domain is the convex slab $`C_0`$ and negative superlevels also equal $`C_0`$. Alternatively one may assign width zero to this failure case; then every positive superlevel is still $`C_T`$, and nonpositive superlevels are all of space. Either natural convention preserves the requested quasiconcavity. Infinite widths cause no difficulty.
