# Exercise 10.13: Eliminating blocks in a convex-concave Newton system

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 10.13, printed page 559. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=573).

Put $`A=f_{uu}\succ0`$, $`C=-f_{vv}\succ0`$, $`B=f_{uv}`$, with block sizes $`p,q`$. Multiplying the second residual equation by minus one shows the root-finding Newton step solves
```math
\begin{bmatrix}A&B\\B^T&-C\end{bmatrix}
\begin{bmatrix}\Delta u\\\Delta v\end{bmatrix}
=-\begin{bmatrix}f_u\\f_v\end{bmatrix}.
```

## (a) Positive-definite elimination
Cholesky-factor $`A`$, solve for $`A^{-1}B,A^{-1}f_u`$, and form the positive-definite Schur complement $`S=C+B^TA^{-1}B`$. Cholesky-factor $`S`$ and solve
```math
S\Delta v=f_v-B^TA^{-1}f_u,\qquad
\Delta u=-A^{-1}(f_u+B\Delta v).
```
Alternatively eliminate $`v`$ using a Cholesky factor of $`C`$ and the positive-definite complement $`A+BC^{-1}B^T`$. Both avoid an indefinite solve. If one wishes to use factors of both original positive blocks, whiten with $`A=L_AL_A^T,C=L_CL_C^T`$ and $`G=L_A^{-1}BL_C^{-T}`$; the remaining normalized complement is $`I+G^TG`$ or $`I+GG^T`$, also Cholesky-factorable.

For dense data, elimination of $`u`$ has leading factorization/assembly work
```math
p^3/3+p^2q+pq^2+q^3/3=(p+q)^3/3
```
flops, plus lower-order vector solves. Thus it has the same cubic leading order as a dense symmetric $`LDL^T`$ factorization, while using positive-definite factorizations and exposing block structure. Factoring both original blocks as an optional whitening step adds work unless their factors are already available.

## (b) Diagonal or block-diagonal structure
If $`A`$ has block sizes $`p_j`$, its factorization costs $`\sum_jp_j^3/3`$ and its solves with $`q`$ right-hand sides cost $`O(q\sum_jp_j^2)`$. The remaining dense cross-block work is $`O(pq^2)`$ to form the complement and $`O(q^3)`$ to factor it. Interchange $`p,q`$ if exploiting $`C`$ instead. For diagonal $`A`$, these first costs reduce to $`O(p)`$ and $`O(pq)`$.

If both are diagonal and, say, $`q\le p`$, use the $`q\times q`$ complement: total cost is $`O(pq^2+q^3)`$, and reverse the choice when $`p<q`$. With comparable dimensions this is still cubic because $`B`$ is dense; diagonality does not make the entire solve linear. For $`p=q=d`$, the leading work drops from $`8d^3/3`$ for the full dense factorization to approximately $`4d^3/3`$ for diagonal-block elimination. Strong convex-concavity guarantees every positive block and complement used here is nonsingular.
