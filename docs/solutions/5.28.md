# Exercise 5.28: An exact LP optimum and uniqueness certificate

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.28](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=296). The source exercise and all of its subparts were checked directly.

Let $`A,b,c`$ be the exact integer data in the exercise. At $`x^\star=(1,1,1,1)`$, the five left-hand sides are $`(-3,5,-8,-7,3)`$, so the first four constraints are active and the fifth has slack one. Its objective is $`47+93+17-93=64`$.

Use the exact nonnegative multiplier

```math
\lambda=(3,2,2,7,0).
```

Direct integer multiplication gives

```math
A^T\lambda=(-47,-93,-17,93)=-c,
\qquad
-b^T\lambda=-[-9+10-16-49]=64.
```

Thus for every feasible $`x`$,

```math
c^Tx=-\lambda^TAx\ge-\lambda^Tb=64.
```

The proposed point attains this lower bound, proving global optimality without an LP solver.

To prove uniqueness, equality in the weighted inequalities forces the first four constraints to be active at any optimizer, because all four corresponding multipliers are strictly positive. If $`d=x-x^\star`$, those equations are

```math
\begin{aligned}
-d_1-6d_2+d_3+3d_4&=0,\\
-d_1-2d_2+7d_3+d_4&=0,\\
3d_2-10d_3-d_4&=0,\\
-6d_1-11d_2-2d_3+12d_4&=0.
\end{aligned}
```

Subtract the first from the second to get $`2d_2+3d_3-d_4=0`$. Together with the third, this gives $`d_2=13d_3`$ and $`d_4=29d_3`$. The first then gives $`d_1=10d_3`$. Substituting in the fourth yields $`143d_3=0`$. Hence every component is zero and $`x=x^\star`$. Equivalently the active matrix has nonzero determinant $`286`$.

## Validation

The certificate and uniqueness proof use only displayed integer products and elimination. No linear-programming code is used to establish the result; every arithmetic step can be checked directly from the source data.
