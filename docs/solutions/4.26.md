## Rotated-cone identity

With $`y,z\ge0`$, the quantity $`y+z`$ is nonnegative, so squaring the norm inequality is reversible. The expansion is

```math
4\|x\|_2^2+(y-z)^2\le(y+z)^2
\quad\Longleftrightarrow\quad\|x\|_2^2\le yz.
```

This includes $`y=0`$ or $`z=0`$, which force $`x=0`$. In fact the norm inequality itself implies $`y+z\ge|y-z|`$ and therefore both signs.

## (a) Reciprocal sum (harmonic mean up to scale)

Put $`s_i=a_i^Tx-b_i`$. Since the reciprocal is strictly decreasing on positive numbers, maximizing $`(\sum_i1/s_i)^{-1}`$ is equivalent to minimizing $`\sum_i1/s_i`$ over positive slacks. An exact SOCP is

```math
\begin{aligned}
\mathrm{minimize}\quad&\sum_i u_i\\
\mathrm{subject\ to}\quad&s=Ax-b,\\
&\|(2,u_i-s_i)\|_2\le u_i+s_i,\quad i=1,\ldots,m.
\end{aligned}
```

Each cone is equivalent to $`u_is_i\ge1`$, $`u_i,s_i\ge0`$, and hence forces strict positivity. For fixed $`x`$ the optimal bound is $`u_i=1/s_i`$. The optimizer maps are exact; the original optimal value is the reciprocal of the SOCP infimum, with $`1/0=+\infty`$ if an unbounded harmonic objective is approached. Infeasibility of the positive-slack domain is preserved. This transformation is preferable to allowing boundary points $`s_i=0`$, which the original domain excludes.

## (b) Geometric mean

Set $`s=Ax-b\succeq0`$ and introduce $`t\ge0`$, to be maximized. For $`m=1`$, impose $`t\le s_1`$. Otherwise let $`N`$ be the smallest power of two at least $`m`$. Form a binary tree with $`N`$ leaves: the first $`m`$ leaves are $`s_i`$, and the other $`N-m`$ are copies of $`t`$. Each internal node is a nonnegative variable $`w`$ with nonnegative children $`u,v`$ and the SOC constraint

```math
\|(2w,u-v)\|_2\le u+v.
```

Constrain the root to be at least $`t`$. Repeated multiplication of $`w^2\le uv`$ yields

```math
t^N\le\left(\prod_{i=1}^m s_i\right)t^{N-m}.
```

For $`t>0`$ this is equivalent to $`t^m\le\prod_i s_i`$. Conversely, if this product inequality holds, fill each internal node with the geometric mean of its children; the root then meets its lower bound. For $`t=0`$, every nonnegative leaf vector is feasible by setting all internal nodes to zero, matching the true geometric-mean hypograph. Thus the construction is exact, including zero slacks and non-power-of-two $`m`$. It uses fewer than $`2m`$ leaves and a linear number of SOC constraints. Maximizing $`t`$ returns the original value and an original optimizer when one exists.

## Validation

The harmonic formulation retains a strict positive domain through a nonzero product lower bound; the geometric formulation intentionally permits zero factors and handles arbitrary sizes.
