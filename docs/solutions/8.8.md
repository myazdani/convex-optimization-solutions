# Exercise 8.8: Polyhedral intersection and containment

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.8, printed page 448. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=462).

## Inequality representations
(a) Find any feasible point of the LP constraints $`Ax\le b,\ Fx\le g`$. Infeasibility means the intersection is empty.

(b) First test $`P_1`$ for feasibility; an empty $`P_1`$ is contained in every set. Otherwise, for each row $`f_j^T`$ of $`F`$, the inequality $`f_j^Tx\le g_j`$ holds on $`P_1`$ exactly when there exists a nonnegative multiplier
```math
A^T\lambda_j=f_j,\qquad b^T\lambda_j\le g_j,\qquad\lambda_j\ge0.
```
Necessity follows from LP duality for maximizing $`f_j^Tx`$ over the nonempty polyhedron; if bounded the primal and dual attain equal optima. Sufficiency follows by multiplying $`Ax\le b`$ by $`\lambda_j`$. Thus $`p`$ LP feasibility tests, or a single block feasibility LP, decide containment without a numerical “strict violation” threshold.

## Vertex representations
Let $`V=[v_1\ \cdots\ v_K]`$ and $`W=[w_1\ \cdots\ w_L]`$.

(a) Solve the feasibility LP
```math
V\alpha=W\beta,\quad \mathbf1^T\alpha=\mathbf1^T\beta=1,
\quad\alpha,\beta\ge0.
```
A feasible common vector is the required intersection point.

(b) It suffices and is necessary to test every $`v_k\in P_2`$: solve $`W\beta^{(k)}=v_k,\ \mathbf1^T\beta^{(k)}=1,\ \beta^{(k)}\ge0`$ for each $`k`$. Necessity is immediate; sufficiency follows because a convex set containing all generators contains their convex hull. This uses $`K`$ feasibility LPs, or their block combination. Empty vertex lists have the usual empty-hull interpretation and can be handled before these tests.
