# Exercise 2.8: Which sets are polyhedra?

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.8, p. 60](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=74).

Original solution.

## (a) The two-generator zonotope

It is always a polyhedron. Write $`B=[a_1\ a_2]`$. If $`B`$ has rank two, let $`L=(B^TB)^{-1}B^T`$. An explicit description is
```math
-\mathbf1\le Ly\le\mathbf1,\qquad (I_n-BL)y=0,
```
Equivalently the inequalities are $`Ly\le\mathbf1`$ and $`-Ly\le\mathbf1`$. The equality forces $`y=B(Ly)`$, proving equivalence with the original parametrization.

If the rank is one, choose a nonzero vector $`u`$ and scalars $`\alpha_i`$ with $`a_i=\alpha_i u`$. Set $`r=|\alpha_1|+|\alpha_2|`$. The image of the square is the segment $`\{tu:|t|\le r\}`$, described by
```math
\left(I_n-\frac{uu^T}{u^Tu}\right)y=0,
\qquad -r\le\frac{u^Ty}{u^Tu}\le r.
```
For rank zero it is the singleton $`\{0\}`$, described by $`y=0`$.

## (b) Moment constraints

All constraints are linear in $`x`$. Take $`A=-I_n`$, $`b=0`$, and, with $`a=(a_1,\ldots,a_n)`$ and componentwise square $`a\circ a`$,
```math
F=\begin{bmatrix}\mathbf1^T\\a^T\\(a\circ a)^T\end{bmatrix},
\qquad g=\begin{bmatrix}1\\b_1\\b_2\end{bmatrix}.
```
The possibly empty feasible set is a polyhedron.

## (c) Euclidean-ball portion

The maximum of $`x^Ty`$ over $`\|y\|_2=1`$ is $`\|x\|_2`$, so this is $`\{x\ge0:\|x\|_2\le1\}`$. For $`n\ge2`$ it is not a polyhedron. Its intersection with the plane having all but the first two coordinates zero is a quarter disk. Every point of its circular arc with positive coordinates is an extreme point, because equality in the Euclidean triangle inequality for two unit-ball points forces them to coincide. A bounded two-dimensional polyhedron has finitely many vertices, whereas this arc supplies infinitely many. For $`n=1`$ the set is the interval $`[0,1]`$, a polyhedron.

## (d) Infinity-norm box

For $`\sum_i|y_i|=1`$, $`x^Ty\le\|x\|_\infty`$, with equality at a signed coordinate vector maximizing $`|x_i|`$. Thus the set is $`[0,1]^n`$, given by $`-x\le0`$ and $`x\le\mathbf1`$.
