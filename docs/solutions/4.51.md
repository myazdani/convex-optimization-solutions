# Exercise 4.51: Order transformations: a counterexample and corrected theorem

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.51](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=220). The source exercise and all of its subparts were checked directly.

## The printed hypothesis is insufficient

A one-way strictly order-preserving map need not reflect order: it may make originally incomparable values comparable. Consequently the claimed equivalence is false as written.

For a convex counterexample, let the feasible set be $`0\le x\le1`$, let $`K=\mathbb R_+^2`$, and take

```math
f_0(x)=(x,1-x),\qquad
\phi(u_1,u_2)=(u_1+2u_2,u_1+2u_2).
```

Whenever $`u\preceq v`$ and $`u\ne v`$, the positive weighted sum strictly increases, so $`\phi(u)\prec\phi(v)`$. Thus this map satisfies exactly the source's hypothesis. All original feasible points are Pareto optimal: reducing one coordinate increases the other. There is no original optimal point that dominates all other values. But

```math
\phi(f_0(x))=(2-x,2-x),
```

so the transformed problem has the unique Pareto optimal point $`x=1`$, which is also an optimal point. This disproves both claimed equivalences.

## What the one-way condition does prove

If $`x`$ is dominated originally by $`z`$, strict order preservation makes it dominated after transformation. Thus every transformed Pareto point was originally Pareto. Also, an original optimal point remains optimal after transformation. The reverse implications fail in the example above.

## Corrected equivalence and proof

A sufficient corrected hypothesis is that $`\phi`$ is an order embedding on the achievable objective values: for all such $`u,v`$,

```math
u\preceq_K v\quad\Longleftrightarrow\quad
\phi(u)\preceq_K\phi(v),\qquad
u=v\quad\Longleftrightarrow\quad\phi(u)=\phi(v).
```

Then one achievable value strictly dominates another before transformation exactly when it does afterward. The absence of a strict dominator is therefore unchanged, proving equivalence of Pareto optimal points. Likewise, being no larger than every achievable value is unchanged, proving equivalence of optimal points.

For multicriterion optimization with the componentwise order, replacing each coordinate by a strictly increasing scalar function is indeed an order embedding: $`\phi_i(u_i)\le\phi_i(v_i)`$ if and only if $`u_i\le v_i`$, with equality if and only if the inputs agree. Thus the final special case in the exercise is valid. “Increasing” here must mean strictly increasing; flat scalar functions can destroy dominance information.

## Validation

The counterexample obeys the printed implication on the entire objective space. The solution distinguishes the false general assertion from its valid coordinatewise special case instead of supplying a proof of an untrue statement.
