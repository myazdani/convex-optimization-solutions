# Exercise 8.4: A non-Euclidean projection need not give the Euclidean separator

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.4, printed page 447. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=461).

In $`\mathbb R^2`$ take the norm $`\|(u,v)\|=\sqrt{u^2+4v^2}`$, the closed convex line $`C=\{(t,t):t\in\mathbb R\}`$, and $`x_0=(1,0)`$. Projection in this norm minimizes
```math
(t-1)^2+4t^2=5(t-1/5)^2+4/5,
```
so its unique projected point is $`p=(1/5,1/5)`$. The proposed hyperplane has normal $`p-x_0=(-4/5,1/5)`$. Its value along the line $`C`$ is
```math
(p-x_0)^T\left((t,t)-\frac{x_0+p}{2}\right)
=-\frac35t+\frac{23}{50}.
```
This takes both signs as $`t`$ varies, so the hyperplane cuts the set and cannot separate it from $`x_0`$. This counterexample even uses a smooth, strictly convex norm and a unique projection. A valid separator must use a supporting functional of the selected norm rather than the unmodified Euclidean difference vector.
