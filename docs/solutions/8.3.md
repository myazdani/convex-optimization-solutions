# Exercise 8.3: Projections on three proper cones

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.3, printed page 447. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=461).

## (a) Nonnegative orthant
Squared Euclidean distance separates coordinatewise. The scalar problem $`\min_{x_i\ge0}(x_i-x_{0i})^2`$ has the unique solution $`\max(x_{0i},0)`$. Therefore $`P_{\mathbb R_+^n}(x_0)=(x_0)_+`$.

## (b) Positive semidefinite matrices
Use the Frobenius inner product on symmetric matrices. Diagonalize $`X_0=U\mathrm{diag}(\lambda)U^T`$ and write $`Y=U^TXU\succeq0`$. Orthogonal invariance gives
```math
\|X-X_0\|_F^2=\sum_i(Y_{ii}-\lambda_i)^2+\sum_{i\ne j}Y_{ij}^2.
```
Since $`Y_{ii}\ge0`$, this is minimized by the feasible diagonal matrix $`Y_{ii}=\max(\lambda_i,0)`$, $`Y_{ij}=0`$. Hence $`P_{\mathbb S_+^n}(X_0)=U\mathrm{diag}(\lambda_+)U^T`$. The formula is independent of choices within repeated eigenspaces.

## (c) Second-order cone
Let $`r=\|x_0\|`$. For a fixed $`s=\|x\|\ge0`$, Cauchy–Schwarz shows that the smallest $`\|x-x_0\|^2`$ is $`(s-r)^2`$, attained by $`x=(s/r)x_0`$ when $`r>0`$. It remains to project $`(r,t_0)`$ onto $`\{(s,t):0\le s\le t\}`$.

If $`t_0\ge r`$, the original point is feasible. If $`t_0\le-r`$, the origin is optimal: for every feasible $`s,t`$, $`rs+t_0t\le(r+t_0)t\le0`$, so expansion of squared distance bounds it below by the distance to zero. In the remaining case $`-r<t_0<r`$, the optimum is on $`s=t`$, and minimizing $`(s-r)^2+(s-t_0)^2`$ gives $`s=t=(r+t_0)/2>0`$. Recovering $`x`$ yields
```math
P_K(x_0,t_0)=\begin{cases}
0,&r\le-t_0,\\
(x_0,t_0),&r\le t_0,\\
\tfrac12(1+t_0/r)(x_0,r),&r>|t_0|.
\end{cases}
```
At the shared boundaries the formulas agree. For $`r=0`$, use $`(0,\max(t_0,0))`$; no division by zero is needed.
