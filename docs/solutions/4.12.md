# Exercise 4.12: A linear program for network flow

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.12](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=207). The source exercise and all of its subparts were checked directly.

Use one variable $`x_{ij}`$ for each directed link. Conservation says that outgoing flow minus incoming flow equals the external supply. The LP is

```math
\begin{aligned}
\mathrm{minimize}\quad &\sum_{i,j=1}^n c_{ij}x_{ij}\\
\mathrm{subject\ to}\quad &\sum_{j=1}^n x_{ij}-\sum_{j=1}^n x_{ji}=b_i,
\quad i=1,\ldots,n,\\
&l_{ij}\le x_{ij}\le u_{ij},\quad i,j=1,\ldots,n.
\end{aligned}
```

All terms are linear in the flows. Positive external supply appears on the outgoing-minus-incoming side with a positive sign. Summing the conservation equations cancels every link contribution, giving the necessary condition $`\mathbf1^Tb=0`$. That condition alone does not guarantee feasibility when link bounds are imposed.

If self-links are included, $`x_{ii}`$ cancels from conservation, and its bounded cost is optimized independently. If the network excludes them, simply omit them. With finite consistent bounds, any nonempty feasible set is compact, so the linear objective attains its minimum. Infeasible bounds or incompatible capacities are correctly reported as LP infeasibility.

## Validation

Each constraint corresponds directly to either a link capacity or one node's flow balance, with no auxiliary relaxation.
