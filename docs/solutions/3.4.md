# Exercise 3.4: An integral characterization of convexity

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.4, p. 114](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=128).

Original solution.

If $`f`$ is convex, the pointwise chord bound is
```math
f((1-t)x+ty)\le(1-t)f(x)+tf(y),\qquad0\le t\le1.
```
Integrating gives the stated trapezoidal-average inequality.

Conversely, assume the integral inequality holds on every segment and that $`f`$ is continuous. Fix a segment and subtract its endpoint chord:
```math
h(t)=f((1-t)x+ty)-(1-t)f(x)-tf(y),\qquad t\in[0,1].
```
Then $`h`$ is continuous and $`h(0)=h(1)=0`$. Subtracting an affine function preserves the integral inequality on every subinterval of $`[0,1]`$.

If $`h(t_0)>0`$ somewhere, take the connected component $`(a,b)`$ of the open set $`\{t:h(t)>0\}`$ containing $`t_0`$. Its endpoints lie in $`[0,1]`$ and satisfy $`h(a)=h(b)=0`$ by continuity, including endpoints zero and one when present. But
```math
\frac1{b-a}\int_a^b h(t)\,dt>0
=\frac{h(a)+h(b)}2,
```
contradicting the integral inequality on that subsegment. Thus $`h\le0`$ everywhere. Since the segment was arbitrary, this is exactly convexity of $`f`$.
