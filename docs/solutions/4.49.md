# Exercise 4.49: Cone-valued denominators and fractional quasiconvexity

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.49](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=219). The source exercise and all of its subparts were checked directly.

Although the source labels the codomain as a vector space, the infimum defining $`f_0`$ is a scalar. Put $`a=Cx+d`$, $`b=Fx+g\in\mathrm{int}K`$.

Because $`b`$ is interior, $`tb-a\in K`$ for all sufficiently large $`t`$: divide by $`t>0`$ and use a neighborhood of $`b`$ contained in $`K`$. The feasible scalar set is closed by closedness of $`K`$ and is upward closed because $`b\in K`$. It is bounded below: choose any nonzero dual-cone vector $`z\in K^*`$; interiority gives $`z^Tb>0`$, and feasibility implies $`t\ge z^Ta/(z^Tb)`$. Thus the infimum is a finite attained scalar, and

```math
f_0(x)\le t\quad\Longleftrightarrow\quad
Cx+d\preceq_K t(Fx+g).
```

For fixed $`t`$, this is an affine inverse image of the convex cone. The domain $`Fx+g\in\mathrm{int}K`$ is convex as well. Their intersection is convex, proving quasiconvexity. Equivalently,

```math
f_0(x)=\sup_{z\in K^*\setminus\{0\}}
\frac{z^T(Cx+d)}{z^T(Fx+g)},
```

using the dual characterization of a closed convex cone.

## Generalized linear-fractional program

For the maximum of ratios $`\max_i(a_i^Tx+b_i)/(c_i^Tx+d_i)`$, each denominator being positive, choose $`K=\mathbb R_+^m`$, stack the numerator affine functions as $`Cx+d`$, and stack the denominator affine functions as $`Fx+g`$. The cone inequality is exactly the componentwise collection of ratio upper bounds. Keep any original affine feasibility constraints.

## Generalized eigenvalue program

Work in the finite-dimensional inner-product space of symmetric matrices with cone $`\mathbb S_+^k`$ (or any fixed linear coordinate representation of that space). Set the numerator affine map to $`A(x)`$ and denominator map to $`B(x)`$. Then

```math
\inf\{t:A(x)\preceq tB(x)\}=\lambda_{\max}(A(x),B(x)),
\qquad B(x)\succ0,
```

as follows by testing all quadratic forms. This is the required generalized fractional representation.

## Validation

Proper-cone interiority ensures the scalar threshold is finite and attained, which is needed for replacing the infimum by a non-strict level inequality.
