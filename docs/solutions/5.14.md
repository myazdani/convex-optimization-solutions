# Exercise 5.14: A dual certificate from an equality penalty

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.14](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=291). The source exercise and all of its subparts were checked directly.

Let $`r=A\widetilde x-b`$. Unconstrained first-order optimality for the differentiable convex penalty gives

```math
\nabla f_0(\widetilde x)+2\alpha A^Tr=0.
```

Define the equality multiplier $`\widetilde\nu=2\alpha r`$. Equality multipliers have no sign restriction, so it is dual feasible. More importantly, the convex function $`x\mapsto f_0(x)+\widetilde\nu^T(Ax-b)`$ has zero gradient at $`\widetilde x`$. Thus this point is its global minimizer and the dual value can be evaluated exactly:

```math
g(\widetilde\nu)
=f_0(\widetilde x)+\widetilde\nu^Tr
=f_0(\widetilde x)+2\alpha\|r\|_2^2
=\phi(\widetilde x)+\alpha\|r\|_2^2.
```

Weak duality proves $`p^\star\ge g(\widetilde\nu)`$. This is the requested lower bound. It is not an upper bound obtained from $`\widetilde x`$, because that point need not satisfy the equality constraint. If its residual is zero, it is primal feasible and the displayed bound coincides with its objective, certifying optimality.

The full-row-rank hypothesis guarantees that the original affine constraints have a solution for every $`b`$, but the certificate construction itself only uses stationarity and convexity and does not require forming a matrix inverse.

## Validation

The multiplier is twice the penalty weight times the residual, and the lower-bound value contains twice the quadratic penalty, not once.
