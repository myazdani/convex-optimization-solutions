# Exercise 5.4: Aggregated-halfspace bounds and the LP dual

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.4](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=287). The source exercise and all of its subparts were checked directly.

For $`w\succeq0`$, put $`a=A^Tw`$, $`\beta=b^Tw`$ and let $`h(w)=\inf\{c^Tx:a^Tx\le\beta\}`$.

## (a) The halfspace minimum

If $`a\ne0`$, a finite minimum exists exactly when $`c=-\alpha a`$ for some $`\alpha\ge0`$. Then the minimum is $`-\alpha\beta`$: for $`\alpha>0`$ take any boundary point, and for $`\alpha=0`$ the objective is identically zero. Otherwise an improving ray exists, either orthogonal to $`a`$ or in direction $`-a`$, and $`h(w)=-\infty`$.

If $`a=0`$ and $`\beta\ge0`$, the halfspace is all of space; its value is zero when $`c=0`$ and $`-\infty`$ otherwise. If $`a=0`$ and $`\beta<0`$, it is empty and its infimum is $`+\infty`$. These cases complete the formula including degenerate aggregations.

## (b) Best finite supporting-halfspace bound

For a nonempty halfspace that gives a finite bound, write $`\lambda=\alpha w\succeq0`$. The proportionality condition and bound become

```math
A^T\lambda=-c,\qquad h(w)=-b^T\lambda.
```

For $`c\ne0`$, conversely any such $`\lambda`$ is itself an aggregate weight with nonzero normal and gives this bound, using scaling factor one. Thus, for $`c\ne0`$, maximizing these bounds gives

```math
\mathrm{maximize}\quad-b^T\lambda\qquad
\mathrm{subject\ to}\quad A^T\lambda+c=0,\quad\lambda\succeq0.
```

When the original LP is feasible, every aggregate halfspace is nonempty and this describes the best aggregate bound, including value $`-\infty`$ if no finite bound exists. For the separate case $`c=0`$, every nonempty aggregate has minimum zero, and when the original LP is feasible the dual also has optimum zero: $`\lambda=0`$ attains it, while weak duality bounds all other choices above by zero.

## (c) Relation to the Lagrangian and infeasible cases

The LP Lagrangian is $`(c+A^T\lambda)^Tx-b^T\lambda`$. Its infimum over all $`x`$ is $`-b^T\lambda`$ when the displayed equality holds and $`-\infty`$ otherwise. Hence the optimization above is exactly the usual LP dual: its feasible weights select an aggregate halfspace with normal opposite the objective.

If an aggregation is empty, it already proves original infeasibility and gives the bound $`+\infty`$. One must not assume that maximizing these geometric bounds always equals the dual value for an infeasible primal. For example $`A=0,b=-1,c=1`$ in one dimension has an empty aggregate halfspace at $`w=1`$, but its Lagrange dual is infeasible since $`A^T\lambda=-1`$ is impossible. The geometric best bound is then $`+\infty`$ and the dual value is $`-\infty`$. Thus the usual equivalence of this interpretation applies directly when the primal is feasible, or to the finite nonempty-halfspace bounds; the exceptional empty-halfspace case is an infeasibility certificate rather than an ordinary finite supporting bound.

## Validation

The derivation includes zero normals and empty halfspaces, so it does not tacitly impose a missing feasibility hypothesis.
