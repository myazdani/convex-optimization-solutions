# Exercise 3.7: A globally upper-bounded convex function is constant

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.7, p. 114](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=128).

Original solution.

Suppose there were $`x,y`$ with $`f(y)>f(x)`$. For each $`t>1`$ let $`z_t=x+t(y-x)`$, which is in the full domain. Since $`y=(1-1/t)x+(1/t)z_t`$, convexity implies
```math
f(y)\le(1-1/t)f(x)+(1/t)f(z_t),
```
so
```math
f(z_t)\ge f(x)+t(f(y)-f(x))\longrightarrow+\infty.
```
This contradicts the global upper bound. Therefore $`f(y)\le f(x)`$ for every pair; swapping the pair gives equality. Thus $`f`$ is constant. The full-domain assumption is essential, since many nonconstant convex functions are bounded above on a bounded domain.
