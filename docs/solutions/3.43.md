# Exercise 3.43: The first-order test for quasiconvexity

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.43, p. 121](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=135).

Original solution.

Assume the differentiable function has a convex domain.

For necessity, let $`f(y)\le f(x)`$. Quasiconvexity gives $`f(x+t(y-x))\le f(x)`$ for $`0\le t\le1`$. Taking the right derivative at zero yields $`\nabla f(x)^T(y-x)\le0`$.

For sufficiency, suppose the stated implication holds, but quasiconvexity fails on some segment. Restrict to that line to get a differentiable function $`h`$ on $`[a,b]`$ with an interior point whose value exceeds $`M=\max(h(a),h(b))`$. The open set $`\{t:h(t)>M\}`$ has a component $`(u,v)`$ containing such a point, with $`h(u)=h(v)=M`$. Choose any point $`r\in(u,v)`$. By the mean value theorem on $`[u,r]`$, there exists $`s\in(u,r)`$ with
```math
h'(s)=\frac{h(r)-h(u)}{r-u}>0.
```
But $`h(v)=M<h(s)`$ and $`v>s`$, so the assumed first-order implication applied at $`s`$ with comparison point $`v`$ gives $`h'(s)(v-s)\le0`$, a contradiction. Therefore no segment can have an interior value above its endpoint maximum, which is quasiconvexity.

The restriction inherits the implication because $`h'(t)`$ is the directional derivative of $`f`$ along the segment; thus the one-dimensional proof establishes the full multidimensional result.
