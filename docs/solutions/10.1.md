# Exercise 10.1: Nonsingularity and inertia of a KKT matrix

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 10.1, printed page 557. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=571).

Let $`K=\begin{bmatrix}P&A^T\\A&0\end{bmatrix}`$, with $`P\succeq0`$ and $`A`$ of full row rank.

## (a) Equivalent conditions
If $`v\in\ker P\cap\ker A`$, then $`K(v,0)=0`$, so nonsingularity implies the intersection is trivial. Conversely, if $`K(v,w)=0`$, then $`Av=0`$ and $`Pv+A^Tw=0`$. Multiplying by $`v^T`$ gives $`v^TPv=0`$, hence $`Pv=0`$ because $`P\succeq0`$. The trivial intersection gives $`v=0`$, and full row rank gives $`w=0`$. This proves equivalence with the first condition.

For a PSD matrix, $`v^TPv=0`$ is equivalent to $`Pv=0`$, so the second condition is the same statement. Since $`F`$ has $`n-p`$ columns and range $`\ker A`$, it has full column rank; writing $`v=Fu`$ proves equivalence with $`F^TPF\succ0`$.

Finally if $`P+A^TQA\succ0`$ for some $`Q\succeq0`$, its restriction to $`\ker A`$ is $`P`$, giving the second condition. Conversely trivial common nullspace makes
```math
v^T(P+A^TA)v=v^TPv+\|Av\|^2>0\quad(v\ne0),
```
so the fourth condition holds already with $`Q=I`$.

## (b) Inertia
The nonsingular change of variables $`w=\widetilde w+\tfrac12Av`$ transforms the quadratic form $`v^TPv+2w^TAv`$ into $`v^T(P+A^TA)v+2\widetilde w^TAv`$. Thus $`K`$ is congruent to the KKT matrix with positive-definite leading block $`R=P+A^TA`$. Completing its square shows that matrix is congruent to
```math
\mathrm{diag}(R,-AR^{-1}A^T).
```
The first block has $`n`$ positive eigenvalues and the second has $`p`$ negative eigenvalues because $`A`$ has full row rank. Congruence preserves inertia, proving the stated counts and absence of zero eigenvalues.
