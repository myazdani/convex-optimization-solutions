# Exercise 5.23: Strong LP duality from active normals and alternatives

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.23](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=294). The source exercise and all of its subparts were checked directly.

## (a) Finite attained primal value

Let $`I`$ be the active set at $`x^\star`$. The cone $`C=\{\sum_{i\in I}z_ia_i:z_i\ge0\}`$ is a closed finitely generated cone. If $`-c\notin C`$, separation from this cone yields a direction $`v`$ with $`a_i^Tv\le0`$ for all active indices and $`c^Tv<0`$. (The cone's scaling and its inclusion of zero allow the separating level to be zero.)

For sufficiently small $`\epsilon>0`$, $`x^\star+\epsilon v`$ remains feasible: active inequalities cannot increase, and finitely many inactive inequalities retain their positive slack for a small enough step. Its objective is strictly smaller, contradicting optimality. Therefore $`-c\in C`$. Choose the corresponding nonnegative coefficients and set $`z_i=0`$ off the active set. Then $`A^Tz+c=0`$, and

```math
-b^Tz=-\sum_{i\in I}z_i a_i^Tx^\star
=c^Tx^\star.
```

This dual feasible point matches the primal value, so weak duality certifies both optimality and strong duality.

## (b) Infeasible primal but feasible dual

The linear alternative for infeasible $`Ax\preceq b`$ gives $`v\succeq0`$ with $`A^Tv=0`$ and $`b^Tv<0`$, necessarily nonzero. If $`z^0`$ is any dual feasible point, then $`z^0+tv`$ is dual feasible for every $`t\ge0`$, and its objective is

```math
-b^Tz^0-tb^Tv\longrightarrow+\infty.
```

Thus $`d^\star=+\infty=p^\star`$. If instead the primal is feasible and unbounded below, weak duality forces $`d^\star=-\infty=p^\star`$. Together with (a), these cases prove the stated extended-value strong-duality assertion whenever at least one side is feasible.

## (c) Both sides infeasible

The first primal inequality is $`0\le-1`$, so there is no primal feasible point and $`p^\star=+\infty`$. Its dual is

```math
\mathrm{maximize}\quad z_1-z_2\qquad
\mathrm{subject\ to}\quad z_2+1=0,\quad z_1,z_2\ge0.
```

The equality requires $`z_2=-1`$, so the dual is infeasible and $`d^\star=-\infty`$. This is exactly the exceptional case allowed in the claim.

## Validation

The finite-value proof uses active-normal separation rather than assuming strong LP duality, and the infeasible-primal case supplies an explicit improving dual ray.
