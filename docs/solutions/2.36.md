# Exercise 2.36: The cone of Euclidean distance matrices

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.36, p. 65](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=79).

Original solution.

Using the characterization supplied in the exercise, the cone is
```math
\mathcal E=
\{D\in\mathbb S^n:D_{ii}=0\ \forall i,\quad
z^TDz\le0\ \forall z\text{ with }\mathbf1^Tz=0\}.
```
Each diagonal condition is linear and homogeneous, and for each fixed $`z`$ the quadratic-looking expression is linear in the matrix variable $`D`$. Hence this is an intersection of a linear subspace and homogeneous closed halfspaces: it is a closed convex cone.

There is also a direct geometric proof of the cone property. If $`D`$ is generated by points $`x_i\in\mathbb R^k`$ and $`E`$ by points $`y_i\in\mathbb R^\ell`$, then for $`\alpha,\beta\ge0`$ the concatenated points $`w_i=(\sqrt\alpha x_i,\sqrt\beta y_i)`$ satisfy
```math
\|w_i-w_j\|_2^2=\alpha D_{ij}+\beta E_{ij}.
```
Thus every nonnegative linear combination is again a Euclidean distance matrix, including zero. The dimension may grow, which is allowed by the question.
