# Exercise 8.11: The narrowest circular cone through given directions

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.11, printed page 449. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=463).

For nonzero samples set $`v_i=a_i/\|a_i\|_2`$. A unit center direction $`c`$ and radius $`\theta\le\pi/2`$ contain them exactly when $`c^Tv_i\ge\cos\theta`$ for every $`i`$. Solve the SOCP
```math
\text{maximize }t\quad\text{subject to }c^Tv_i\ge t\ (i=1,\ldots,m),
\quad\|c\|_2\le1.
```
It is feasible at $`(c,t)=(0,0)`$ and attains an optimum with $`0\le t_*\le1`$. If $`t_*>0`$, every optimum has $`\|c_*\|=1`$: otherwise rescaling $`c_*,t_*`$ upward improves it. Thus $`\theta_* =\arccos t_*`$ and $`c_*`$ give the narrowest cone, since any smaller angle would imply a larger feasible $`t`$.

If $`t_*=0`$, the relaxation by itself does not distinguish a hemisphere from infeasibility, because it admits $`c=0`$. Test for a nonzero vector satisfying $`c^Tv_i\ge0`$. This is done with at most $`2n`$ LP feasibility problems: add $`c_j=1`$ or $`c_j=-1`$ in turn. Any nonzero feasible vector can be positively scaled to meet one of these equations. If any test succeeds, normalize its vector and use $`\theta_* =\pi/2`$. If all fail, no allowed cone exists. This gives the requested complete feasibility test.

Zero input points may be omitted when using the standard closed-cone convention that the apex belongs to every cone. Under a literal angle definition they have undefined angle and require that convention to make the question meaningful. If all samples are zero, every direction with radius zero is adequate under the apex convention. Radius-zero rays and radius-$`\pi/2`$ halfspaces are limiting circular cones; they are not nonsingular linear images of a full-dimensional pointed SOC, despite the exercise's blanket parenthetical description.
