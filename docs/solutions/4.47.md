# Exercise 4.47: Positive semidefinite and maximum-determinant completion

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.47](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=218). The source exercise and all of its subparts were checked directly.

## (a) Specified diagonal convention

Let $`U`$ be the indices whose diagonal entries were not specified. If $`X`$ is any positive semidefinite completion, choose a scalar $`t\ge\max_{i\in U}X_{ii}`$ and replace all missing diagonal entries by this common value. The resulting matrix is

```math
X+\sum_{i\in U}(t-X_{ii})e_ie_i^T\succeq0,
```

and every originally specified entry is unchanged. Consequently the original instance is feasible if and only if there exists a scalar $`t`$ for which the instance obtained by specifying all missing diagonals as $`t`$ is feasible. This reduces the general question to a family of fully specified-diagonal questions, with a monotone parameter. It does not justify choosing one arbitrary fixed value in advance. For actual computation on an input with missing diagonals, simply leave them as free variables in the SDP below.

In particular, the maximum-determinant conclusions in (c) genuinely require fixed diagonal values. Without them, increasing a free diagonal can make the determinant unbounded. Nor does an arbitrarily large missing diagonal repair every input: $`\begin{bmatrix}0&1\\1&t\end{bmatrix}`$ is never positive semidefinite.

## (b) Feasibility SDP

Let $`\mathcal E`$ be the set of specified entries and $`a_{ij}`$ their prescribed values. Find a symmetric matrix $`X`$ satisfying

```math
X\succeq0,\qquad X_{ij}=a_{ij}\quad((i,j)\in\mathcal E).
```

This is an SDP feasibility problem with affine equality constraints, whether or not all diagonal entries were initially specified. An inconsistent pair of prescribed symmetric entries gives infeasibility.

## (c) Existence, uniqueness, and inverse zeros

Now fix all diagonals and assume a positive definite completion exists. For any positive semidefinite completion, each principal two-by-two minor gives $`|X_{ij}|^2\le a_{ii}a_{jj}`$. Thus the feasible set is closed and bounded, hence compact. The continuous determinant attains a maximum there; its value is positive because a positive definite completion exists. Any maximizing matrix is therefore positive definite.

On that positive-definite affine slice, maximize $`\log\det X`$ instead. This function is strictly concave: for every nonzero symmetric direction $`H`$,

```math
D^2\log\det X[H,H]
=-\mathrm{tr}(X^{-1}HX^{-1}H)
=-\|X^{-1/2}HX^{-1/2}\|_F^2<0.
```

Consequently two distinct maximizers cannot exist. At the unique maximizer $`X^\star`$, every unspecified off-diagonal pair admits small perturbations in both directions $`H=e_ie_j^T+e_je_i^T`$, because positive definiteness is open and no specified entry changes. Stationarity yields

```math
0=\mathrm{tr}((X^\star)^{-1}H)=2((X^\star)^{-1})_{ij}.
```

Thus the inverse vanishes at all originally unspecified entries. (Under the fixed-diagonal hypothesis they are off-diagonal.)

## (d) Tridiagonal specification

When exactly the diagonal and first off-diagonals are specified, the other entries satisfy $`|i-j|>1`$. Apply (c): the maximum-determinant completion exists, is positive definite, and its inverse has zeros at all these positions. Its inverse is therefore tridiagonal, as required.

## Validation

Compactness and positivity establish existence before using strict concavity for uniqueness. The diagonal convention is separated from the actual fixed-diagonal requirement in the determinant problem.
