# Exercise 8.15: An ellipsoid covering several ellipsoids

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.15, printed page 449. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=463).

Parametrize the sought ellipsoid as $`\{x:\|Bx+d\|_2\le1\}`$ with symmetric $`B\succ0`$. Its volume is proportional to $`1/\det B`$. For an input full-dimensional ellipsoid write $`q_i(x)=x^TA_ix+2b_i^Tx+c_i`$; it has a strictly feasible point $`q_i(x)<0`$.

The S-lemma, with precisely this strict-feasibility hypothesis, says that $`q_i(x)\le0\Rightarrow1-\|Bx+d\|^2\ge0`$ is equivalent to existence of $`\tau_i\ge0`$ such that
```math
1-\|Bx+d\|^2+\tau_iq_i(x)\ge0\quad\text{for every }x.
```
A quadratic is globally nonnegative exactly when its augmented symmetric coefficient matrix is positive semidefinite. Applying the Schur complement of an identity block gives the affine LMI
```math
\begin{bmatrix}
\tau_iA_i&\tau_i b_i&B\\
\tau_i b_i^T&1+\tau_i c_i&d^T\\
B&d&I
\end{bmatrix}\succeq0.
```
Thus minimize $`-\log\det B`$ over $`B\succ0,d,\tau_i\ge0`$ subject to these $`K`$ LMIs. This is a convex determinant-maximization problem. Recover the requested parameters as $`x_0=-B^{-1}d`$ and $`A=B^{-2}`$.

The sign of the multiplier can be checked directly: on $`q_i\le0`$, the global inequality implies $`1-\|Bx+d\|^2\ge-\tau_iq_i\ge0`$. Empty input sets impose no constraint. If “ellipsoid” is allowed to mean a degenerate set with no strict point, the strict S-lemma cannot be invoked as stated; first restrict its quadratic to its affine hull (or impose point constraints for a singleton) and apply the same construction there.
