# Exercise 5.2: Weak duality at extended optimal values

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.2](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=287). The source exercise and all of its subparts were checked directly.

For every primal-feasible $`x`$ and dual-feasible $`(\lambda,\nu)`$, the elementary Lagrangian inequality gives $`g(\lambda,\nu)\le f_0(x)`$.

If $`p^\star=-\infty`$, there exists a primal-feasible sequence whose finite objective values tend to $`-\infty`$. The same dual value is bounded above by every value in that sequence, so it must equal $`-\infty`$. This holds for every dual-feasible multiplier; their supremum is therefore $`d^\star=-\infty`$. If the dual feasible set is empty, its supremum is also $`-\infty`$ by convention.

Conversely, if $`d^\star=+\infty`$ and a primal-feasible point with finite objective existed, its value would be an upper bound on every dual objective and hence on their supremum. This contradicts $`d^\star=+\infty`$. Thus there is no finite-objective primal-feasible point, and under the problem's domain convention the primal is infeasible, with $`p^\star=+\infty`$.

## Validation

The proof uses the pointwise lower-bound inequality and explicit sequences or a finite upper bound. It never subtracts or rearranges undefined differences of infinities.
