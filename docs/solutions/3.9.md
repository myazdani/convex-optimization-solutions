# Exercise 3.9: Convexity after restriction to an affine set

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.9, p. 114](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=128).

Original solution.

The inverse image of the convex domain under $`z\mapsto Fz+\widehat x`$ is convex.

## (a) Restricted Hessian

The chain rule gives
```math
\nabla\widetilde f(z)=F^T\nabla f(Fz+\widehat x),
\qquad
\nabla^2\widetilde f(z)=F^T\nabla^2f(Fz+\widehat x)F.
```
Applying the second-order convexity criterion to $`\widetilde f`$ proves the stated equivalence. No injectivity or full-column-rank assumption on $`F`$ is needed; its null directions merely give zero curvature.

## (b) Sufficient shifted-Hessian condition

Write $`H=\nabla^2f(Fz+\widehat x)`$. If $`H+\lambda A^TA\succeq0`$, then for every $`u\in\mathbb R^m`$,
```math
u^TF^THFu
=(Fu)^T(H+\lambda A^TA)(Fu)\ge0,
```
because $`AF=0`$. Thus $`F^THF\succeq0`$ at each point, and part (a) proves convexity. The scalar $`\lambda`$ may depend on $`z`$; uniformity is unnecessary. The nullspace/range equality in the problem ensures this condition addresses the intended affine tangent space, although the displayed sufficiency proof itself only needs $`AF=0`$.
