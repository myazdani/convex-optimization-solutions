# Exercise 11.11: Method of analytic centers: certificates and a point-limit counterexample

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 11.11, printed page 626. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=640).

The method has the stated geometric objective-gap guarantee and a computable stopping certificate. The stronger assertion that its whole sequence must converge to one optimal point is false under the given assumptions, even with a twice continuously differentiable convex objective, a compact feasible set, and a unique analytic center at every level. We first prove the guarantees and then give a self-contained counterexample to that stronger wording.

## Contraction of the objective upper bound
For a centered iterate $`x=z_*(u)`$, Exercise 11.10 gives its central parameter
```math
t=\frac1{u-f_0(x)}.
```
Its nonnegative dual multipliers are $`\lambda_i=1/[t(-f_i(x))]`$, and stationarity makes $`x`$ minimize their convex Lagrangian. Hence weak duality gives
```math
0\le f_0(x)-p^\star\le\frac mt=m(u-f_0(x)).\tag{1}
```
Rearranging yields $`(m+1)f_0(x)\le m u+p^\star`$. Therefore the update obeys
```math
\begin{aligned}
u^+-p^\star
&=\theta(u-p^\star)+(1-\theta)(f_0(x)-p^\star)\\
&\le\frac{m+\theta}{m+1}(u-p^\star).
\end{aligned}\tag{2}
```
The factor is strictly below one. Also $`u^+-f_0(x)=\theta(u-f_0(x))>0`$, so the current point is strictly feasible for the next centering problem. The initial point need not be centered; (2) applies beginning with the first computed center. Consequently
```math
u^{(k)}\downarrow p^\star,\qquad f_0(x^{(k)})\longrightarrow p^\star.
```

## A stopping criterion using only computed quantities
From (1), stop when
```math
m\bigl(u-f_0(x)\bigr)\le\epsilon.
```
Equivalently, using the next scalar update, stop when $`m(u-u^+)/(1-\theta)\le\epsilon`$. A certified lower bound is $`f_0(x)-m(u-f_0(x))`$; subtracting it from the current feasible value gives exactly the displayed certificate. These certificates require a centered iterate, or a separately validated dual point if numerical centering is inexact.

If the iterates lie in a compact feasible sublevel set and the objective is continuous there, every accumulation point is optimal: pass to a convergent subsequence and use the vanishing value gap. Their distance to the optimal set tends to zero, since otherwise a subsequence at distance at least a fixed positive number would have an optimal accumulation point. If the optimizer is unique, compactness then gives convergence of the entire sequence to it. A distinct argument or assumption is necessary when there are multiple optimizers, as the example below proves.

## Counterexample satisfying unique-center existence
Use variables $`(\xi,\eta)`$ and the convex open objective domain $`|\xi|<2`$. Define
```math
f_0(\xi,\eta)=
\begin{cases}
\eta^4\bigl[(\xi-\sin(\log\eta))^2+20\bigr],&\eta>0,\\
0,&\eta\le0.
\end{cases}\tag{3}
```
Impose the four affine inequalities
```math
-1\le\xi\le1,\qquad0\le\eta\le1.\tag{4}
```
The compact feasible set lies strictly inside the objective's horizontal domain. Its optimal value is zero and its optimizer set is $`[-1,1]\times\{0\}`$.

We verify convexity and smoothness, not merely a numerical oscillation. For $`\eta>0`$ put $`b=\sin(\log\eta)`$, $`c=\cos(\log\eta)`$, and $`a=\xi-b`$. The horizontal second derivative is $`2\eta^4>0`$. The Schur complement of that entry in the Hessian is
```math
f_{\eta\eta}-\frac{f_{\xi\eta}^2}{f_{\xi\xi}}
=\eta^2\bigl(240-20a^2+2a(b+c)\bigr).
```
On $`|\xi|<2`$, $`|a|<3`$ and $`|b+c|\le\sqrt2`$, so this is at least
```math
\eta^2(240-180-6\sqrt2)>0.
```
The Hessian is therefore positive definite above the axis. Below the axis it is zero. Every derivative through order two of the positive-side expression has a factor at least $`\eta^2`$ times a bounded trigonometric polynomial, apart from fixed locally bounded horizontal factors. These derivatives tend to zero at the axis, agreeing with the zero extension. Thus $`f_0`$ is $`C^2`$ on its convex domain with PSD Hessian everywhere, and hence convex.

The barrier for (4) is
```math
\phi(\xi,\eta)=-\log(1-\xi^2)-\log\eta-\log(1-\eta).
```
It has positive-definite Hessian on the strict box and diverges at its boundary. For every $`u>0`$, the set $`f_0<u`$ contains strict-box points with sufficiently small positive $`\eta`$. The augmented objective $`-\log(u-f_0)+\phi`$ is strictly convex. It diverges both at the strict-box boundary and at the objective-bound boundary; its other terms are bounded below there. Thus its minimizer exists and is unique for every $`u>0`$, precisely the assumption in the question. The ordinary centering objectives $`t f_0+\phi`$ likewise have unique minimizers for every $`t>0`$.

## The actual fixed-parameter iteration does not converge
Run the specified method with $`\theta=1/2`$ from any allowed initialization. After its first centered iterate, the preceding contraction proof applies with $`m=4`$. Thus $`u_k\to0`$ and $`\eta_k\to0`$, the latter because $`20\eta_k^4\le f_0(\xi_k,\eta_k)<u_k`$.

At any centered point put $`v=t\eta^4>0`$. The two stationarity equations, the second multiplied by $`\eta`$, are
```math
\frac{\xi}{1-\xi^2}=v(b-\xi),\qquad
vD=R,\quad
D=4(a^2+20)-2ac,\quad R=\frac{1-2\eta}{1-\eta}.\tag{5}
```
Eventually $`0<\eta\le1/10`$. On this region $`|a|\le2`$, hence $`76\le D\le100`$, while $`8/9\le R<1`$. In particular
```math
\frac1{120}\le v\le\frac1{76}.
```
Since $`u=f_0+1/t`$,
```math
u=\eta^4 B,\qquad
B=a^2+20+1/v,\qquad96\le B\le144.\tag{6}
```
The scalar update gives $`u_{k+1}=(u_k+f_0(x_k))/2\ge u_k/2`$. Combining this with (6) at consecutive sufficiently late iterates yields
```math
\eta_{k+1}^4=\frac{u_{k+1}}{B_{k+1}}
\ge\frac{u_k}{2\cdot144}
=\frac{B_k\eta_k^4}{288}
\ge\frac{96}{288}\eta_k^4=\tfrac13\eta_k^4.
```
Taking logarithms gives
```math
\log\eta_k-\log\eta_{k+1}\le\tfrac14\log3<\pi/3.\tag{7}
```
Yet $`\log\eta_k\to-\infty`$. Such a sequence must visit infinitely many bands where its sine is at least $`1/2`$, and infinitely many where it is at most $`-1/2`$: each corresponding logarithmic phase band has width $`2\pi/3`$, larger than the largest downward jump allowed by (7). More explicitly, at the first downward crossing of a band's upper endpoint, the new point cannot jump past the band's lower endpoint. These crossings occur for arbitrarily negative bands because the logarithms tend to minus infinity. Monotonicity of the logarithm sequence is not needed.

When $`b\ge1/2`$, the first equation in (5) forces $`\xi>0`$. If $`\xi\ge1/4`$ it is certainly at least $`1/512`$. Otherwise $`b-\xi\ge1/4`$, so
```math
\frac{16}{15}\xi\ge\frac{\xi}{1-\xi^2}
=v(b-\xi)\ge\frac1{480},
```
and again $`\xi\ge1/512`$. Reflecting the signs gives $`\xi\le-1/512`$ whenever $`b\le-1/2`$. Therefore infinitely many iterates satisfy each of these separated horizontal bounds, while all have $`\eta_k\to0`$. The sequence cannot have one point limit.

This explicit example disproves the unqualified point-convergence phrase for the actual iteration with a permitted fixed parameter. It retains the valid conclusions (1)–(2), the stopping certificate, and convergence to the optimal set. Unique optimality or another condition ensuring a central-path limit restores the stronger conclusion.
