# Exercise 4.9: A square inequality-form linear program

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.9](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=207). The source exercise and all of its subparts were checked directly.

Set $`y=Ax`$ and $`d=A^{-T}c`$. Nonsingularity makes this a bijective change of variables. The problem becomes

```math
\mathrm{minimize}\quad d^Ty\qquad\mathrm{subject\ to}\quad y\preceq b.
```

If $`d\preceq0`$, each product satisfies $`d_i y_i\ge d_i b_i`$. The point $`y=b`$ therefore attains the value $`d^Tb=c^TA^{-1}b`$. More completely, every optimizer has $`y_i=b_i`$ wherever $`d_i<0`$, with arbitrary $`y_i\le b_i`$ where $`d_i=0`$; recover $`x=A^{-1}y`$.

If some $`d_j>0`$, the feasible ray $`y=b-te_j`$ has objective $`d^Tb-td_j\to-\infty`$. Thus the value is $`-\infty`$ and the optimal set is empty. Feasibility is never an issue because $`A^{-1}b`$ is feasible.

## Validation

The sign condition is nonpositivity because the feasible coordinates are bounded above, and the zero-coefficient case is explicitly retained.
