# Exercise 4.41: Semidefinite sufficient tests for copositivity and P0

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.41](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=216). The source exercise and all of its subparts were checked directly.

## (a) Copositive decomposition

If $`A=B+C`$, $`B\succeq0`$, and $`C`$ is entrywise nonnegative, then for every $`x\succeq0`$,

```math
x^TAx=x^TBx+\sum_{ij}C_{ij}x_ix_j\ge0.
```

This proves copositivity. An SDP feasibility test is to find a symmetric $`B`$ satisfying $`B\succeq0`$ and the scalar linear inequalities $`B_{ij}\le A_{ij}`$ for all entries; then set $`C=A-B`$. Equivalently retain both symmetric matrix variables with the affine equality $`A=B+C`$. Failure of this sufficient test does not by itself disprove copositivity.

## (b) Positive diagonal scaling

Let $`D=\mathrm{diag}(d)`$ with every $`d_i>0`$ and $`DA+A^TD\succeq0`$. For every $`x`$,

```math
0\le\tfrac12x^T(DA+A^TD)x=\sum_i d_i x_i(Ax)_i.
```

If every $`x_i(Ax)_i`$ were negative, the strictly positive weighted sum would be negative. Therefore at least one is nonnegative, which is precisely the P0 condition.

The strict positivity can be normalized away because the matrix inequality is homogeneous in $`D`$. If a positive $`d`$ works, scaling it by $`1/\min_i d_i`$ makes $`d_i\ge1`$ without affecting semidefiniteness. Thus the exact SDP feasibility test for such a certificate is

```math
\mathrm{diag}(d)A+A^T\mathrm{diag}(d)\succeq0,\qquad d_i\ge1\quad(i=1,\ldots,n).
```

Conversely any solution clearly gives a strictly positive diagonal certificate. The lower bounds also exclude the useless all-zero scaling.

## Validation

Both claims are sufficient conditions, not asserted characterizations. The P0 proof requires strictly positive weights, and the homogeneity normalization enforces them with closed affine constraints.
