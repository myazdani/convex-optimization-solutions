# Exercise 7.1: Exponential-noise maximum likelihood

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 7.1, printed page 393. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=407).

The independent noises are $`v_i=y_i-a_i^Tx`$. The likelihood is zero unless $`Ax\le y`$; on that set its logarithm is
```math
-m\log a-\frac1a\mathbf1^T(y-Ax).
```
Hence a maximum-likelihood estimate is any solution of the LP
```math
\text{maximize }\mathbf1^TAx\quad\text{subject to }Ax\le y.
```
Equivalently minimize the sum of the nonnegative residuals $`y-Ax`$. When feasible, this objective is bounded and an LP optimum is attained. If no $`x`$ satisfies the one-sided measurements, every likelihood is zero, so the data have no positive-likelihood fit under this model. Nonuniqueness, for example along the nullspace of $`A`$, is allowed.
