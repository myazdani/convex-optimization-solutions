# Exercise 4.40: Linear and conic programs as semidefinite programs

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.40](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=216). The source exercise and all of its subparts were checked directly.

## (a) Linear programming

For the general LP $`\min c^Tx+d`$ subject to $`Gx\preceq h`$, $`Ax=b`$, replace the inequalities by

```math
\mathrm{diag}(h-Gx)\succeq0.
```

Keep the affine equations, or encode each as two scalar LMIs. This preserves the problem exactly.

## (b) Quadratic and second-order-cone programming

For any convex quadratic $`f_i(x)=\tfrac12x^TP_ix+q_i^Tx+r_i`$, choose $`R_i`$ with $`R_i^TR_i=P_i/2`$. Its epigraph $`f_i(x)\le t_i`$ is equivalent to

```math
\begin{bmatrix}
t_i-q_i^Tx-r_i&(R_ix)^T\\
R_ix&I
\end{bmatrix}\succeq0,
```

by the Schur complement of the identity. For a QP, introduce an objective bound $`t_0`$, minimize it, impose this LMI for its objective, and retain the affine constraints. For a QCQP, also use the same LMI with $`t_i=0`$ for each quadratic inequality, retaining the affine equations. Singular $`P_i`$ causes no difficulty because only a square-root factor, not its inverse, is used.

For an SOCP constraint $`\|A_ix+b_i\|_2\le c_i^Tx+d_i`$, let $`v=A_ix+b_i`$ and $`s=c_i^Tx+d_i`$. The equivalent LMI is

```math
\begin{bmatrix}sI&v\\v^T&s\end{bmatrix}\succeq0.
```

Its eigenvalues include $`s\pm\|v\|_2`$, so the equivalence also holds at $`s=0`$. Retain the linear objective and equations to obtain an SDP. All epigraph variables are tight at an optimum where they enter the minimized objective positively.

## (c) Matrix-fractional objective, with its strict domain

Put $`a(x)=Ax+b`$. On $`F(x)\succ0`$, Schur complementation gives

```math
\begin{bmatrix}F(x)&a(x)\\a(x)^T&t\end{bmatrix}\succeq0
\quad\Longleftrightarrow\quad t\ge a(x)^TF(x)^{-1}a(x).
```

To retain the strict original domain using only non-strict LMIs, introduce a symmetric auxiliary matrix $`S`$ and solve the SDP

```math
\begin{aligned}
\mathrm{minimize}\quad&t\\
\mathrm{subject\ to}\quad&
\begin{bmatrix}F(x)&a(x)\\a(x)^T&t\end{bmatrix}\succeq0,\qquad
\begin{bmatrix}F(x)&I\\I&S\end{bmatrix}\succeq0.
\end{aligned}
```

The second block forces $`F(x)\succ0`$: its principal block is positive semidefinite, and if $`F(x)v=0`$, positivity of the whole quadratic form implies $`(v,0)`$ is in its kernel, whose lower block would be $`v=0`$. Conversely, if $`F(x)\succ0`$, taking $`S=F(x)^{-1}`$ satisfies that block. Thus it enforces the strict domain exactly after projection. Every original point has an exact epigraph lift; every SDP point projects to an original-domain point with objective at most $`t`$. Values and optimizer recovery are exact even when an infimum is unattained.

Simply keeping the first block would admit singular boundary matrices and could create extra attained optima outside the stated domain. The extra block avoids that closure issue.

## Validation

Every displayed block is affine in all decision variables. The source's strictly positive-definite matrix domain is retained exactly rather than silently closed.
