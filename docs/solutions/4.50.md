# Exercise 4.50: Reading a least-squares trade-off figure

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.50](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=219). The source exercise and all of its subparts were checked directly.

The relevant plot is [Figure 4.11, printed page 185](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=199). Both plotted coordinates are squared norms: $`F_1=\|Ax-b\|_2^2`$ and $`F_2=\|x\|_2^2`$. This matters because the introductory line of the exercise omits the square on its first norm, while the actual figure and the following questions use the squared residual.

The marked endpoints read approximately $`(F_1,F_2)=(2,9)`$ for least squares and $`(10,0)`$ for the zero vector. The remaining numbers below are graphical estimates, not exact values inferred from unavailable matrix data.

## (a) Least-squares solution norm

The vertical coordinate at the least-squares point is approximately nine, so $`\|x_{\mathrm{ls}}\|_2\approx3`$.

## (b) Least-squares residual norm

The horizontal coordinate there is approximately two, so $`\|Ax_{\mathrm{ls}}-b\|_2\approx\sqrt2`$.

## (c) Norm of the data vector

At the only point with $`F_2=0`$ we have $`x=0`$, so $`F_1=\|b\|_2^2\approx10`$. Thus $`\|b\|_2\approx\sqrt{10}`$.

## (d) Unit-norm equality constraint

Intersect the achievable set with the horizontal line $`F_2=1`$ and take its leftmost point. The optimal squared residual is approximately $`5.5`$.

## (e) Unit-ball inequality constraint

The leftmost achievable point with $`F_2\le1`$ lies on that same horizontal boundary, because the decreasing trade-off curve has not yet reached its unconstrained least-squares endpoint at $`F_2=9`$. The optimum is again approximately $`5.5`$.

## (f) Sum of squared residual and squared norm

Slide the line $`F_1+F_2=c`$ toward the lower left until it first touches the shaded set. Its slope is minus one in the plotted coordinate units. The minimum is approximately $`6.2`$, with contact near $`(3.9,2.25)`$.

## (g) Rank

The figure shows only one attainable point at the minimum residual coordinate, rather than a vertical ray. If $`\ker A`$ contained a nonzero $`v`$, the minimum-norm least-squares solution would satisfy $`x_{\mathrm{ls}}\perp v`$, and $`x_{\mathrm{ls}}+tv`$ would give the same residual for every $`t`$ but squared norm $`\|x_{\mathrm{ls}}\|_2^2+t^2\|v\|_2^2`$. All points vertically above the least-squares endpoint would then be achievable, contrary to the boundary shown. Thus the intended plotted instance has full column rank, namely ten.
