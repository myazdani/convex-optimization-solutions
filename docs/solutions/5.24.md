# Exercise 5.24: The weak max-min inequality

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.24](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=295). The source exercise and all of its subparts were checked directly.

For any $`w\in W`$ and $`z\in Z`$,

```math
\inf_{\widetilde w\in W}f(\widetilde w,z)
\le f(w,z)
\le\sup_{\widetilde z\in Z}f(w,\widetilde z).
```

In particular, for every fixed $`w`$, the rightmost quantity bounds the leftmost one for every $`z`$. Taking the supremum over $`z`$ and then the infimum over $`w`$ proves

```math
\sup_{z\in Z}\inf_{w\in W}f(w,z)
\le\inf_{w\in W}\sup_{z\in Z}f(w,z).
```

No continuity, convexity, compactness, or attainment is used. With standard empty-set conventions the claim also holds for empty domains: if $`Z`$ is empty and $`W`$ nonempty, both sides are $`-\infty`$; if $`W`$ is empty and $`Z`$ nonempty, both are $`+\infty`$; if both are empty the inequality is $`-\infty\le+\infty`$.

## Validation

The proof only orders quantities and takes monotone extrema, avoiding any undefined extended-real subtraction.
