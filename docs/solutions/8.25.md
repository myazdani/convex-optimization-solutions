# Exercise 8.25: A separating ellipsoid of minimum eccentricity

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.25, printed page 451. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=465).

Describe the ellipsoid by a positive-definite quadratic $`q(z)=z^TPz+h^Tz+r`$ and $`E=\{z:q(z)\le0\}`$. Multiplying all its coefficients by a positive scalar changes neither the set nor the condition number of $`P`$. Thus normalize its smallest eigenvalue to one and solve the SDP
```math
\begin{array}{ll}
\text{minimize}&t\\
\text{subject to}&I\preceq P\preceq tI,\\
&x_i^TPx_i+h^Tx_i+r\le0,\quad i=1,\ldots,N,\\
&y_j^TPy_j+h^Ty_j+r\ge0,\quad j=1,\ldots,M.
\end{array}
```
Every scalar inequality is affine in $`P,h,r`$. Any genuine separating ellipsoid can be scaled into this program with $`t=\kappa(P)`$. Conversely every feasible point has $`\kappa(P)\le t`$, proving equality of the optimal infima. The outside constraints allow the negative samples on the boundary, exactly as requested.

Complete the square to recover center $`c=-\tfrac12P^{-1}h`$ and radius parameter $`R^2=\tfrac14h^TP^{-1}h-r`$. If the positive class contains two distinct points, strict convexity of $`q`$ at their midpoint ensures $`R^2>0`$, so the result is a genuine ellipsoid with shape matrix $`R^2P^{-1}`$ and condition number $`\kappa(P)`$.

If all positive samples equal one point $`x`$, the SDP may return the degenerate solution $`q(z)=(z-x)^TP(z-x)`$. It can be replaced, with unchanged $`P`$, by
```math
q_\epsilon(z)=(z-x)^TP(z-x)-2\epsilon v^TP(z-x),\qquad v\ne0.
```
For sufficiently small positive $`\epsilon`$, every finite negative sample unequal to $`x`$ still has positive value, samples equal to $`x`$ remain on the boundary, and $`R^2=\epsilon^2v^TPv>0`$. Thus degeneracy does not change the optimal eccentricity. With no positive samples, a small sphere away from the finite negative class already gives the optimal value one.
