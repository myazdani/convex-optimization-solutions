# Exercise 11.4: Uniform curvature from a Euclidean ball constraint

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 11.4, printed page 623. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=637).

For $`R>0`$ the added barrier is $`h(x)=-\log(R^2-\|x\|^2)`$, defined on $`\|x\|<R`$. Its Hessian is
```math
\nabla^2h(x)=\frac2{R^2-\|x\|^2}I
+\frac4{(R^2-\|x\|^2)^2}xx^T
\succeq\frac2{R^2}I.
```
Every other term of the convex centering objective has a PSD Hessian: for a convex constraint $`f_i<0`$,
```math
\nabla^2[-\log(-f_i)]
=\frac{\nabla^2f_i}{-f_i}+
\frac{\nabla f_i\nabla f_i^T}{f_i^2}\succeq0.
```
Adding $`t\nabla^2f_0\succeq0`$ proves that $`a=2/R^2`$ is a valid uniform lower bound, at every strictly feasible point where the barrier is defined. The barrier Hessian is not defined on the ball boundary; “all feasible points” in this statement must refer to the strict barrier domain.
