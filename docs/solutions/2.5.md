# Exercise 2.5: Distance between parallel hyperplanes

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.5, p. 60](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=74).

Original solution.

Assume $`a\ne0`$, as required for these sets to be hyperplanes. For points $`x_1,x_2`$ on the two hyperplanes, Cauchy–Schwarz gives
```math
|b_2-b_1|=|a^T(x_2-x_1)|\le\|a\|_2\|x_2-x_1\|_2.
```
Equality is attainable: choose any $`x_1`$ on the first hyperplane and put $`x_2=x_1+(b_2-b_1)a/\|a\|_2^2`$. Thus their distance is
```math
\frac{|b_2-b_1|}{\|a\|_2}.
```
In particular, it is zero for coincident hyperplanes. If $`a=0`$, the sets are instead empty or all of $`\mathbb R^n`$, and the hyperplane formula does not apply.
