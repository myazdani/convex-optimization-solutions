# Exercise 8.16: Maximum-volume axis-aligned rectangle

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.16, printed page 449. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=463).

Write the rectangle as $`c+\{z:|z_j|\le h_j\}`$, where $`c=(u+l)/2`$ and $`h=(u-l)/2\ge0`$. For a row $`a_i^T`$,
```math
\max_{x\in R}a_i^Tx=a_i^Tc+\sum_j|a_{ij}|h_j.
```
Hence containment is exactly $`Ac+|A|h\le b`$, with entrywise absolute value. For a positive-volume rectangle solve
```math
\text{maximize }\sum_{j=1}^n\log h_j
\quad\text{subject to }Ac+|A|h\le b,\quad h\succ0.
```
This is convex optimization (concave maximization with affine constraints), using $`m`$ inequalities rather than enumerating $`2^n`$ vertices. Recover $`l=c-h,u=c+h`$. The omitted volume factor $`2^n`$ is constant. If no strictly positive $`h`$ is feasible, the polyhedron contains no positive-volume rectangle; any feasible degenerate rectangle has volume zero. Unboundedness of the objective correctly signals arbitrarily large enclosed rectangles.
