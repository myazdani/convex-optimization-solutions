# Exercise 2.18: Inverse of a nonsingular linear-fractional map

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.18, p. 62](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=76).

Original solution.

Partition the inverse of the given homogeneous-coordinate matrix as
```math
Q^{-1}=\begin{bmatrix}E&f\\g^T&h\end{bmatrix}.
```
For $`y=(Ax+b)/(c^Tx+d)`$ with $`\tau=c^Tx+d>0`$, homogeneous coordinates satisfy
```math
\begin{bmatrix}y\\1\end{bmatrix}
=\frac1\tau Q\begin{bmatrix}x\\1\end{bmatrix},
\qquad
\begin{bmatrix}Ey+f\\g^Ty+h\end{bmatrix}
=\frac1\tau\begin{bmatrix}x\\1\end{bmatrix}.
```
Therefore $`g^Ty+h=1/\tau>0`$ and
```math
f^{-1}(y)=\frac{Ey+f}{g^Ty+h},
\qquad \mathrm{dom}\,f^{-1}=\{y:g^Ty+h>0\}.
```
Here the block vector $`f`$ is distinguished from the original map by context. To verify that this is the entire inverse domain, start with any $`y`$ satisfying the displayed strict inequality and call its denominator $`\sigma`$. Multiplication by $`Q`$ gives
$`Q[x;1]=[y;1]/\sigma`$, so $`c^Tx+d=1/\sigma>0`$ and the original map sends $`x`$ to $`y`$. This proves surjectivity onto that halfspace and uniqueness, hence invertibility between the stated domains. Empty-domain cases, if allowed by the data, are also correctly represented by these formulas.
