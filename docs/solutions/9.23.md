# Exercise 9.23: Precomputations for efficient line searches

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.23, printed page 518. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=532).

We count dense arithmetic and let $`v=\Delta x`$. Values already cached at the current iterate can only reduce the stated setup costs.

## (a) Logarithms of affine slacks
Precompute $`s=b-Ax`$ and $`q=Av`$ in $`O(mn)`$ operations. Then
```math
g(t)=-\sum_i\log(s_i-tq_i),\qquad
g'(t)=\sum_i\frac{q_i}{s_i-tq_i},
```
with the domain test $`s-tq\succ0`$. Both evaluations cost $`O(m)`$ after setup. Without precomputation, forming the affine quantities costs $`O(mn)`$ at each trial, for both objective and derivative.

## (b) Log-sum-exp
Precompute $`a=Ax+b`$ and $`q=Av`$ in $`O(mn)`$. Then
```math
g(t)=\log\sum_i e^{a_i+tq_i},\qquad
g'(t)=\frac{\sum_iq_i e^{a_i+tq_i}}{\sum_i e^{a_i+tq_i}}.
```
Both cost $`O(m)`$, versus $`O(mn)`$ without setup. Subtract $`\max_i(a_i+tq_i)`$ before exponentiating for numerical stability, adding it back only to the log-sum-exp value.

## (c) Matrix-fractional objective
Initially form
```math
M=P_0+\sum_jx_jP_j\succ0,\quad N=\sum_jv_jP_j,
\quad r=Ax-b,\quad s=Av.
```
This costs $`O(nm^2+mn)`$. A basic trial evaluation factors $`M+tN`$ and solves $`z=(M+tN)^{-1}(r+ts)`$, giving
```math
g(t)=(r+ts)^Tz,\qquad g'(t)=2s^Tz-z^TNz.
```
Its cost is $`O(m^3)`$ for the factorization plus $`O(m^2)`$ for value/derivative. Without setup each trial also pays $`O(nm^2+mn)`$ for assembly.

A stronger one-time precomputation reduces each trial to linear cost. Compute $`M=LL^T`$, diagonalize the symmetric pencil $`L^{-1}NL^{-T}=U\mathrm{diag}(\lambda)U^T`$, and set $`a=U^TL^{-1}r`$, $`b=U^TL^{-1}s`$. The additional cost is $`O(m^3)`$. Then
```math
g(t)=\sum_i\frac{(a_i+tb_i)^2}{1+t\lambda_i},
\qquad
g'(t)=\sum_i\left[\frac{2b_i(a_i+tb_i)}{1+t\lambda_i}
-\frac{\lambda_i(a_i+tb_i)^2}{(1+t\lambda_i)^2}\right].
```
The domain is exactly $`1+t\lambda_i>0`$ for all $`i`$. Each value, derivative, and feasibility test now costs $`O(m)`$, after total setup $`O(nm^2+mn+m^3)`$. No simultaneous diagonalizability of the original $`P_i`$ is assumed; only the single search-direction pencil is whitened and diagonalized.
