# Exercise 2.22: Separation without a closest pair

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.22, p. 63](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=77).

Original solution.

Assume $`C,D`$ are nonempty disjoint convex sets. Their difference $`S=C-D`$ is nonempty and convex, and $`0\notin S`$. We first find a nonzero $`a`$ with $`a^Ts\ge0`$ on $`S`$.

Put $`T=\mathrm{cl}\,S`$. If $`0\notin T`$, a nearest point $`p\in T`$ to zero exists: intersect a minimizing sequence with a sufficiently large closed ball and use compactness. It is nonzero. For every $`s\in T`$, differentiation at zero along the segment $`p+t(s-p)`$ gives $`p^T(s-p)\ge0`$. Thus $`a=p`$ works, indeed $`a^Ts\ge\|p\|^2>0`$.

Suppose now $`0\in T`$. If $`T`$ lies in a proper affine subspace, that subspace contains zero and is linear. Any nonzero vector perpendicular to it gives $`a^Ts=0`$, as needed.

Otherwise $`T`$ has full dimension. We need the elementary fact that an interior point of the closure of a full-dimensional convex set belongs to the set itself. To see this, place a small simplex around the interior point, with that point strictly inside it and all vertices in the closure. Approximate the finitely many vertices by points in the set. Sufficiently small perturbations retain the point in the simplex interior (the barycentric coordinates depend continuously on its affinely independent vertices). Convexity then puts the point in the set. Hence $`0\notin S`$ implies that zero is a boundary point of $`T`$.

Choose $`z_j\notin T`$ with $`z_j\to0`$, and let $`p_j`$ be a closest point of $`T`$ to $`z_j`$. Since $`0\in T`$, $`\|p_j-z_j\|\le\|z_j\|`$, so $`p_j\to0`$. The projection inequality is
```math
(p_j-z_j)^T(s-p_j)\ge0\qquad(s\in T).
```
Set $`a_j=(p_j-z_j)/\|p_j-z_j\|`$. A subsequence converges to a unit vector $`a`$. Taking limits for each fixed $`s\in T`$ gives $`a^Ts\ge0`$.

Finally $`a^T(c-d)\ge0`$ for every $`c\in C,d\in D`$. Therefore
```math
\sup_{d\in D}a^Td\le\inf_{c\in C}a^Tc.
```
Both bounds are finite: fix one point in each nonempty set to bound the opposite set's values. Choose any real $`b`$ between them. Then $`a^Td\le b\le a^Tc`$ separates the sets. Replacing $`a,b`$ by their negatives gives the orientation in the textbook.
