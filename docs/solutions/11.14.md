# Exercise 11.14: Positive curvature of centering problems: the equality qualification

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 11.14, printed page 627. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=641).

With no equality constraints, the intended conclusion follows as follows. Let $`F=tf_0+\phi`$. Exercise 11.3 makes its sublevel sets bounded, and Exercise 9.17 makes the nullspace of its Hessian independent of the point. If a nonzero null direction $`v`$ existed, the restriction of $`F`$ to any domain line parallel to $`v`$ would be affine. Closedness and the open differentiable domain force that line's domain interval to extend infinitely in both directions: at any finite endpoint the affine values have a finite limit, whereas the closed extension would be infinite outside the domain. An affine function on a full line has an unbounded nonempty sublevel set, contradicting boundedness. Thus $`\nabla^2F\succ0`$ everywhere.

However problem (11.1) includes equalities $`Ax=b`$. Bounded feasible sublevels then give this conclusion only on feasible directions, not in the full ambient space. A counterexample to the literal full-Hessian claim is
```math
f_0(x)=0,\qquad f_1(x)=x_1-1,\quad f_2(x)=-x_1-1,
\qquad x_2=0.
```
The original feasible set $`[-1,1]\times\{0\}`$ is bounded. Its centering function
```math
F(x)=-\log(1-x_1)-\log(1+x_1),\qquad |x_1|<1,
```
is closed and self-concordant, but its Hessian has a zero $`x_2`$ row and column everywhere.

The correct statement with equalities is
```math
v^T\nabla^2F(x)v>0\quad\text{for every nonzero }v\in\ker A,
```
or equivalently $`N^T\nabla^2F(x)N\succ0`$ for a full-column-rank nullspace basis $`N`$. Apply the preceding proof to $`\widetilde F(z)=F(x_0+Nz)`$: its sublevel sets are bounded by 11.3, it is closed under this affine substitution, and it is self-concordant. Alternatively a fixed full-space null direction in $`\ker A`$ would create an unbounded feasible affine line exactly as above. This is also precisely the curvature required for a nonsingular centering KKT system when $`A`$ has full row rank. Thus the unqualified printed statement needs either elimination of equalities or a stronger full-space boundedness assumption.
