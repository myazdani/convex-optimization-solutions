# Exercise 4.58: Consumption planning with concave returns

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.58](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=222). The source exercise and all of its subparts were checked directly.

Introduce capital variables $`k_1,\ldots,k_{T+1}`$ in addition to nonnegative consumptions, with the supplied $`k_0`$ fixed. Solve

```math
\begin{aligned}
\mathrm{maximize}\quad&\sum_{t=0}^{T}\beta^t u(c_t)\\
\mathrm{subject\ to}\quad&c_t\ge0,\quad k_{t+1}\ge0,\\
&k_{t+1}+c_t-k_t-f(k_t)\le0,
\quad t=0,\ldots,T.
\end{aligned}
```

The objective is concave, since every positive discount weight multiplies a concave utility. Each dynamic inequality is convex because $`-f`$ is convex and the other terms are affine. This is a convex optimization problem.

Every original feasible trajectory satisfies these inequalities with equality, so it is a feasible lift with the same utility. Conversely take any relaxed feasible $`(c,k)`$. Keep exactly the same consumptions, and reconstruct actual capital by

```math
\widehat k_0=k_0,\qquad
\widehat k_{t+1}=\widehat k_t+f(\widehat k_t)-c_t.
```

Since $`a\mapsto a+f(a)`$ is nondecreasing, induction gives $`\widehat k_t\ge k_t`$: it is true initially, and then

```math
\widehat k_{t+1}\ge k_t+f(k_t)-c_t\ge k_{t+1}\ge0.
```

Thus the reconstructed trajectory is original-feasible with identical utility. The feasible consumption vectors, optimal values, and optimal consumptions are exactly the same, even if utility is only nondecreasing and a relaxed optimizer discards money.

If utility is strictly increasing, no optimal relaxed trajectory can have slack in a dynamic inequality: increasing just that period's consumption by part of the slack leaves all capital variables and other constraints unchanged and improves utility. Likewise an optimum has zero final capital, since otherwise final consumption can be raised. Neither extra assertion is needed for the equivalence proof.

## Validation

The recovery map preserves consumption and recomputes capital, avoiding an unsupported claim that all relaxed inequalities must be active under weakly increasing utility.
