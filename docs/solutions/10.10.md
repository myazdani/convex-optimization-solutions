# Exercise 10.10: A uniformly bounded inverse for a strongly convex-concave game

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 10.10, printed page 559. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=573).

Let $`r=(\nabla_u f,-\nabla_v f)`$. Its Jacobian is
```math
J=Dr=\begin{bmatrix}f_{uu}&f_{uv}\\-f_{uv}^T&-f_{vv}\end{bmatrix}.
```
The symmetric part is $`\mathrm{diag}(f_{uu},-f_{vv})\succeq mI`$ because the off-diagonal parts cancel. For every vector $`h`$,
```math
m\|h\|^2\le h^TJh\le\|h\|\,\|Jh\|.
```
Thus $`\|Jh\|\ge m\|h\|`$, so $`J`$ is nonsingular and $`\|J^{-1}\|_2\le1/m`$. Finally $`J=\mathrm{diag}(I,-I)\nabla^2f`$, where the left factor is orthogonal. It preserves singular values, yielding $`\|\nabla^2f^{-1}\|_2=\|J^{-1}\|_2\le1/m`$. The Hessian is indefinite in general; the argument bounds its singular values rather than incorrectly treating it as positive definite.
