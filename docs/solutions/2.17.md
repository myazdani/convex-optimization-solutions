# Exercise 2.17: Perspective images of polyhedral sets

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.17, p. 62](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=76).

Original solution.

Write the image point as $`z=v/t`$ and set $`s=1/t>0`$.

## (a) Convex hull with positive last coordinates

The image is $`\mathrm{conv}\{v_i/t_i:i=1,\ldots,K\}`$. Indeed, a combination with weights $`\theta_i`$ maps to a combination of $`v_i/t_i`$ with weights
```math
\alpha_i=\frac{\theta_i t_i}{\sum_j\theta_jt_j}.
```
Conversely, given weights $`\alpha_i`$, choose $`\theta_i=(\alpha_i/t_i)/(\sum_j\alpha_j/t_j)`$; these recover the desired image.

## (b) Hyperplane

The equality becomes $`f^Tz+g=hs`$ with $`s>0`$. Hence the image is
```math
\begin{cases}
\{z:f^Tz+g>0\},&h>0,\\
\{z:f^Tz+g=0\},&h=0,\\
\{z:f^Tz+g\lt 0\},&h\lt 0.
\end{cases}
```
These formulas also handle $`f=0`$: the displayed set is then empty or all of space as determined by the scalar condition.

## (c) Halfspace

Now $`f^Tz+g\le hs`$. If $`h>0`$, sufficiently large $`s`$ works for every $`z`$, so the image is $`\mathbb R^n`$. If $`h=0`$, the image is $`\{z:f^Tz+g\le0\}`$. If $`h<0`$, existence of positive $`s`$ is equivalent to $`f^Tz+g<0`$: choose $`s\le(f^Tz+g)/h`$.

## (d) Polyhedron

A direct linear-inequality description with one eliminated scalar is
```math
P(C)=\{z:\text{there exists }s>0\text{ with }Fz+g\le sh\}.
```
For an explicit description in $`z`$ alone, let $`u_i=F_{i,:}z+g_i`$. Its necessary and sufficient conditions are
```math
u_i\le0\quad(h_i=0),\qquad
u_j\lt 0\quad(h_j\lt 0),\qquad
\frac{u_i}{h_i}\le\frac{u_j}{h_j}\quad(h_i>0,\ h_j\lt 0).
```
To prove sufficiency, the positive-$`h`$ rows impose lower bounds on $`s`$, and the negative-$`h`$ rows impose upper bounds. All upper bounds are strictly positive by the second condition, and each lower bound is no larger than each upper bound by the third. Thus a positive $`s`$ between them exists. If there are no upper bounds, take $`s`$ sufficiently large; if there are no lower bounds, take a sufficiently small positive $`s`$. Necessity follows immediately from such an $`s`$. The mixed inequalities are affine after multiplying by the fixed nonzero denominators. Strict inequalities are essential: perspective images need not be closed polyhedra.
