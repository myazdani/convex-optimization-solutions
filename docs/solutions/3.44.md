# Exercise 3.44: Rank-one updates and bordered-Hessian inertia

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.44, p. 121](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=135).

Original solution.

At the fixed point write $`B=\nabla^2f(x)`$ and $`a=\nabla f(x)`$. The weak condition (3.21) is $`z^TBz\ge0`$ whenever $`a^Tz=0`$; the strict condition (3.22) replaces it by $`>0`$ for nonzero such $`z`$.

## (a) Rank-one updates

If $`B+\sigma aa^T\succeq0`$, then on $`a^Tz=0`$ its quadratic form is exactly $`z^TBz`$, proving the weak sufficient condition. The same observation gives necessity of the strict tangent condition from a positive definite update.

Conversely suppose the strict tangent condition holds. If $`a=0`$, it says $`B\succ0`$, so any update parameter works. Otherwise choose an orthonormal basis in which $`a=(0,\ldots,0,\gamma)`$, $`\gamma>0`$, and write
```math
B=\begin{bmatrix}C&b\\b^T&d\end{bmatrix}.
```
The tangent condition says $`C\succ0`$. The update is positive definite precisely when
```math
d+\sigma\gamma^2-b^TC^{-1}b>0,
```
by the Schur complement. A sufficiently large $`\sigma`$ satisfies this. When the tangent space has dimension zero, the condition is vacuous and the same statement reduces to choosing the scalar update positive.

The weak implication need not be reversible: with $`B=\begin{bmatrix}0&1\\1&0\end{bmatrix}`$ and $`a=e_2`$, the tangent quadratic form is zero, but the determinant of every updated matrix is $`-1`$.

## (b) Bordered-matrix characterization

If $`a=0`$, the bordered matrix is $`\mathrm{diag}(B,0)`$. Thus the weak tangent condition is exactly $`B\succeq0`$, and having exactly one nonpositive eigenvalue is exactly $`B\succ0`$.

For $`a\ne0`$, use the basis from (a). The bordered matrix has quadratic form, on variables $`(u,v,w)`$,
```math
u^TCu+2v b^Tu+dv^2+2\gamma vw.
```
The invertible variable substitution
$`\widehat w=w+b^Tu/\gamma+dv/(2\gamma)`$ reduces it to
```math
u^TCu+2\gamma v\widehat w.
```
By invariance of inertia under invertible congruence, its positive/negative/zero counts equal those of $`C`$ plus one positive and one negative eigenvalue. Consequently it has exactly one negative eigenvalue if and only if $`C\succeq0`$, which is the weak tangent condition. It has exactly one nonpositive eigenvalue if and only if $`C\succ0`$, which is the strict tangent condition. This handles singular tangent blocks without assuming an inverse in the weak case.
