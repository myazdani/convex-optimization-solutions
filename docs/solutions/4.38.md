# Exercise 4.38: One-variable LMIs by simultaneous congruence

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.38](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=215). The source exercise and all of its subparts were checked directly.

## (a) Generalized eigenvalues

Congruence gives

```math
\det(\lambda B-A)=\det(R)^{-2}\prod_i(\lambda b_i-a_i).
```

Since $`B`$ and $`R`$ are nonsingular, every $`b_i\ne0`$. Hence all $`n`$ roots, counted with multiplicity, are the real values $`a_i/b_i`$.

## (b) The feasible interval and optimum

Congruence preserves semidefinite order, so $`tB\preceq A`$ is equivalent to $`tb_i\le a_i`$ for every $`i`$. Define

```math
L=\max_{i:b_i<0}\frac{a_i}{b_i},\qquad
U=\min_{i:b_i>0}\frac{a_i}{b_i},
```

with $`L=-\infty`$ if its index set is empty and $`U=+\infty`$ if its index set is empty. The feasible set is the closed interval or half-line $`[L,U]\cap\mathbb R`$.

If $`L>U`$, the problem is infeasible and its value is $`+\infty`$. Otherwise:

- If $`c>0`$ and $`L`$ is finite, the optimizer is $`t=L`$ and the value is $`cL`$. If $`L=-\infty`$, the value is $`-\infty`$ and no optimizer exists.
- If $`c<0`$ and $`U`$ is finite, the optimizer is $`t=U`$ and the value is $`cU`$. If $`U=+\infty`$, the value is $`-\infty`$ and no optimizer exists.
- If $`c=0`$, every feasible real $`t`$ is optimal with value zero.

The endpoint formulas also cover the singleton case $`L=U`$.

## Validation

Negative diagonal entries reverse the scalar bound direction; mixed signs, missing bounds, infeasibility, and a zero objective coefficient are all included.
