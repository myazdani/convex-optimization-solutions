# Exercise 8.10: Minimax fitting of vector angles

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.10, printed page 448. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=462).

Normalize $`z_i`$ to $`v_i=z_i/\|z_i\|_2`$. For a fixed angle bound $`0\le\theta<\pi/2`$, a nonzero vector satisfies that bound exactly when
```math
\cos\theta\,\|A_ix+b_i\|_2\le v_i^T(A_ix+b_i),
\qquad v_i^T(A_ix+b_i)>0.\tag{1}
```
These are convex constraints for fixed $`\theta`$. Hence the minimax problem on its acute-angle region is quasiconvex and can be solved by bisection on $`\theta`$. If the other constraints are linear inequalities, each test is an SOCP. To handle the strict nonzero requirement reliably as a mathematical feasibility question, add a common variable $`0\le\delta\le1`$, replace each strict right-hand projection by $`v_i^T(A_ix+b_i)\ge\delta`$, and maximize $`\delta`$. A positive achievable value is equivalent to (1).

The endpoint $`\theta=\pi/2`$ needs care: its angular inequality is merely $`v_i^T(A_ix+b_i)\ge0`$, and zero vectors must still be excluded because their angles are undefined. Let $`K`$ be the convex feasible set after these nonstrict linear conditions. A point avoiding all the affine zero sets $`Z_i=\{x:A_ix+b_i=0\}`$ exists if and only if $`K`$ is nonempty and is not contained in any one $`Z_i`$. Necessity is obvious. For sufficiency, choose, for each $`i`$, a witness in $`K\setminus Z_i`$; a generic convex combination of the witnesses avoids the finitely many proper affine zero sets (equivalently, avoid their finitely many polynomial zero sets in the simplex of combination weights).

With linear constraints, checking $`K\subseteq Z_i`$ requires maximizing and minimizing each of the $`k`$ affine coordinates of $`A_ix+b_i`$ over $`K`$, so at most $`2mk`$ LPs supply the endpoint test and witnesses. Under the frequently used convention that cone apex zero is admissible, these extra nonzero checks can be omitted, but that convention differs from the angle definition in this exercise. A minimizing sequence may approach excluded zero vectors, so bisection always determines the optimal infimum; attainment must be checked at the recovered candidate.
