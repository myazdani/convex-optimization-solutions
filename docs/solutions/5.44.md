# Exercise 5.44: Strong alternatives for nonstrict linear matrix inequalities

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.44](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=301). The source exercise and all of its subparts were checked directly.

Write $`\mathcal L=\mathrm{span}\{F_1,\ldots,F_n\}`$. The hypothesis says that $`\mathcal L\cap\mathbf S_+^m=\{0\}`$, where $`m`$ is the matrix order.

## (a) Attainment and the strong alternative

First replace the list $`F_i`$ by a basis of $`\mathcal L`$. Every affine matrix $`G+\sum_i x_iF_i`$ remains available, so this changes neither feasibility nor the auxiliary value. It also preserves the dual trace constraints, because orthogonality to a basis is equivalent to orthogonality to its span. Thus assume the $`F_i`$ are linearly independent. If $`\mathcal L=\{0\}`$, the auxiliary optimum is simply $`\lambda_{\max}(G)`$ and is attained; the arguments below apply to a nonzero-dimensional span.

For each unit vector $`v`$, the matrix $`H(v)=\sum_i v_iF_i`$ is nonzero. Moreover,

```math
\lambda_{\max}(H(v))>0.
```

Otherwise $`H(v)\preceq0`$, so $`-H(v)\in\mathcal L\cap\mathbf S_+^m`$ would be zero, contradicting independence and $`\|v\|_2=1`$. Eigenvalues depend continuously on the matrix. Compactness of the unit sphere therefore gives

```math
\delta=\min_{\|v\|_2=1}\lambda_{\max}(H(v))>0.
```

For arbitrary $`x\ne0`$, homogeneity and the Rayleigh quotient imply

```math
\lambda_{\max}\left(G+\sum_i x_iF_i\right)
\ge\lambda_{\max}\left(\sum_i x_iF_i\right)-\|G\|_2
\ge\delta\|x\|_2-\|G\|_2.
```

Consequently this continuous function is coercive. Its sublevel sets are closed and bounded, and a minimizing sequence has a convergent subsequence. The auxiliary problem is exactly

```math
\min_x\lambda_{\max}\left(G+\sum_i x_iF_i\right),
```

with the optimal $`s`$ equal to this eigenvalue. Its value is finite and attained. In fact the proof establishes attainment for every possible value, including zero, which is needed to exclude an unattained zero infimum in the alternative argument.

For completeness, derive its dual using $`Z\succeq0`$ for $`F(x)-sI\preceq0`$:

```math
L(x,s,Z)=\mathrm{tr}(GZ)+\sum_i x_i\mathrm{tr}(F_iZ)
+s(1-\mathrm{tr}\,Z).
```

The free variables require $`\mathrm{tr}(F_iZ)=0`$ and $`\mathrm{tr}\,Z=1`$, so the dual is

```math
\mathrm{maximize}\quad\mathrm{tr}(GZ)
\quad\mathrm{subject\ to}\quad
Z\succeq0,\quad\mathrm{tr}\,Z=1,\quad\mathrm{tr}(F_iZ)=0\ (i=1,\ldots,n).
```

The auxiliary primal is strictly feasible: take any $`x`$ and choose $`s>\lambda_{\max}(F(x))`$. Its finite value therefore equals an attained dual value by Slater's condition.

If the original LMI has no feasible point, the attained auxiliary value must be strictly positive; a minimizer with value at most zero would satisfy $`F(x)\preceq0`$. An optimal dual matrix thus supplies

```math
Z\succeq0,\qquad\mathrm{tr}(F_iZ)=0,\qquad\mathrm{tr}(GZ)>0,
```

the desired alternative certificate. Conversely, such a certificate and an original feasible point cannot coexist: positivity of the semidefinite trace pairing gives $`\mathrm{tr}(ZF(x))\le0`$, but the trace equalities give $`\mathrm{tr}(ZF(x))=\mathrm{tr}(ZG)>0`$. Exactly one system is feasible.

## (b) Failure without the hypothesis

For the stated matrices,

```math
F(x)=\begin{bmatrix}0&1\\1&x\end{bmatrix},\qquad\det F(x)=-1.
```

The two eigenvalues have opposite signs for every real $`x`$, so $`F(x)\preceq0`$ is impossible. On the other side, write

```math
Z=\begin{bmatrix}a&b\\b&c\end{bmatrix}\succeq0.
```

The equality $`\mathrm{tr}(F_1Z)=0`$ forces $`c=0`$. Positive semidefiniteness then forces $`b=0`$, since $`b^2\le ac=0`$. Hence $`\mathrm{tr}(GZ)=2b=0`$, and a strictly positive certificate is impossible too.

Here the auxiliary value explains the failure:

```math
\lambda_{\max}(F(x))=\frac{x+\sqrt{x^2+4}}2>0,
\qquad
\inf_x\lambda_{\max}(F(x))=0,
```

where the infimum is approached as $`x\to-\infty`$ and never attained. The structural hypothesis fails because $`F_1`$ is itself a nonzero positive semidefinite matrix in $`\mathcal L`$.

## Validation

The attainment proof controls all directions after eliminating the common kernel, not only positive objective levels. The counterexample separately proves infeasibility of both systems and identifies the unattained zero auxiliary value.
