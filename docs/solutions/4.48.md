# Exercise 4.48: Generalized eigenvalues and perspective search

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.48](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=218). The source exercise and all of its subparts were checked directly.

## (a) Scalar convex feasibility functions

For $`B\succ0`$,

```math
\lambda_{\max}(A,B)\le t
\quad\Longleftrightarrow\quad u^T(A-tB)u\le0\text{ for every }u
\quad\Longleftrightarrow\quad\lambda_{\max}(A-tB)\le0.
```

Thus choose $`\phi_t(A,B)=\lambda_{\max}(A-tB)`$, a convex function of the matrix pair for fixed real $`t`$. With the affine matrix functions in the exercise, feasibility of $`\phi_t(A(x),B(x))\le0`$, $`B(x)\succ0`$ is a convex feasibility problem. The feasible levels are upward closed, so bisection between valid lower and upper bounds yields the infimum to the requested tolerance; lack of attainment must not be confused with infeasibility of every larger level.

## (b) Matrix-convex feasibility functions

Choose the affine, hence matrix-convex, map $`\Phi_t(A,B)=A-tB`$. The level condition is the LMI $`A(x)-tB(x)\preceq0`$. To enforce the strict domain with non-strict LMIs if desired, introduce a symmetric auxiliary $`S`$ and impose

```math
\begin{bmatrix}B(x)&I\\I&S\end{bmatrix}\succeq0.
```

Its positivity forces $`B(x)\succ0`$ by the kernel argument; conversely $`S=B(x)^{-1}`$ is feasible for every positive-definite $`B(x)`$. Thus every feasibility test can be expressed as an ordinary SDP without admitting singular denominators.

## (c) Scalar denominator and its boundary qualification

When $`B(x)=(a^Tx+b)I`$, set

```math
s=\frac1{a^Tx+b}>0,\qquad y=sx.
```

Then $`a^Ty+bs=1`$ and the objective is exactly $`\lambda_{\max}(sA_0+\sum_i y_iA_i)`$. Conversely a feasible pair with $`s>0`$ recovers $`x=y/s`$, with the same objective. This is a convex problem; an eigenvalue epigraph makes it an SDP, and a two-by-two block $`\begin{bmatrix}s&1\\1&z\end{bmatrix}\succeq0`$ can enforce its strict positivity exactly.

The source displays $`s\ge0`$. That closed relaxation preserves the infimum, but not necessarily the existence or recovery of an optimizer. To prove infimum equality, choose any normalized point with positive $`s`$; it exists because $`a\ne0`$. Every feasible boundary pair with $`s=0`$ is approached by convex combinations with this point, all of which have positive $`s`$. The largest eigenvalue is continuous, so the boundary value is a limit of original objective values.

The attainment caveat is real: for scalar matrices $`A(x)=1`$, $`B(x)=x`$, the original problem on $`x>0`$ is $`\inf 1/x=0`$ without a minimizer. The displayed closed problem is $`\min s`$ with $`y=1,s\ge0`$, and attains zero at $`s=0`$. Such a point yields an approximating original sequence, not a finite optimizer. Whenever a closed-formulation optimizer has $`s>0`$, direct recovery remains exact.

## Validation

Both convex families, all strict matrix domains, and the precise limit-versus-optimizer meaning of the source's boundary relaxation are addressed.
