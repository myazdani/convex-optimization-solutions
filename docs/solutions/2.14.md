# Exercise 2.14: Expanding and shrinking a convex set

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.14, p. 61](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=75).

Original solution.

## (a) Expansion by distance

If $`S=\varnothing`$, use $`\mathrm{dist}(x,S)=+\infty`$, so the expansion is empty. Otherwise let $`x,z\in S_a`$, $`t\in[0,1]`$, and $`\epsilon>0`$. Choose $`s_x,s_z\in S`$ with
```math
\|x-s_x\|\le a+\epsilon,\qquad \|z-s_z\|\le a+\epsilon.
```
Their convex combination lies in $`S`$, and the triangle inequality gives
```math
\mathrm{dist}(tx+(1-t)z,S)
\le\|t(x-s_x)+(1-t)(z-s_z)\|
\le a+\epsilon.
```
Letting $`\epsilon\downarrow0`$ proves convexity. This proof does not assume existence of nearest points or closure of $`S`$; in particular $`S_0=\mathrm{cl}\,S`$.

## (b) Restriction by contained balls

Writing $`B=\{u:\|u\|\le a\}`$, one has
```math
S_{-a}=\{x:x+B\subseteq S\}=\bigcap_{u\in B}(S-u).
```
Each translate is convex, so the intersection is convex. This remains valid for $`a=0`$, where the restricted set is exactly $`S`$, and for open or empty $`S`$.
