# Exercise 8.19: A sufficient redundancy certificate at the analytic center

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.19, printed page 450. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=464).

The inverse $`H^{-1}`$ in the exercise assumes $`H\succ0`$. Translate the analytic center to zero and transform by $`H^{1/2}`$. Set
```math
v_i=\frac{H^{-1/2}a_i}{b_i-a_i^Tx_{\rm ac}}.
```
The transformed polyhedron has inequalities $`v_i^Tz\le1`$, and stationarity and the Hessian normalization give
```math
\sum_i v_i=0,\qquad\sum_i v_iv_i^T=I.
```
For any feasible $`z`$, let $`t_i=v_i^Tz`$. Then $`t_i\le1`$, $`\sum_i t_i=0`$, and $`\|z\|^2=\sum_i t_i^2`$. Each $`t_i\ge-(m-1)`$; on this interval,
```math
t_i^2\le(2-m)t_i+(m-1).
```
Summing yields $`\|z\|^2\le m(m-1)`$.

The proposed certificate is exactly $`\|v_k\|\le1/m`$. If $`v_k=0`$, its strictly feasible inequality is plainly redundant. Otherwise any point on its boundary $`v_k^Tz=1`$ has norm at least $`1/\|v_k\|\ge m>\sqrt{m(m-1)}`$, so no point of the original feasible set lies on that boundary.

If removing inequality $`k`$ admitted a violating point $`w`$, the segment from zero to $`w`$ would first reach its boundary at some $`z=\theta w`$ with $`0<\theta<1`$. Every other inequality remains satisfied along the segment, so this boundary point would belong to the original feasible set, a contradiction. Thus removing the inequality changes nothing.
