# Exercise 3.30: The convex envelope as the greatest convex minorant

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.30, p. 119](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=133).

Original solution.

Let $`E=\mathrm{conv}(\mathrm{epi}\,f)`$ and define $`g(x)=\inf\{t:(x,t)\in E\}`$, using $`+\infty`$ for an empty fiber. Fibers are upward closed because the original epigraph is and convex combinations preserve that property.

Since $`(x,f(x))\in E`$ for every original domain point, $`g(x)\le f(x)`$. For points with finite $`g(x),g(y)`$, choose $`s<g(x)+\epsilon`$ and $`t<g(y)+\epsilon`$ with $`(x,s),(y,t)\in E`$. Convexity of $`E`$ gives
```math
g(\theta x+(1-\theta)y)
\le\theta s+(1-\theta)t
\le\theta g(x)+(1-\theta)g(y)+\epsilon.
```
Let $`\epsilon\downarrow0`$ to prove convexity. Empty fibers impose no constraint on the convexity inequality; if a fiber is unbounded below, take its chosen height arbitrarily negative to obtain the corresponding extended-valued inequality. Thus the envelope is convex wherever it is a proper extended-valued function, and can be the improper value $`-\infty`$ when no finite convex minorant exists.

Now let $`h`$ be any convex underestimator of $`f`$. Then $`\mathrm{epi}\,f\subseteq\mathrm{epi}\,h`$. The latter is convex, so $`E\subseteq\mathrm{epi}\,h`$. Hence every $`(x,t)\in E`$ satisfies $`h(x)\le t`$, and taking the infimum of the fiber gives $`h(x)\le g(x)`$. This proves the greatest-minorant property.

One technical qualification to the geometric wording: $`\mathrm{epi}\,g`$ need not equal $`E`$ literally, because taking a fiber infimum fills a missing bottom point. For example, if $`f(x)=e^{-x^2}`$ on the line, then $`g\equiv0`$: equal-weight points $`x\pm R`$ have average function value tending to zero, while all original values are positive. Thus $`E=\mathbb R\times(0,\infty)`$, whereas $`\mathrm{epi}\,g=\mathbb R\times[0,\infty)`$. The definition and greatest-minorant conclusion remain valid without assuming epigraph closure.
