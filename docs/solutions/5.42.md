# Exercise 5.42: Dual of a conic inequality problem

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.42](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=301). The source exercise and all of its subparts were checked directly.

Use a multiplier $`\lambda\in K^*`$ for $`Ax-b\preceq_K0`$, where

```math
K^*=\{\lambda:\lambda^Ts\ge0\text{ for every }s\in K\}.
```

For feasible $`x`$, $`b-Ax\in K`$, and therefore $`\lambda^T(Ax-b)\le0`$. This is the sign that makes the Lagrangian a lower bound:

```math
L(x,\lambda)=c^Tx+\lambda^T(Ax-b)
=(c+A^T\lambda)^Tx-b^T\lambda.
```

The variable $`x\in\mathbf R^n`$ is unrestricted. If $`c+A^T\lambda\ne0`$, taking $`x=-t(c+A^T\lambda)`$ and $`t\to\infty`$ makes the infimum $`-\infty`$. If that coefficient vanishes, the infimum is $`-b^T\lambda`$. Making the implicit equality explicit gives

```math
\begin{aligned}
\mathrm{maximize}\quad &-b^T\lambda\\
\mathrm{subject\ to}\quad &A^T\lambda+c=0,\\
&\lambda\in K^*.
\end{aligned}
```

For a primal-feasible $`x`$ and dual-feasible $`\lambda`$, the gap is

```math
c^Tx-(-b^T\lambda)=\lambda^T(b-Ax)\ge0.
```

This proves weak duality without a qualification. If some $`x`$ satisfies $`b-Ax\in\mathrm{int}\,K`$ and the primal value is finite, Slater's condition gives equality of optimal values and dual attainment. Such a condition is not assumed merely to derive the dual, and neither primal attainment nor unconditional strong duality follows from the problem statement alone.

## Validation

The multiplier lies in the dual cone, the free-variable stationarity equality is explicit, and the gap has the required nonnegative cone pairing.
