# Exercise 5.37: A stationary Markov distribution from Farkas lemma

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.37](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=299). The source exercise and all of its subparts were checked directly.

Set

```math
B=\begin{bmatrix}P-I\\\mathbf1^T\end{bmatrix},\qquad
d=\begin{bmatrix}0\\1\end{bmatrix}.
```

The desired distribution is a nonnegative vector $`y`$ satisfying $`By=d`$. If none existed, Farkas' lemma would give $`v\in\mathbb R^n`$ and $`\alpha\in\mathbb R`$ with

```math
(P-I)^Tv+\alpha\mathbf1\succeq0,\qquad\alpha<0.
```

Thus $`P^Tv\succeq v-\alpha\mathbf1\succ v`$. Choose an index $`j`$ where $`v_j`$ is largest. Since column $`j`$ of $`P`$ is a probability vector,

```math
(P^Tv)_j=\sum_iP_{ij}v_i\le\sum_iP_{ij}v_j=v_j,
```

contradicting the strict inequality. The certificate cannot exist, so a nonnegative unit-sum fixed point exists.

No irreducibility, aperiodicity, or strictly positive entries are required. Those conditions concern uniqueness or convergence, neither asserted here.

## Validation

Column stochasticity is used exactly as stated, with the corresponding fixed-point convention.
