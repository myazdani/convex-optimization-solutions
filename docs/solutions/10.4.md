# Exercise 10.4: Curvature and smoothness after eliminating equalities

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 10.4, printed page 558. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=572).

Let $`\sigma_-=\sigma_{\min}(F)>0`$, $`\sigma_+=\sigma_{\max}(F)`$. The reduced Hessian is $`\widetilde H=F^THF`$. The source assumptions are $`0\preceq H\preceq MI`$, an inverse-KKT norm bound $`K`$, and a Hessian Lipschitz constant $`L`$ on the initial feasible sublevel set.

For any $`u`$, since $`AF=0`$,
```math
\begin{bmatrix}H&A^T\\A&0\end{bmatrix}
\begin{bmatrix}Fu\\0\end{bmatrix}
=\begin{bmatrix}HFu\\0\end{bmatrix}.
```
The inverse bound implies $`\|Fu\|\le K\|HFu\|`$. Since $`H^2\preceq MH`$,
```math
\sigma_-^2\|u\|^2\le\|Fu\|^2
\le K^2M\,u^TF^THFu.
```
Thus one may take
```math
\widetilde m=\frac{\sigma_-^2}{K^2M},\qquad
\widetilde M=M\sigma_+^2.
```
The upper bound follows directly from $`H\preceq MI`$. For reduced points $`z,\hat z`$,
```math
\|F^T[H(Fz+\hat x)-H(F\hat z+\hat x)]F\|
\le\sigma_+^2 L\|F(z-\hat z)\|
\le L\sigma_+^3\|z-\hat z\|.
```
Hence $`\widetilde L=L\sigma_+^3`$ is a valid Lipschitz constant. The reduced sublevel set is closed as the inverse image of the closed feasible sublevel set under a continuous affine map. These are sufficient constants, not assertions that each bound is sharp.
