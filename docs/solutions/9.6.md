# Exercise 9.6: Exact iterates for a two-dimensional quadratic

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.6, printed page 515. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=529).

The example has $`f(x)=\tfrac12(x_1^2+\gamma x_2^2)`$, $`\gamma>0`$, and $`x^{(0)}=(\gamma,1)`$. Write $`Q=\mathrm{diag}(1,\gamma)`$. Exact line search along $`-Qx`$ minimizes a scalar quadratic, giving
```math
t=\frac{x^TQ^2x}{x^TQ^3x}
=\frac{x_1^2+\gamma^2x_2^2}{x_1^2+\gamma^3x_2^2}
```
when $`x\ne0`$. The relation $`x_1^2=\gamma^2x_2^2`$ holds initially and gives $`t=2/(1+\gamma)`$. The update then multiplies the first component by $`q=(\gamma-1)/(\gamma+1)`$ and the second by $`-q`$, preserving the same relation. Induction yields
```math
x_1^{(k)}=\gamma q^k,\qquad x_2^{(k)}=(-q)^k,
\qquad f(x^{(k)})=\frac{\gamma(\gamma+1)}2q^{2k}.
```
These are the claimed formulas. If $`\gamma=1`$, the first step reaches zero and the method stops; the formulas hold for all later iterates taken to remain zero. For other positive $`\gamma`$, $`|q|<1`$ and the objective contracts by exactly $`q^2`$ at every step.
