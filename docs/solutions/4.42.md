# Exercise 4.42: Realifying complex Hermitian LMIs

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.42](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=216). The source exercise and all of its subparts were checked directly.

Write the Hermitian matrix as $`X=R+iS`$. Hermitian symmetry means $`R^T=R`$ and $`S^T=-S`$, so the real block matrix below is symmetric. For any $`z=u+iv`$, direct expansion gives

```math
z^HXz=
\begin{bmatrix}u\\v\end{bmatrix}^{T}
\begin{bmatrix}R&-S\\S&R\end{bmatrix}
\begin{bmatrix}u\\v\end{bmatrix}.
```

Every complex vector corresponds to exactly one real pair $`(u,v)`$. Thus the quadratic form is nonnegative on all complex vectors if and only if the real block quadratic form is nonnegative on all real pairs. This proves the claimed semidefinite equivalence, including singular matrices.

Define the real-linear map $`\mathcal R(X)=\begin{bmatrix}\Re X&-\Im X\\\Im X&\Re X\end{bmatrix}`$. For real decision variables,

```math
\mathcal R\left(\sum_jx_jF_j+G\right)
=\sum_jx_j\mathcal R(F_j)+\mathcal R(G).
```

Replace the complex LMI by this real LMI with the same inequality direction, retain the real linear objective and any affine constraints, and obtain an ordinary real SDP with doubled matrix dimension. The decision vector is unchanged, so feasible sets, values, and optimizers correspond identically.

## Validation

The sign of the imaginary off-diagonal block follows from skew-symmetry. The transformation doubles the matrix size, not the number of the already-real decision variables.
