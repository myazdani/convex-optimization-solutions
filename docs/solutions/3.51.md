# Exercise 3.51: Real-rooted polynomials on their positive intervals

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.51, p. 123](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=137).

Original solution.

For a nonzero polynomial with only real roots, write
```math
p(x)=c\prod_{j=1}^r(x-\rho_j)^{m_j},\qquad m_j\ge1.
```
On any interval where $`p>0`$, no root belongs to the interval. Taking the logarithm of its positive value gives
```math
\log p(x)=\log|c|+\sum_jm_j\log|x-\rho_j|.
```
Thus
```math
\frac{d^2}{dx^2}\log p(x)
=-\sum_j\frac{m_j}{(x-\rho_j)^2}\le0.
```
The log is concave on that interval, proving log-concavity. Repeated roots are included via their multiplicities. A positive constant polynomial has constant log and satisfies the claim; the zero polynomial has no interval of strict positivity.
