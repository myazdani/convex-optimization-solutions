# Exercise 3.59: Second derivatives and cone-convexity

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.59, p. 124](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=138).

Original solution.

For a proper closed convex cone $`K`$, the dual characterization is
```math
w\in K\quad\Longleftrightarrow\quad
\lambda^Tw\ge0\quad\text{for every }\lambda\in K^*.
```
Consequently $`f`$ is $`K`$-convex exactly when each scalar function $`\lambda^Tf`$, $`\lambda\in K^*`$, is convex: apply the characterization to the difference between the weighted endpoint values and the value at their convex combination.

For such a scalarization, the Hessian quadratic form in direction $`y`$ is
```math
y^T\nabla^2(\lambda^Tf)(x)y
=\lambda^T\left(\sum_{i,j=1}^n
\frac{\partial^2f(x)}{\partial x_i\partial x_j}y_i y_j\right).
```
The ordinary second-order criterion says it is nonnegative for all $`x,y`$ exactly when the scalarization is convex on the given convex domain. Requiring this for every $`\lambda\in K^*`$, and applying the dual characterization once more, is exactly the stated condition that the vector-valued second derivative belongs to $`K`$. This proves both directions. As in the ordinary Hessian theorem, twice differentiability is understood on an open domain; on an affine relative domain restrict directions to its tangent space.
