# Exercise 9.27: Efficient analytic-center Newton steps with box bounds

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 9.27, printed page 518. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=532).

Let $`s=b-Ax\succ0`$, $`B=\mathrm{diag}(s_i^{-1})A`$, and
```math
D=\mathrm{diag}\left((1+x_j)^{-2}+(1-x_j)^{-2}\right).
```
Differentiation gives
```math
g_j=-\frac1{1+x_j}+\frac1{1-x_j}+(A^Ts^{-1})_j,
\qquad H=D+B^TB.
```
The diagonal $`D\succ0`$ makes the Newton system nonsingular without a rank assumption on $`A`$.

If $`m\ge n`$, explicitly form the $`n\times n`$ matrix $`H`$ and use Cholesky. Dense work is $`O(mn^2+n^3)`$, plus $`O(mn)`$ for slacks and gradient; storage beyond the input is $`O(n^2)`$.

If $`m\le n`$, form $`K=I_m+BD^{-1}B^T\succ0`$ and use the Woodbury formula:
```math
\Delta x=-D^{-1}g+D^{-1}B^TK^{-1}BD^{-1}g.
```
Computing $`K`$ costs $`O(nm^2)`$, its Cholesky costs $`O(m^3)`$, and the remaining diagonal operations and products cost $`O(mn)`$. This avoids a dense $`n\times n`$ factorization. Diagonal inverse operations mean elementwise divisions, and $`K^{-1}`$ denotes a Cholesky solve rather than forming a numerical inverse. At $`m=0`$ the system is purely diagonal; near equal dimensions either method has the same cubic order.
