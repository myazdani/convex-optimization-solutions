# Exercise 3.37: Conjugate of the trace inverse

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.37, p. 120](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=134).

Original solution.

The conjugate uses the trace inner product. If $`Y`$ has a positive eigenvalue with unit eigenvector $`q`$, take $`X=I+tqq^T\succ0`$. The linear term grows like $`tq^TYq`$, while $`\mathrm{tr}(X^{-1})`$ stays bounded, so the conjugate is infinite.

Now let $`Y=-A`$ with $`A\succeq0`$. For any $`X\succ0`$, the squared Frobenius norm identity is
```math
\|X^{1/2}A^{1/2}-X^{-1/2}\|_F^2
=\mathrm{tr}(AX)+\mathrm{tr}(X^{-1})-2\mathrm{tr}(A^{1/2})\ge0.
```
Therefore $`\mathrm{tr}(YX)-\mathrm{tr}(X^{-1})\le-2\mathrm{tr}(A^{1/2})`$.

If $`A\succ0`$, equality holds at $`X=A^{-1/2}`$. If $`A`$ is singular, diagonalize it and take $`X`$ in the same eigenbasis, with entry $`a_i^{-1/2}`$ where $`a_i>0`$ and entry $`R`$ where $`a_i=0`$. As $`R\to\infty`$, the objective tends to the bound. Thus
```math
f^*(Y)=-2\mathrm{tr}((-Y)^{1/2}),\qquad Y\preceq0,
```
and it is infinite otherwise. At singular $`-Y`$ the supremum is generally unattained, including $`Y=0`$, but its finite value is included in the conjugate domain.
