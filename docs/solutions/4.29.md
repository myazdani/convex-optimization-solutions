# Exercise 4.29: Maximizing a Gaussian linear-inequality probability

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.29](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=213). The source exercise and all of its subparts were checked directly.

Let $`\mu(x)=\bar c^Tx-\alpha`$ and $`s(x)=\|R^{1/2}x\|_2`$, with a positive semidefinite covariance square root. When $`s(x)>0`$, normality gives

```math
\Pr(c^Tx\ge\alpha)=\Phi\left(\frac{\mu(x)}{s(x)}\right),
```

where $`\Phi`$ is the strictly increasing standard normal CDF. When $`s(x)=0`$, the event is deterministic, with probability one if $`\mu(x)\ge0`$ and zero otherwise.

The assumed feasible point with $`\mu\ge0`$ achieves probability at least one half. Hence points with $`\mu<0`$ can be discarded: they have probability below one half (or zero in the deterministic case). First check the LP feasibility system

```math
Fx\preceq g,\qquad Ax=b,\qquad R^{1/2}x=0,\qquad\mu(x)\ge0.
```

If feasible, its solution achieves the global maximum probability one. This check also handles equality in the deterministic event, which a standardized ratio alone would miss.

If that system is infeasible, every remaining feasible point has $`s(x)>0`$. We can maximize the nonnegative ratio $`\mu(x)/s(x)`$ by quasiconvex feasibility search: a trial ratio $`\tau\ge0`$ is feasible exactly when the SOCP

```math
Fx\preceq g,\qquad Ax=b,\qquad
\tau\|R^{1/2}x\|_2\le\bar c^Tx-\alpha
```

is feasible. For fixed $`\tau`$ this is a convex constraint, and its right side automatically enforces $`\mu\ge0`$. Feasibility is monotone decreasing in $`\tau`$. Bisection thus finds the optimal ratio and hence the optimal probability, to any desired attainable tolerance. Equivalently bisect a probability level $`p\in[1/2,1)`$ and use $`\tau=\Phi^{-1}(p)`$, which keeps a bounded search interval even if the ratio supremum is infinite.

If the feasible polyhedron is unbounded, attainment is not guaranteed. The probability supremum can equal one through an unbounded sequence without any deterministic feasible point; the search then supplies arbitrarily good feasible points rather than claiming an unattained optimizer.

## Validation

The covariance may be singular; deterministic equality gives probability one, not one half. The mean-side assumption is exactly what allows nonnegative levels and convex SOC feasibility constraints.
