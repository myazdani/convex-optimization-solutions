# Exercise 5.8: Eliminating box-constraint dual multipliers

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 5.8](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=289). The source exercise and all of its subparts were checked directly.

In Example 5.9 set $`r=A^T\nu+c`$. The explicit-box dual requires $`\lambda_2-\lambda_1=r`$, $`\lambda_1,\lambda_2\succeq0`$. Every such pair is uniquely expressible as

```math
\lambda_1=r_-+w,\qquad\lambda_2=r_++w,\qquad w\succeq0,
```

where $`(r_+)_i=\max(r_i,0)`$ and $`(r_-)_i=\max(-r_i,0)`$. Its objective becomes

```math
-b^T\nu-u^Tr_-+l^Tr_++(l-u)^Tw.
```

Because $`l\prec u`$, this is maximized for fixed $`\nu`$ uniquely at $`w=0`$. Eliminating the nonnegative multipliers therefore gives precisely the implicit-box dual

```math
\mathrm{maximize}_\nu\quad
-b^T\nu-u^T(A^T\nu+c)_-+l^T(A^T\nu+c)_+.
```

Every implicit dual point lifts to the explicit one using the positive/negative parts above with identical objective. Every explicit feasible point can be replaced by this lift at the same $`\nu`$ with objective no smaller. Thus the two duals have equal suprema, even in extended-value cases, and any optimizer of the implicit dual lifts to an optimizer of the explicit dual. Conversely, any finite optimal explicit point has $`w=0`$ and its $`\nu`$ solves the implicit problem.

The componentwise expression is also the minimum of the affine function $`r^Tx`$ on the box: choose $`x_i=l_i`$ when $`r_i\ge0`$ and $`x_i=u_i`$ when $`r_i<0`$. This independently verifies the signs and the concave piecewise-linear objective.

## Validation

The source's strict box widths justify eliminating all common multiplier slack; no dual-feasibility or primal-attainment assumption is needed for the value-preserving maps.
