# Exercise 2.19: Inverse images under a linear-fractional map

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.19, p. 62](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=76).

Original solution.

In every part retain the strict domain constraint $`\tau=c^Tx+d>0`$, and write $`u=Ax+b`$. Positivity of $`\tau`$ permits multiplication without reversing scalar or matrix inequalities.

## (a) Halfspace

The inverse image is
```math
\{x:\tau>0,\quad g^T(Ax+b)\le h(c^Tx+d)\}.
```
Equivalently its other constraint is $`(A^Tg-hc)^Tx\le hd-g^Tb`$.

## (b) Polyhedron

The inverse image is
```math
\{x:\tau>0,\quad G(Ax+b)\le h(c^Tx+d)\}.
```
Thus it is an intersection of affine closed halfspaces with the open domain halfspace; it need not be closed.

## (c) Ellipsoid

Use the positive definite square root of $`P`$. The inverse image is the second-order-cone inequality
```math
\{x:\tau>0,\quad \|P^{-1/2}(Ax+b)\|_2\le c^Tx+d\}.
```
Equivalently $`u^TP^{-1}u\le\tau^2`$ together with $`\tau>0`$. The norm formulation makes convexity apparent; the quadratic inequality alone would also admit the wrong denominator sign.

## (d) Linear matrix inequality

The inverse image is
```math
\left\{x:\tau>0,\quad
\sum_{i=1}^n(Ax+b)_iA_i\preceq(c^Tx+d)B\right\}.
```
This is an affine matrix inequality in $`x`$ together with the domain constraint. In each case substitution $`y=u/\tau`$ proves both directions of the asserted equivalence.
