# Exercise 4.57: Channel capacity as entropy maximization

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.57](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=221). The source exercise and all of its subparts were checked directly.

The channel columns are probability vectors. Let $`x\succeq0,\mathbf1^Tx=1`$ and put $`y=Px`$, the output distribution. Define $`c_j=\sum_i p_{ij}\log_2p_{ij}`$, with $`0\log_2 0=0`$. Expanding the mutual information yields

```math
\begin{aligned}
I(X;Y)
&=\sum_{ij}x_jp_{ij}\log_2p_{ij}
-\sum_i\left(\sum_jx_jp_{ij}\right)\log_2y_i\\
&=c^Tx-\sum_i y_i\log_2y_i.
\end{aligned}
```

If $`y_i=0`$, all nonnegative products $`x_jp_{ij}`$ in that row are zero; the continuous entropy convention makes its whole contribution zero. Thus the identity includes zero channel probabilities and zero output probabilities.

Compute capacity by the convex optimization problem

```math
\begin{aligned}
\mathrm{maximize}\quad&c^Tx-\sum_i y_i\log_2y_i\\
\mathrm{subject\ to}\quad&y=Px,\qquad x\succeq0,\quad\mathbf1^Tx=1.
\end{aligned}
```

Entropy is concave on the probability simplex, so the objective is concave and the constraints are affine. Equivalently minimize its negative. Eliminating $`y`$ gives the same concave function of $`x`$. The input simplex is compact and entropy is continuous including its boundary, so the supremum is attained. The base-two logarithm returns capacity in bits per channel use, or bits per second for the one-use-per-second convention in the exercise.
