# Exercise 3.3: Inverse of an increasing convex function

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.3, p. 114](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=128).

Original solution.

The existence of the inverse requires the increasing function to be strictly increasing. The inverse $`g`$ is increasing and **concave**. Let $`u=f(x)`$, $`v=f(y)`$, with $`x,y\in(a,b)`$, and let $`t\in[0,1]`$. Convexity gives
```math
f(tx+(1-t)y)\le tu+(1-t)v.
```
Applying the increasing inverse gives
```math
tg(u)+(1-t)g(v)=tx+(1-t)y\le g(tu+(1-t)v),
```
which is concavity. The inverse domain is an interval because a finite convex function is continuous on the open interval; endpoint values in its description mean the one-sided limits, possibly infinite. If $`f`$ is affine with positive slope, $`g`$ is also affine; a strictly convex $`f`$ gives a strictly concave inverse by the same argument with a strict inequality.
