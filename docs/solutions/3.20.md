# Exercise 3.20: Affine composition examples

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.20, p. 116](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=130).

Original solution.

## (a) Norm of an affine residual

For $`x,y`$ and $`\theta\in[0,1]`$, the triangle inequality and norm homogeneity give
```math
\|A(\theta x+(1-\theta)y)-b\|
\le\theta\|Ax-b\|+(1-\theta)\|Ay-b\|.
```
Thus the function is convex, for any norm and any matrix rank.

## (b) Negative determinant root

Let $`M(x)=A_0+\sum_i x_iA_i`$. The domain $`\{x:M(x)\succ0\}`$ is convex because it is an affine inverse image of the positive definite cone. Exercise 3.18 shows $`M\mapsto(\det M)^{1/m}`$ is concave. Negating it gives a convex function, and composition with the affine map $`M(x)`$ preserves convexity.

## (c) Trace of the inverse

The same domain is convex. Exercise 3.18 shows $`M\mapsto\mathrm{tr}(M^{-1})`$ is convex, so its affine composition $`x\mapsto\mathrm{tr}(M(x)^{-1})`$ is convex. In both matrix examples no injectivity of $`x\mapsto M(x)`$ is needed; an empty domain is simply an empty-domain convex function.
