# Exercise 11.3: Bounded original sublevels imply bounded centering sublevels

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 11.3, printed page 623. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=637).

Work in the affine space $`Ax=b`$. If there is no strictly feasible point, every centering sublevel set is empty and the claim is immediate. Otherwise fix a strictly feasible $`x_0`$ and write $`r=\|x-x_0\|_2`$.

Boundedness of the original sublevel set at level $`f_0(x_0)+1`$ supplies $`R>0`$ such that every feasible point at distance $`R`$ from $`x_0`$ has objective greater than that level. If a feasible $`x`$ has $`r>R`$, its segment point $`z=x_0+(R/r)(x-x_0)`$ is feasible, and convexity gives
```math
f_0(x_0)+1<f_0(z)
\le f_0(x_0)+\frac Rr(f_0(x)-f_0(x_0)).
```
Thus $`f_0(x)>f_0(x_0)+r/R`$ outside that ball.

Each convex differentiable constraint has the affine lower bound
```math
f_i(x)\ge f_i(x_0)+\nabla f_i(x_0)^T(x-x_0),
```
so at a strictly feasible point its positive slack satisfies
```math
0<-f_i(x)\le a_i+b_i r,
\qquad a_i=-f_i(x_0)>0,\quad b_i=\|\nabla f_i(x_0)\|.
```
Consequently, for fixed $`t>0`$ and $`r>R`$,
```math
t f_0(x)+\phi(x)
\ge t f_0(x_0)+\frac tR r-\sum_i\log(a_i+b_i r)
\longrightarrow+\infty\quad(r\to\infty).
```
A linear lower bound dominates the logarithmic terms, even when some $`b_i=0`$. Therefore every finite centering sublevel set is bounded. The proof uses neither a false nonnegative lower bound on the log barrier nor compactness of the entire original feasible set.
