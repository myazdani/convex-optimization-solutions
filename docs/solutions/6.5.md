# Exercise 6.5: Minimum prefix length is quasiconvex

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 6.5, printed page 345. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=359).

Use the convention $`\mathrm{length}(0)=0`$. For a real level $`\alpha`$, the sublevel set of length is empty if $`\alpha<0`$, all of $`\mathbb R^n`$ if $`\alpha\ge n`$, and otherwise the linear subspace
```math
\{x:x_{\lfloor\alpha\rfloor+1}=\cdots=x_n=0\}.
```
Every sublevel set is convex, so length is quasiconvex. The constraint $`\|Ax-b\|\le\epsilon`$ is convex for any norm, proving the claimed quasiconvex optimization formulation.

To solve it, test the nested feasibility problems
```math
\|A_{:,1:k}z-b\|\le\epsilon,\qquad k=0,1,\ldots,n.
```
The $`k=0`$ test is $`\|b\|\le\epsilon`$. If the $`k=n`$ test fails, the original problem is infeasible. Otherwise integer bisection finds the smallest feasible $`k`$ in at most $`\lceil\log_2(n+1)\rceil`$ further tests; pad its solution with zeros. No sparsity claim about unordered subsets of columns is needed.
