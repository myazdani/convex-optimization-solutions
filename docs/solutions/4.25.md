# Exercise 4.25: Strict separation of ellipsoids by an SOCP

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.25](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=211). The source exercise and all of its subparts were checked directly.

For an ellipsoid $`E_i=q_i+P_i\{u:\|u\|_2\le1\}`$, the extreme affine values are

```math
\min_{x\in E_i}(a^Tx+b)=a^Tq_i+b-\|P_i^Ta\|_2,
\qquad
\max_{x\in E_i}(a^Tx+b)=a^Tq_i+b+\|P_i^Ta\|_2.
```

These follow from the Euclidean support function and remain valid for singular or indefinite symmetric $`P_i`$. Solve the SOCP feasibility problem

```math
\begin{aligned}
\|P_i^Ta\|_2&\le a^Tq_i+b-1,&&i=1,\ldots,K,\\
\|P_i^Ta\|_2&\le -a^Tq_i-b-1,&&i=K+1,\ldots,K+L.
\end{aligned}
```

Every feasible solution gives a strict separator, with margin at least one throughout every ellipsoid. Conversely a strict separator has a positive minimum margin: each ellipsoid is compact, the affine function is continuous, and there are finitely many ellipsoids. If this margin is $`\delta>0`$, divide $`a,b`$ by $`\delta`$ to satisfy the SOCP. Thus infeasibility certifies that no strict separator exists.

If both groups are nonempty, the two margin families also exclude $`a=0`$, since they would require $`b\ge1`$ and $`b\le-1`$. Replacing strict separation by weak separation would be a different problem and would not justify this unit-margin normalization.

## Validation

Both signs of the ellipsoid support function and the compactness needed for positive uniform margin are explicit.
