# Exercise 8.20: Analytic-center ellipsoids for an LMI

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.20, printed page 450. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=464).

Put $`S=B-\sum_j(x_{\rm ac})_jA_j\succ0`$ and $`M_j=S^{-1/2}A_jS^{-1/2}`$. For a displacement $`h=x-x_{\rm ac}`$, define the symmetric matrix $`V=\sum_jh_jM_j`$. The original LMI is equivalent to $`I-V\succeq0`$. At the analytic center, gradient stationarity and the log-determinant Hessian formula give
```math
\mathrm{tr}(M_j)=0,\qquad H_{ij}=\mathrm{tr}(M_iM_j),
\qquad\mathrm{tr}(V)=0,\quad h^THh=\mathrm{tr}(V^2).
```
If $`h^THh\le1`$, then every eigenvalue of $`V`$ has absolute value at most $`\sqrt{\mathrm{tr}(V^2)}\le1`$. In particular $`I-V\succeq0`$, proving the inner inclusion.

Conversely if $`x\in C`$, the eigenvalues satisfy $`\lambda_i\le1`$ and $`\sum_i\lambda_i=0`$. Consequently $`\lambda_i\ge-(m-1)`$. The scalar inequality
```math
\lambda_i^2\le(2-m)\lambda_i+(m-1)
```
holds throughout this interval, since it is equivalent to $`(1-\lambda_i)(\lambda_i+m-1)\ge0`$. Summing proves
```math
h^THh=\sum_i\lambda_i^2\le m(m-1),
```
the outer inclusion. The argument permits singular $`H`$: then the displayed quadratic sets are cylinders, reflecting directions that do not change the LMI. If one calls them ellipsoids in the bounded sense, positive definiteness of $`H`$ is an additional assumption.
