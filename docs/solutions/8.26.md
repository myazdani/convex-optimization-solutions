# Exercise 8.26: Quadratic placement by a graph Laplacian

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 8.26, printed page 451. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=465).

Let $`L`$ be the unweighted graph Laplacian: $`L_{ii}=\deg(i)`$ and $`L_{ij}=-1`$ for an edge between distinct nodes, zero otherwise. Count each undirected edge once. For either coordinate vector $`z\in\mathbb R^N`$,
```math
\sum_{\{i,j\}\in\mathcal A}(z_i-z_j)^2=z^TLz.
```
Partition indices into free $`F=\{1,\ldots,M\}`$ and fixed $`B`$. With fixed coordinate vector $`z_B`$, differentiating the quadratic gives
```math
L_{FF}z_F=-L_{FB}z_B.
```
Thus $`C=L_{FF}`$ is symmetric, its diagonal is each free node's total degree (including fixed neighbors), and its off-diagonal is minus one for a free-free edge. The right-hand side for coordinate $`\ell`$ is
```math
(d_\ell)_i=\sum_{j\in B:\{i,j\}\in\mathcal A}x_{j\ell}.
```
Solving $`Cu=d_1,Cv=d_2`$ supplies the positions. The PSD Laplacian makes stationarity sufficient. The matrix is positive definite exactly when every graph component containing a free node also contains a fixed node: a null vector must be constant on a free component and zero wherever an anchoring edge reaches a fixed node. Unanchored components have arbitrary common translations; their right-hand side is zero, and a pseudoinverse solution plus the corresponding componentwise constants gives every minimizer. Weighted edges replace one by the positive edge weight throughout.
