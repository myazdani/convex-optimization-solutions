# Exercise 2.1: Finite convex combinations

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 2.1, p. 60](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=74).

Original solution.

Use induction on the number of points. The assertion for one point is immediate. Suppose it holds for $`k-1`$ points and set $`s=\sum_{i=1}^{k-1}\theta_i=1-\theta_k`$.
If $`s=0`$, nonnegativity forces every earlier weight to vanish, so the combination is $`x_k\in C`$. If $`s>0`$, the induction hypothesis gives
```math
y=\sum_{i=1}^{k-1}\frac{\theta_i}{s}x_i\in C.
```
Since $`s,\theta_k\ge0`$ and $`s+\theta_k=1`$, two-point convexity implies $`sy+\theta_kx_k\in C`$, which is the required combination. This also covers $`\theta_k=0`$.
