# Exercise 3.28: Affine minorants of a convex function

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.28, p. 119](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=133).

Original solution.

Treat $`f`$ as a proper extended-valued convex function: it is finite on its nonempty domain and $`+\infty`$ outside. Let $`\widetilde f`$ be the supremum of all global affine minorants. By definition $`\widetilde f\le f`$.

## (a) Equality on the domain interior

At an interior domain point $`x`$, a convex function has a supporting affine minorant. One way to see this is to support its epigraph at $`(x,f(x))`$. Orient the supporting inequality as $`a^Tz+bt\ge c`$ on the epigraph. Upward vertical rays force $`b\ge0`$. If $`b=0`$, a neighborhood of $`x`$ in the domain forces $`a=0`$, contradicting a nonzero supporting normal. Thus $`b>0`$, and $`g(z)=(c-a^Tz)/b`$ is a global affine minorant with $`g(x)=f(x)`$. This proves equality. The epigraph boundary assertion follows from the continuity of a convex function on its domain interior. If the interior is empty, (a) is vacuous.

We will also use that every proper convex function has at least one affine minorant, even with lower-dimensional domain. Apply the same support argument in $`\mathrm{aff}(\mathrm{dom}\,f)\times\mathbb R`$ at a relative-interior domain point; the relative-interior continuity and nonvertical-normal argument still hold. Extend the resulting affine functional from this affine hull to all of $`\mathbb R^n`$; outside the domain it automatically remains a minorant of $`+\infty`$.

## (b) Equality everywhere for a closed function

Fix $`x`$ and a finite number $`r<f(x)`$. Since the epigraph is closed, strict separation of $`(x,r)`$ from it gives $`(a,b)\ne0`$ and $`c`$ with
```math
a^Tx+br<c\le a^Tz+bt\qquad((z,t)\in\mathrm{epi}\,f).
```
Again $`b\ge0`$. If $`b>0`$, the affine minorant $`(c-a^Tz)/b`$ has value greater than $`r`$ at $`x`$.

If $`b=0`$, choose an existing affine minorant $`g_0(z)=u^Tz+v`$. Adding $`\epsilon(t-u^Tz-v)\ge0`$ to the valid separating inequality yields
```math
(a-\epsilon u)^Tz+\epsilon t\ge c+\epsilon v
```
on the epigraph. At $`(x,r)`$ the strict gap stays positive for sufficiently small $`\epsilon>0`$, because its limit is $`c-a^Tx>0`$. This produces a nonvertical affine minorant whose value at $`x`$ exceeds $`r`$.

Therefore $`\widetilde f(x)\ge r`$ for every finite $`r<f(x)`$. If $`f(x)`$ is finite, take $`r\uparrow f(x)`$; if it is infinite, take $`r\to+\infty`$. Together with the initial upper bound, this proves $`f=\widetilde f`$ everywhere, including points outside the domain.
