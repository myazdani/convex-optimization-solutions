# Exercise 3.5: Convexity of a running average

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.5, p. 114](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=128).

Original solution.

For $`x>0`$, substitute $`t=sx`$ to obtain
```math
F(x)=\int_0^1 f(sx)\,ds.
```
For every fixed $`s\in[0,1]`$, the function $`x\mapsto f(sx)`$ is convex. Thus for $`x,y>0`$ and $`\theta\in[0,1]`$,
```math
\begin{aligned}
F(\theta x+(1-\theta)y)
&=\int_0^1f(\theta sx+(1-\theta)sy)\,ds\\
&\le\theta\int_0^1f(sx)\,ds
 +(1-\theta)\int_0^1f(sy)\,ds.
\end{aligned}
```
This proves convexity on $`\mathbb R_{++}`$. The integrals are finite: a finite convex function is continuous away from zero; convexity bounds it above on each compact interval by the endpoint chord, and a supporting affine lower bound at any interior point bounds it below. Any possible endpoint discontinuity at zero does not affect the integral.
