# Exercise 4.15: Bounds and certificates from a Boolean relaxation

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.15](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=208). The source exercise and all of its subparts were checked directly.

## (a) Lower bound and infeasibility

Every Boolean-feasible vector is LP-feasible, since $`x_i\in\{0,1\}`$ implies $`0\le x_i\le1`$. Minimization over the larger set therefore gives

```math
p^\star_{\mathrm{LP}}\le p^\star_{\mathrm{Boolean}}.
```

This remains true in the extended-real sense when the Boolean problem is infeasible. If the LP relaxation is infeasible, the Boolean problem must be infeasible as well. The converse need not hold: for example, the inequalities $`x\le1/2`$ and $`-x\le-1/2`$ admit the relaxed point $`1/2`$ but no Boolean point.

## (b) Integral relaxed optimum

If an LP optimizer $`x^\star`$ is Boolean, it is feasible for the Boolean problem. Hence

```math
p^\star_{\mathrm{LP}}\le p^\star_{\mathrm{Boolean}}
\le c^Tx^\star=p^\star_{\mathrm{LP}}.
```

All values are equal and this vector is globally optimal for the Boolean problem. This is an exact certificate; it requires an integral optimal relaxed point, not merely an integral feasible point. Other relaxed optimizers may still be fractional when the optimal face is not a single point.

## Validation

The reasoning is set inclusion and a matching upper/lower bound, and does not rely on rounding or any heuristic.
