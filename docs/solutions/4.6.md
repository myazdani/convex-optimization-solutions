# Exercise 4.6: When a convex equality relaxation is exact

Source: [Boyd and Vandenberghe, Convex Optimization, exercise 4.6](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=205). The source exercise and all of its subparts were checked directly.

Here “monotonically increasing” is read as strictly increasing, as distinguished in the exercise from “nondecreasing.” Let $`x^\star`$ minimize the relaxed problem and suppose for contradiction that $`h(x^\star)<0`$.

Because $`h`$ is finite and convex on all of $`\mathbb R^n`$, it is continuous. Thus for all sufficiently small $`\epsilon>0`$,

```math
h(x^\star-\epsilon e_r)<0.
```

Decreasing coordinate $`r`$ cannot increase any $`f_i`$, $`i\ge1`$, so this perturbed point is feasible for the relaxation. Strict increase of the objective in that coordinate gives

```math
f_0(x^\star-\epsilon e_r)<f_0(x^\star),
```

a contradiction. Every relaxed optimizer therefore satisfies the equality. Since the equality-feasible set is contained in the relaxed feasible set, such an optimizer solves the original problem as well, with the same value.

The stated monotone decrease of $`h`$ is compatible with the argument: decreasing the coordinate can raise $`h`$, but a small decrease preserves its strictly negative value by continuity. No assumption about eventually reaching zero along the entire ray is needed. The conclusion is conditional on existence of a relaxed optimizer; it asserts neither feasibility nor attainment by itself.

## Why the strict reading matters

If “increasing” meant merely nondecreasing, the claim that every relaxed optimizer has active $`h`$ would be false. For example, $`f_0(x)=0`$ and $`h(x)=-x`$ in one dimension satisfy the weak monotonicities, but every $`x\ge0`$ is a relaxed optimizer and positive ones have inactive $`h`$.

## Validation

The proof uses the full-domain hypothesis exactly to obtain continuity, and makes explicit the strict monotonicity necessary for the asserted conclusion about every optimizer.
