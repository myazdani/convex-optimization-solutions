# Exercise 3.47: A first-order criterion for log-concavity

Source: Boyd and Vandenberghe, [Convex Optimization, exercise 3.47, p. 122](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=136).

Original solution.

Since $`f>0`$, define $`h=\log f`$ on the given convex domain. It is differentiable with $`\nabla h(x)=\nabla f(x)/f(x)`$. By the first-order characterization of concavity, $`h`$ is concave if and only if
```math
\log f(y)\le\log f(x)+\frac{\nabla f(x)^T(y-x)}{f(x)}
```
for all domain points. Subtract $`\log f(x)`$ and exponentiate, using strict monotonicity of the exponential, to obtain exactly
```math
\frac{f(y)}{f(x)}\le
\exp\left(\frac{\nabla f(x)^T(y-x)}{f(x)}\right).
```
Every operation is reversible, proving both necessity and sufficiency.
