# Exercise 7.7: Poisson emission estimation

Source: Boyd and Vandenberghe, *Convex Optimization*, exercise 7.7, printed page 394. [Official book](https://web.stanford.edu/~boyd/cvxbook/bv_cvxbook.pdf#page=408).

Use the thinning model in which each event from source $`i`$ is marked as detected at detector $`j`$ with probability $`p_{ji}`$, or undetected with the remaining probability. Its joint probability generating function is
```math
\exp\left(\mu_i\left[\sum_jp_{ji}t_j+1-\sum_jp_{ji}-1\right]\right)
=\prod_j\exp(p_{ji}\mu_i(t_j-1)).
```
This proves that the detector-specific counts from that source are independent Poisson variables. Independence between sources then gives independent aggregate counts $`y_j\sim\mathrm{Poisson}((P\mu)_j)`$.

Dropping the data-only factorial terms, the negative log likelihood is
```math
\sum_{j=1}^m\left((P\mu)_j-y_j\log(P\mu)_j\right).
```
Minimize this function subject to $`\mu\ge0`$. A positive observed count requires $`(P\mu)_j>0`$; for $`y_j=0`$ interpret its summand as $`(P\mu)_j`$, including at zero. Each scalar summand is convex, since its second derivative for positive intensity is $`y_j/\lambda^2\ge0`$. Thus this is a convex program, possibly nonidentifiable if detectors cannot distinguish some sources. A positive count in a detector with an identically zero row is incompatible with the model.

The thinning interpretation is the one encoded by the probabilities summing to at most one. If a single event could simultaneously create correlated detections at several sensors, these marginal probabilities alone would not specify a joint likelihood; an additional joint-detection model would be needed.
