### Source and data notes

- **Comparing four residual penalties:** Text gives a random 100-by-30 problem; CVX fixes the legacy MATLAB randn state; CVXOPT generates fresh random arrays. New PCG64 seed602 100-by-30 instance. Common b is scaled by 1/(1.1 max|b|), making x=0 strictly feasible for the logarithmic loss. This follows the CVXOPT input convention; its source explicitly says its own data differ from the book. Unlike the old CVXOPT least-squares branch, the right-hand side is actually -b rather than a zero vector.
- **Huber regression with two outliers:** CVXOPT publishes the 42 input points in huber.bin; CVX provides the original seeded generator.
- **Regularized input design:** Impulse response and weights are in the text; the exact piecewise-constant desired output is specified in both companion scripts. CVXOPT stacking omits the relative n/(n-1) derivative normalization. This implementation follows the book and CVX convention.
- **Sparse regressor selection:** The 10-by-20 matrix and response are published in regsel.bin. Official regsel.py explicitly states its problem data differ from the book. This is a complete method reproduction on the published companion instance.
- **Quadratic signal smoothing:** Signal formula is explicit in companion code; noise realization is fixed by legacy MATLAB randn state 0 in CVX. CVXOPT draws fresh noise. New PCG64 seed608 noise replaces the unpublished MATLAB realization. Formula, length4000 and noise standard deviation0.05 match the source. Exact target residuals8,3,1 are found by a scalar root instead of picking the closest point on the coarse trade-off grid.
- **Total-variation signal reconstruction:** Companion code defines the piecewise signal but draws unseeded Gaussian noise. Original noise samples are not published in these sources. New PCG64 seed611 replaces original unseeded noise; the 2000-point signal and noise standard deviation0.1 follow the companion. The book reconstructions are separately solved at exact TV budgets10,8,5. The companion15-point weight sweep and nearest-grid20,8,5 comparisons are also retained, clearly separate from the book targets.
- **Nominal, stochastic and worst-case least squares:** robls.bin contains the 20-by-10 instance indexed as 6.15.
- **Robust least squares with disk uncertainty:** robls.bin contains the 50-by-20 instance indexed as 6.16. CVX supplies a seeded generator and Monte Carlo sampler. Both book delta=1 and companion delta=0.1 are executed. The seed-606 Monte Carlo sample is newly generated and is not the unpublished original histogram sample.
- **Degree-five polynomial fitting:** Forty data pairs are in polapprox.bin; CVX supplies a seeded generator.
- **Cubic spline fitting:** Same 40 input pairs as Example 6.7, published in polapprox.bin.
- **Gabor basis pursuit and time-frequency recovery:** Signal and dictionary are explicit. The sampling-grid statements in the text and companion implementations need reconciliation. The text says501 equally spaced samples on[0,1], but prints0.005k, whose endpoint is2.5. CVX usesk/500 and removes Gaussian tails below0.001. CVXOPT usesk/501 without truncation. All three conventions are executed and reported separately. The full dictionary has30561 columns. Active-column optimization is accepted only after a full-dictionary dual certificate; this is not a reduced-dictionary substitute. The l1 optimum is followed by least-squares refitting on coefficients exceeding1e-5, matching the source workflow. The book reports42 selected atoms and relative squared error2.6e-4. Those are comparison benchmarks; source ambiguities and solver-sensitive support thresholds preclude silently asserting that every convention must recover them.
- **Convex least-squares function fitting:** The data pairs for the figure are published in cvxfit.bin.
- **Consumer preference bounds:** Companion source contains the forty goods baskets as literal constants.
